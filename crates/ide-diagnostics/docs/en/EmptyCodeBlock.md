# Empty code block (EmptyCodeBlock)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Description

Empty blocks in control structures are usually a sign of an incomplete implementation or accidentally removed code.

The diagnostic reports empty branches of `If`, `ElsIf`, `Else`, `While`, `For`, and `For Each`.

Empty procedure bodies and empty `Try`/`Except` sections are handled by other diagnostics.
