# Пропущен постфикс "Клиент" (CommonModuleNameClient)

## Описание диагностики

Клиентские общие модули предназначены для размещения логики, выполняемой на
стороне клиента. Такие модули определяются по клиентским признакам в
метаданных: `Клиент (управляемое приложение)` и/или
`Клиент (обычное приложение)`.

Имя неглобального клиентского общего модуля должно содержать постфикс
`Клиент` (англ. `Client`). Это позволяет сразу понять назначение модуля и не
смешивать его с серверными или клиент-серверными вариантами.

Исключение составляют модули с установленным флагом `Глобальный` — для них
используется отдельная схема именования без постфикса `Клиент`.

В отдельных случаях, когда клиентский код предназначен только для управляемого приложения, только для обычного приложения или только для внешнего соединения, допускается иная комбинация клиентских признаков.

## Примеры

Допустимые имена: `РаботаСФайламиКлиент`, `ОбщегоНазначенияКлиент`, `StandardSubsystemsClient`

Недопустимые имена: `РаботаСФайлами`, `ОбщегоНазначения` (при клиентских признаках модуля)
