# Недопустимый символ (InvalidCharacterInFile)

## Описание диагностики

Текст модуля не должен содержать символы неразрывного пробела, а также
символы, визуально похожие на обычный дефис-минус `-`, но имеющие другой код
Unicode.

Такие символы обычно попадают в код при копировании из офисных документов,
браузера или rich-text редакторов и вызывают следующие проблемы:

- текстовый поиск перестает работать ожидаемым образом;
- автодополнение и статический анализ в конфигураторе и EDT работают некорректно;
- использование "неправильного" минуса в выражении приводит к синтаксической ошибке.

Обнаруживаемые символы:

- Среднее тире
- Цифровое тире
- Длинное тире
- Горизонтальная линия
- "Неправильный" минус
- Мягкий перенос
- Неразрывный пробел
