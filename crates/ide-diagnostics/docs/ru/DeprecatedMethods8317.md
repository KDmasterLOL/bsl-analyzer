# Использование устаревших глобальных методов платформы 8.3.17 (DeprecatedMethods8317)

## Описание диагностики

В версии платформы 8.3.17 введено свойство глобального контекста `ОбработкаОшибок`, предоставляющее возможность централизованного управления текстами ошибок.

В связи с этим следующие методы глобального контекста признаны устаревшими:

* `КраткоеПредставлениеОшибки()`
* `ПодробноеПредставлениеОшибки()`
* `ПоказатьИнформациюОбОшибке()`

Вместо них необходимо вызывать одноимённые методы объекта `ОбработкаОшибок`.

## Примеры

Неправильно:

```bsl
Попытка
    ВыполнитьОперацию();
Исключение
    Текст = КраткоеПредставлениеОшибки(ИнформацияОбОшибке());
КонецПопытки;
```

Правильно:

```bsl
Попытка
    ВыполнитьОперацию();
Исключение
    Текст = ОбработкаОшибок.КраткоеПредставлениеОшибки(ИнформацияОбОшибке());
КонецПопытки;
```
