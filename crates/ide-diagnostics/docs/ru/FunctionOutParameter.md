# Исходящий параметр функции (FunctionOutParameter)

## Описание диагностики

Функция не должна модифицировать свои параметры для передачи результатов вызывающему коду. Все выходные данные следует возвращать через оператор `Возврат`. Когда необходимо вернуть несколько значений, рекомендуется формировать составной результат с помощью типов `Структура`, `Массив`, `Соответствие` и т.п.

## Примеры

Неправильно:
```bsl
Функция ПараметрыАвторизации(Логин, Пароль)
    Логин = НастройкиСистемы.Логин;
    Пароль = НастройкиСистемы.Пароль;
    Возврат Истина;
КонецФункции
```

Правильно:
```bsl
Функция ПараметрыАвторизации()
    Результат = Новый Структура;
    Результат.Вставить("Логин", НастройкиСистемы.Логин);
    Результат.Вставить("Пароль", НастройкиСистемы.Пароль);
    Возврат Результат;
КонецФункции
```
