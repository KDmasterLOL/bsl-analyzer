# Выполнение произвольного кода на сервере (ExecuteExternalCode)

## Описание диагностики

Методы `Выполнить` и `Вычислить` позволяют запустить произвольный программный код. Их использование в серверных методах модулей форм, команд, объектов и других модулей (кроме общих) запрещено, так как открывает возможность для выполнения вредоносного кода на стороне сервера.

Ограничение применяется исключительно к серверным методам. На клиентский код данное правило не распространяется.

## Примеры

### Неправильно (серверный метод модуля формы)

```bsl
&НаСервере
Процедура ОбработатьВыражениеНаСервере(ТекстКода)
    Выполнить(ТекстКода); // запрещено в модуле формы на сервере
КонецПроцедуры
```

### Правильно (клиентский метод -- ограничение не действует)

```bsl
&НаКлиенте
Процедура ОбработатьВыражение(ТекстКода)
    Выполнить(ТекстКода);
КонецПроцедуры
```
