# Устаревший API платформы (DeprecatedPlatformApi)

## Описание диагностики

Диагностика сообщает об обращениях к API платформы 1С:Предприятие, которые помечены в документации платформы как устаревшие.

Проверка покрывает устаревшие глобальные функции, глобальные методы, типы платформы и атрибуты платформы, для которых известно рекомендуемое средство замены. Текст сообщения называет конкретный устаревший API и сохраняет замену из реестра фактов платформы.

`DeprecatedMethodCall` остается отдельной диагностикой для методов прикладного кода, устаревших по комментариям документации. `GetFormMethod` также остается отдельной диагностикой и может срабатывать вместе с этой диагностикой для `ПолучитьФорму()` / `GetForm()`.

## Примеры

Неправильно:

```bsl
ДатаОперации = ТекущаяДата();
Позиция = Найти("abcdef", "cd");
Форма = ПолучитьФорму("Форма");
```

Правильно:

```bsl
ДатаОперации = ТекущаяДатаСеанса();
Позиция = СтрНайти("abcdef", "cd");
ОткрытьФорму("Форма");
```
