# Экспортные методы в модулях команд и общих команд (CommandModuleExportMethods)

## Описание диагностики

В модулях команд и общих команд ключевое слово `Экспорт` не формирует
доступный извне программный интерфейс. К таким модулям нельзя обратиться из
другого прикладного кода так же, как к обычному общему модулю, поэтому
экспортный модификатор в их методах не дает практического эффекта и только
создает ложное ощущение повторного использования.

## Примеры

### Неправильно

```bsl
// Модуль команды
&НаКлиенте
Процедура ОбработкаКоманды(ПараметрКоманды, ПараметрыВыполненияКоманды) Экспорт
    // ...
КонецПроцедуры

// Лишний экспорт -- к этому методу невозможно обратиться извне
&НаСервере
Функция ПолучитьДанные() Экспорт
    Возврат "Данные";
КонецФункции
```

### Правильно

```bsl
// Модуль команды
&НаКлиенте
Процедура ОбработкаКоманды(ПараметрКоманды, ПараметрыВыполненияКоманды)
    // ...
КонецПроцедуры

&НаСервере
Функция ПолучитьДанные()
    Возврат "Данные";
КонецФункции
```
