# Экспортные методы в модулях команд и общих команд (CommandModuleExportMethods)

## Описание диагностики

В модулях команд и общих команд экспортные процедуры и функции лишены смысла. Платформа не предоставляет механизма для обращения к этим модулям из другого кода, поэтому ключевое слово `Экспорт` в их методах не даёт никакого эффекта и вводит в заблуждение при чтении.

## Примеры

### Неправильно

```bsl
// Модуль команды
&НаКлиенте
Процедура ОбработкаКоманды(ПараметрКоманды, ПараметрыВыполненияКоманды) Экспорт
    // ...
КонецПроцедуры

// Лишний экспорт -- к этому методу невозможно обратиться извне
&НаСервере
Функция ПолучитьДанные() Экспорт
    Возврат "Данные";
КонецФункции
```

### Правильно

```bsl
// Модуль команды
&НаКлиенте
Процедура ОбработкаКоманды(ПараметрКоманды, ПараметрыВыполненияКоманды)
    // ...
КонецПроцедуры

&НаСервере
Функция ПолучитьДанные()
    Возврат "Данные";
КонецФункции
```
