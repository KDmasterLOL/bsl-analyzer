# Неиспользуемая локальная переменная (UnusedLocalVariable)

## Описание диагностики

Объявленная, но нигде не используемая локальная переменная является мёртвым кодом. Такие переменные следует удалять: это упрощает чтение модуля и избавляет других разработчиков от необходимости разбираться в их назначении.

Переменная считается неиспользуемой, если её имя нигде в теле метода не встречается в позиции чтения (цель присваивания и объявление `Перем` чтением не являются). Локали `Перем`/циклов/неявных присваиваний проверяются на любом уровне вложенности.

## Параметры

- `analyzeForLoopVariables` (логический, по умолчанию `true`) — сообщать о счётчиках цикла `Для` (`Для Сч = … По …`), которые не читаются в теле цикла. Установите `false`, чтобы их пропускать: такой счётчик нельзя просто удалить, поэтому в части проектов отчёт по нему считается шумом. На `Для Каждого` и остальные локали не влияет.

## Примеры

Неправильно:

```bsl
Процедура ОбработатьДанные()
    ВременнаяПеременная = 42;
    ВыполнитьОсновноеДействие();
КонецПроцедуры
```

Правильно:

```bsl
Процедура ОбработатьДанные()
    ВыполнитьОсновноеДействие();
КонецПроцедуры
```
