# Устаревшее использование типа "УправляемаяФорма" (DeprecatedTypeManagedForm)

## Описание диагностики

Устаревшее имя типа `УправляемаяФорма` следует заменить на `ФормаКлиентскогоПриложения`.

Переход на новое имя делает проверки типа понятнее и приводит код к актуальной терминологии платформы.

## Примеры

### Неправильно

```bsl
Если ТипЗнч(ТекущаяФорма) = Тип("УправляемаяФорма") Тогда
    // обработка формы
КонецЕсли;
```

### Правильно

```bsl
Если ТипЗнч(ТекущаяФорма) = Тип("ФормаКлиентскогоПриложения") Тогда
    // обработка формы
КонецЕсли;
```
