# Устаревшее использование типа "УправляемаяФорма" (DeprecatedTypeManagedForm)

## Описание диагностики

С выходом платформы 8.3.14 тип `УправляемаяФорма` признан устаревшим и заменён на `ФормаКлиентскогоПриложения`. Рекомендуется обновить все обращения к старому имени типа, чтобы обеспечить совместимость с актуальными версиями платформы.

## Примеры

### Неправильно

```bsl
Если ТипЗнч(ТекущаяФорма) = Тип("УправляемаяФорма") Тогда
    // обработка формы
КонецЕсли;
```

### Правильно

```bsl
Если ТипЗнч(ТекущаяФорма) = Тип("ФормаКлиентскогоПриложения") Тогда
    // обработка формы
КонецЕсли;
```
