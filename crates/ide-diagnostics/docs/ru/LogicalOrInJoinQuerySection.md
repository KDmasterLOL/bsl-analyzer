# Логическое 'ИЛИ' в соединениях запроса (LogicalOrInJoinQuerySection)

## Описание диагностики

Диагностика обнаруживает применение оператора `ИЛИ` в условиях соединения таблиц запроса.

Когда условие соединения содержит `ИЛИ` по разным полям, СУБД теряет возможность задействовать индексы и вынуждена выполнять полный перебор строк таблицы. Это приводит к замедлению запроса и повышенному риску блокировок.

Для устранения проблемы рекомендуется разнести условия с `ИЛИ` в отдельные пакеты запросов, объединив их результаты через `ОБЪЕДИНИТЬ ВСЕ`.

Диагностика фиксирует ошибку только при использовании `ИЛИ` над различными полями. Если `ИЛИ` применяется к вариантам значений одного и того же поля, предупреждение не выдается, так как SQL-сервер автоматически преобразует такое условие в оператор `IN`.

## Примеры

1) `ИЛИ` по вариантам одного поля -- ошибка не фиксируется:

```bsl
ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК Контрагенты
ПО Заказы.Контрагент = Контрагенты.Ссылка
   И (Контрагенты.Рейтинг = 1
     ИЛИ Контрагенты.Рейтинг = 5)
```

2) `ИЛИ` по разным полям -- ошибка фиксируется:

```bsl
ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ПоступлениеТоваров КАК Поступление
ПО ПоступлениеТовары.Ссылка = Поступление.Ссылка
   И (ПоступлениеТовары.Количество > 0
   ИЛИ ПоступлениеТовары.Цена > 0)
```

Исправление -- разбиение на отдельные пакеты:

```bsl
ВЫБРАТЬ *
ИЗ
ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ПоступлениеТоваров КАК Поступление
ПО ПоступлениеТовары.Ссылка = Поступление.Ссылка
   И ПоступлениеТовары.Количество > 0

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ *
ИЗ
ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ПоступлениеТоваров КАК Поступление
ПО ПоступлениеТовары.Ссылка = Поступление.Ссылка
   И ПоступлениеТовары.Цена > 0
```

3) Диагностика также срабатывает во вложенных соединениях:

```bsl
Справочник.Товары КАК Товары
ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Категории КАК Категории
    ЛЕВОЕ СОЕДИНЕНИЕ Справочник.ГруппыКатегорий КАК Группы
    ПО Категории.Группа = Группы.Ссылка
        И (Категории.Активна = ИСТИНА
         ИЛИ Группы.ОбязательнаяПроверка = ИСТИНА)
```

Рекомендуется заменить вложенное соединение на соединение с промежуточной временной таблицей, аналогично примеру 2.
