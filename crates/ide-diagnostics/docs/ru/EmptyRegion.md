# Область не должна быть пустой (EmptyRegion)

## Описание диагностики

Пустые области не несут функциональной нагрузки и засоряют текст модуля. Обычно они остаются после удаления кода, неудачного рефакторинга или незавершённой реализации.

Диагностика считает пустыми не только области без инструкций, но и области, в которых остались только комментарии или вложенные пустые области.

## Примеры

### Неправильно

```bsl
#Область СлужебныеПроцедуры
#КонецОбласти
```

### Правильно

Если область не содержит кода, удалите её целиком:

```bsl
// область удалена, лишнего раздела нет
```
