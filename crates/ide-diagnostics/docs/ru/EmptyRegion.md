# Область не должна быть пустой (EmptyRegion)

## Описание диагностики

Пустые области (`#Область ... #КонецОбласти` без содержимого) не несут функциональной нагрузки и засоряют текст модуля. Их следует удалять для поддержания чистоты кода.

## Примеры

### Неправильно

```bsl
#Область СлужебныеПроцедуры
#КонецОбласти
```

### Правильно

Если область не содержит кода -- удалите её. Если код планируется добавить позднее, оставьте комментарий-заглушку:

```bsl
#Область СлужебныеПроцедуры
// ДОДЕЛАТЬ: реализовать вспомогательные процедуры
#КонецОбласти
```
