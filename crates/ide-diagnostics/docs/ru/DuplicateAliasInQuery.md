# Повторный псевдоним источника запроса (DuplicateAliasInQuery)

## Описание диагностики

Диагностика сообщает о двух источниках запроса с одинаковым псевдонимом. Платформа такой запрос отклоняет, а анализатор до этого молча оставлял в области видимости только последний источник — все ссылки по этому имени разрешались в него, и ошибки в остальных полях не находились вовсе.

Имя источника — это его псевдоним, а если псевдонима нет, то полное имя таблицы. Сравнение регистронезависимо, как и везде в языке запросов.

## Примеры

Оба источника названы `Т`:
```sdbl
ВЫБРАТЬ
	Т.Наименование КАК Значение
ИЗ
	Справочник.Товары КАК Т
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Склады КАК Т
		ПО ИСТИНА
```

Исправление — дать источникам разные имена:
```sdbl
ВЫБРАТЬ
	Товары.Наименование КАК Значение
ИЗ
	Справочник.Товары КАК Товары
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Склады КАК Склады
		ПО ИСТИНА
```
