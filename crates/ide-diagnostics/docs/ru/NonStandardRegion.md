# Нестандартные разделы модуля (NonStandardRegion)

## Описание диагностики

Код модуля должен быть организован по стандартным разделам (областям). Для каждого типа модуля (модуль формы, модуль объекта, общий модуль и др.) определён фиксированный набор допустимых областей. Использование областей с произвольными именами, не входящими в этот набор, не допускается.

## Примеры

Неправильно

```bsl
#Область МоиВспомогательныеФункции

Процедура Обработать()
    // ...
КонецПроцедуры

#КонецОбласти
```

Правильно

```bsl
#Область СлужебныеПроцедурыИФункции

Процедура Обработать()
    // ...
КонецПроцедуры

#КонецОбласти
```
