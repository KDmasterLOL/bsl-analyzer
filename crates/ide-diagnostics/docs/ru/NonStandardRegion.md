# Нестандартные разделы модуля (NonStandardRegion)

## Описание диагностики

Диагностика выявляет области модуля, имена которых не входят в стандартный
набор разделов для данного типа модуля.

Стандартная структура модуля 1С задает допустимые названия областей для общих
модулей, модулей форм, модулей объектов и других типов модулей. Произвольные
имена областей делают структуру менее предсказуемой и нарушают общий шаблон,
описанный в стандарте.

## Примеры

Неправильно:

```bsl
#Область МоиВспомогательныеФункции

Процедура Обработать()
КонецПроцедуры

#КонецОбласти
```

Правильно:

```bsl
#Область СлужебныеПроцедурыИФункции

Процедура Обработать()
КонецПроцедуры

#КонецОбласти
```
