# Разыменование ссылочных полей запроса через точку (QueryNestedFieldsByDot)

## Описание диагностики

Диагностика выявляет разыменование ссылочных полей через точку внутри текста
запроса.

Публичная логика правила связана с производительностью: такие выражения могут
порождать неявные соединения и делать выполнение запроса менее предсказуемым.
На практике связанные данные часто понятнее и эффективнее получать через явные
`JOIN`.

Текущая реализация покрывает несколько вариантов:

- обычное вложенное обращение к полям в `SELECT`, `WHERE` и `JOIN`;
- разыменование внутри параметров виртуальных таблиц;
- разыменование после `ВЫРАЗИТЬ`.

## Примеры

Неправильно:

```bsl
ВЫБРАТЬ
    Продажи.Контрагент.Наименование КАК КонтрагентНаименование
ИЗ
    Документ.Продажи КАК Продажи
```

Правильно:

```bsl
ВЫБРАТЬ
    Контрагенты.Наименование КАК КонтрагентНаименование
ИЗ
    Документ.Продажи КАК Продажи
    ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК Контрагенты
    ПО Продажи.Контрагент = Контрагенты.Ссылка
```
