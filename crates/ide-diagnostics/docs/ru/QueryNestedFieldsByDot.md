# Разыменование ссылочных полей запроса через точку (QueryNestedFieldsByDot)

## Описание диагностики

Обращение к полям ссылочного типа через точку в тексте запроса приводит к неявным соединениям таблиц, что негативно сказывается на производительности. Каждое разыменование через точку генерирует дополнительный `LEFT JOIN` на уровне СУБД. Рекомендуется заменять такие обращения явными соединениями.

## Примеры

Неправильно (разыменование в секции выборки):

```bsl
ВЫБРАТЬ
    Продажи.Контрагент.Наименование КАК КонтрагентНаименование
ИЗ
    Документ.Продажи КАК Продажи
```

Неправильно (разыменование в условии):

```bsl
ГДЕ
    Накладная.Склад.Ответственный = &Менеджер
```

Неправильно (разыменование в соединении):

```bsl
ЛЕВОЕ СОЕДИНЕНИЕ ВТ_Заказы КАК Заказы
ПО Оплаты.Контрагент.Договор = Заказы.Договор
```

Правильно (явное соединение):

```bsl
ВЫБРАТЬ
    Контрагенты.Наименование КАК КонтрагентНаименование
ИЗ
    Документ.Продажи КАК Продажи
    ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК Контрагенты
    ПО Продажи.Контрагент = Контрагенты.Ссылка
```
