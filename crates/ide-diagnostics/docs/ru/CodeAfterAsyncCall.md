# После вызова асинхронного метода есть строки кода (CodeAfterAsyncCall)

## Описание диагностики

Код, расположенный непосредственно после вызова асинхронного метода, выполняется сразу, не дожидаясь завершения асинхронной операции. Это частая ошибка: разработчик предполагает последовательное выполнение, тогда как результат асинхронного вызова ещё не получен.

Весь код, зависящий от результата асинхронного действия, необходимо размещать в процедуре-обработчике оповещения, передаваемой через `ОписаниеОповещения`. Альтернативный вариант -- использование конструкции `Ждать` с асинхронными методами, возвращающими обещание (например, `Ждать ПредупреждениеАсинх(Текст)`).

Следует также учитывать ситуацию, когда асинхронный вызов находится внутри условия: код после блока `КонецЕсли` тоже может выполниться до завершения асинхронной операции.

## Примеры

### Неправильно

```bsl
&НаКлиенте
Процедура ОбработатьВыборФайла(Команда)
    Обработчик = Новый ОписаниеОповещения("ПослеВыбораФайла", ЭтотОбъект);
    НачатьПомещениеФайла(Обработчик, , , Истина);

    // Этот код выполнится немедленно, до выбора файла пользователем
    Сообщить("Файл успешно помещён");
КонецПроцедуры
```

### Правильно

```bsl
&НаКлиенте
Процедура ОбработатьВыборФайла(Команда)
    Обработчик = Новый ОписаниеОповещения("ПослеВыбораФайла", ЭтотОбъект);
    НачатьПомещениеФайла(Обработчик, , , Истина);
КонецПроцедуры

&НаКлиенте
Процедура ПослеВыбораФайла(Результат, Адрес, ВыбранноеИмя, ДопПараметры) Экспорт
    Если Результат Тогда
        Сообщить("Файл успешно помещён: " + ВыбранноеИмя);
    КонецЕсли;
КонецПроцедуры
```

### Асинхронный вызов внутри условия

```bsl
&НаКлиенте
Процедура ОбработатьДанные(Команда)
    Если ТребуетсяПодтверждение Тогда
        Обработчик = Новый ОписаниеОповещения("ПослеПодтверждения", ЭтотОбъект);
        ПоказатьВопрос(Обработчик, "Продолжить?", РежимДиалогаВопрос.ДаНет);
    Иначе
        ВыполнитьОбработку();
    КонецЕсли;

    // Код ниже может выполниться до ответа пользователя на вопрос
    ОбновитьИнтерфейс();
КонецПроцедуры
```
