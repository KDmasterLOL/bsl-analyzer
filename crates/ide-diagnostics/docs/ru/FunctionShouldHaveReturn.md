# Функция должна содержать возврат (FunctionShouldHaveReturn)

## Описание диагностики

Ключевое отличие функции от процедуры состоит в том, что функция обязана возвращать значение и может участвовать в выражениях. Функция без оператора `Возврат` является ошибкой. Для исправления необходимо:

- добавить оператор `Возврат` с нужным значением, если метод действительно должен быть функцией
- преобразовать функцию в процедуру, если возврат значения не требуется

## Примеры

Неправильно:
```bsl
Функция ИтогПоДокументу(Документ)
    Сумма = 0;
    Для Каждого Строка Из Документ.Товары Цикл
        Сумма = Сумма + Строка.Сумма;
    КонецЦикла;
КонецФункции
```

Правильно:
```bsl
Функция ИтогПоДокументу(Документ)
    Сумма = 0;
    Для Каждого Строка Из Документ.Товары Цикл
        Сумма = Сумма + Строка.Сумма;
    КонецЦикла;
    Возврат Сумма;
КонецФункции
```
