# Неизвестный код в директиве подавления (UnknownSuppressionCode)

## Описание диагностики

Директива подавления в комментарии (`// bsl-analyzer:off …`, `disable-next-line`, `disable-line`) ссылается на код диагностики, которого не существует. Чаще всего это опечатка в названии кода. Такая директива молча ничего не подавляет, поэтому автор рискует считать замечание скрытым, тогда как оно продолжает срабатывать.

Диагностика указывает на конкретный неизвестный токен, чтобы опечатку можно было сразу исправить.

## Примеры

Неправильно

```bsl
// bsl-analyzer:off NoSuchRule
А = А;
```

Правильно

```bsl
// bsl-analyzer:off SelfAssign
А = А;
```
