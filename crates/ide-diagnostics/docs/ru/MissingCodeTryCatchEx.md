# Конструкция "Попытка...Исключение...КонецПопытки" не содержит кода в исключении (MissingCodeTryCatchEx)

## Описание диагностики

Блок `Исключение` не должен оставаться пустым. Перехват исключения без какой-либо обработки скрывает реальные ошибки, которые впоследствии крайне сложно диагностировать. Как минимум, необходимо записать информацию об ошибке в журнал регистрации, чтобы администратор мог обнаружить и проанализировать проблему.

## Примеры

Неправильно:

```bsl
Попытка
    ЗагрузитьДанныеИзФайла(ПутьКФайлу);
Исключение
КонецПопытки;
```

Правильно:

```bsl
Попытка
    ЗагрузитьДанныеИзФайла(ПутьКФайлу);
Исключение
    ЗаписьЖурналаРегистрации(НСтр("ru = 'Загрузка данных'"),
        УровеньЖурналаРегистрации.Ошибка,,,
        ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;
```
