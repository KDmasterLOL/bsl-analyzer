# Подряд идущие пустые строки (ConsecutiveEmptyLines)

## Описание диагностики

Для визуального разделения логических блоков кода достаточно одной пустой строки. Наличие двух и более пустых строк подряд не добавляет наглядности, а лишь искусственно увеличивает объём модуля и ухудшает читаемость.

## Примеры

Неправильно:

```bsl
Процедура Выполнить()


    ПодготовитьДанные();
КонецПроцедуры
```

Правильно:

```bsl
Процедура Выполнить()

    ПодготовитьДанные();
КонецПроцедуры
```
