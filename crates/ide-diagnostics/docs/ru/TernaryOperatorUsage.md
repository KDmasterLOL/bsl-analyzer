# Использование тернарного оператора (TernaryOperatorUsage)

## Описание диагностики

Тернарный оператор `?(...)` снижает читаемость кода, особенно при вложенном использовании. Рекомендуется заменять его на конструкцию `Если...Тогда...Иначе...КонецЕсли`, которая делает логику ветвления наглядной и упрощает сопровождение.

## Примеры

Плохо:

```bsl
Статус = ?(Сумма > 1000, ?(Сумма > 5000, "Крупный", "Средний"), "Мелкий");
```

Хорошо:

```bsl
Если Сумма > 5000 Тогда
    Статус = "Крупный";
ИначеЕсли Сумма > 1000 Тогда
    Статус = "Средний";
Иначе
    Статус = "Мелкий";
КонецЕсли;
```

Плохо:

```bsl
Если ?(Документ.Статус = Null, 0, Документ.Статус) = 0 Тогда
    ОбработатьДокумент();
КонецЕсли;
```

Хорошо:

```bsl
Если Документ.Статус = Null ИЛИ Документ.Статус = 0 Тогда
    ОбработатьДокумент();
КонецЕсли;
```
