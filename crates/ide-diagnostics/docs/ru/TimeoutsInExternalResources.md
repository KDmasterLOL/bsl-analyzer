# Таймауты при работе с внешними ресурсами (TimeoutsInExternalResources)

## Описание диагностики

При создании объектов для работы с внешними ресурсами (`HTTPСоединение`, `FTPСоединение`, `WSОпределения`, `WSПрокси`) необходимо явно указывать таймаут. Без ограничения времени ожидания приложение может зависнуть при недоступности удалённого сервера.

Для `ИнтернетПочтовыйПрофиль` платформа устанавливает таймаут 30 секунд по умолчанию, однако рекомендуется задавать его явно.

Явное указание таймаута защищает от следующих проблем:

* разрыв интернет-соединения;
* блокировка запросов антивирусом или брандмауэром;
* некорректная конфигурация прокси-сервера;
* перегрузка или сбой удалённого сервера.

## Примеры

Неправильно:

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443);
```

```bsl
СоединениеFTP = Новый FTPСоединение(АдресСервера, Порт, Логин, Пароль, Прокси, ПассивныйРежим);
```

Правильно:

```bsl
Таймаут = 30;
Соединение = Новый HTTPСоединение("api.example.com", 443,,,, Таймаут);
```

```bsl
СоединениеFTP = Новый FTPСоединение(АдресСервера, Порт, Логин, Пароль, Прокси, ПассивныйРежим, 60);
```
