# Таймауты при работе с внешними ресурсами (TimeoutsInExternalResources)

## Описание диагностики

При создании объектов для работы с внешними ресурсами желательно явно задавать таймаут, чтобы сетевой вызов или обращение к удаленному сервису не ждали бесконечно долго.

Текущая реализация диагностики проверяет известные конструкторы объектов:

- `HTTPСоединение` / `HTTPConnection`
- `FTPСоединение` / `FTPConnection`
- `WSОпределения` / `WSDefinitions`
- `WSПрокси` / `WSProxy`
- `ИнтернетПочтовыйПрофиль` / `InternetMailProfile`

Диагностика сообщает о проблеме, если:

- в конструкторе не передан параметр таймаута;
- и после создания объекта не найдено присваивание свойства `Таймаут` / `Timeout` той же простой переменной.

Для `ИнтернетПочтовыйПрофиль` проверка настраивается отдельно, так как у платформы для него есть значение таймаута по умолчанию.

## Примеры

Неправильно:

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443);
```

```bsl
Определения = Новый WSОпределения("http://localhost/test.asmx?WSDL");
```

Правильно:

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443,,,, 30);
```

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443);
Соединение.Таймаут = 30;
```

## Параметры

- `analyzeInternetMailProfileZeroTimeout` (Булево, по умолчанию `true`)  
  Включает или отключает проверку `ИнтернетПочтовыйПрофиль`.
