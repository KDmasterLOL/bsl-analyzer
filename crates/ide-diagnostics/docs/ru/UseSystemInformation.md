# Использование системной информации (UseSystemInformation)

## Описание диагностики

Объект `СистемнаяИнформация` предоставляет сведения о компьютере пользователя и конфигурации системы. Эти данные могут быть использованы злоумышленниками для подготовки целенаправленных атак. Применение данного объекта требует обоснования и должно быть ограничено.

## Примеры

Неправильно:

```bsl
Инфо = Новый СистемнаяИнформация;
ОтправитьНаСервер(Инфо.ВерсияОС, Инфо.ОперативнаяПамять);
```
