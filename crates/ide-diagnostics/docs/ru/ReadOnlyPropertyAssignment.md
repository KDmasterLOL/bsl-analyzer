# Присваивание значения свойству, доступному только для чтения

Диагностика срабатывает на оператор присваивания, в котором левая часть — доступ к свойству платформенного типа, помеченному `Использование: Только чтение` в справке платформы (например, `Запрос.Параметры`, `РезультатЗапроса.Колонки`).

## Почему это проблема

Такое присваивание выполнится молча на этапе разбора, но во время выполнения приведёт либо к исключению, либо просто не окажет никакого эффекта на объект. Обычно корректный способ задать значение — использовать специальный метод менеджера (`УстановитьПараметр` для параметров запроса) или пересобрать объект целиком.

## Примеры

Неправильно:

```bsl
Зап = Новый Запрос;
Зап.Параметры = Новый Структура; // <-- свойство только для чтения
```

Правильно:

```bsl
Зап = Новый Запрос;
Зап.УстановитьПараметр("Ключ", Значение);
```

## Отключение

Если справка платформы для конкретного свойства устарела, или диагностика срабатывает на корректном коде, её можно отключить стандартным образом в настройках анализатора.
