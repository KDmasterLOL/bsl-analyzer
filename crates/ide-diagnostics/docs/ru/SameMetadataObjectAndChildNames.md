# Совпадает имя объекта метаданного и его дочернего (SameMetadataObjectAndChildNames)

## Описание диагностики

Подчинённые элементы метаданных (реквизиты, измерения, ресурсы, табличные части и их реквизиты) не должны носить то же имя, что и объект-владелец. Совпадение имён порождает неоднозначности при обращении к полям в запросах и может приводить к трудноуловимым ошибкам.

## Примеры

Неправильное именование

```
Справочник.Валюты.Реквизит.Валюты
РегистрНакопления.ОстаткиТоваров.Измерение.ОстаткиТоваров
Документ.Заказ.ТабличнаяЧасть.Заказ.Реквизит.Заказ
```
