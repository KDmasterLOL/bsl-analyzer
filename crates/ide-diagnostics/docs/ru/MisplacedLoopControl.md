# Оператор Прервать или Продолжить вне цикла (MisplacedLoopControl)

## Описание диагностики

`Прервать` и `Продолжить` допустимы только внутри тел циклов: `Пока`, `Для` или
`Для Каждого`. Диагностика сообщает об этих операторах на верхнем уровне метода
или внутри нециклических блоков, например `Если` или `Попытка`.

## Примеры

### Неправильно

```bsl
Процедура Тест()
    Прервать;
КонецПроцедуры
```

### Правильно

```bsl
Процедура Тест()
    Пока Истина Цикл
        Прервать;
    КонецЦикла;
КонецПроцедуры
```
