# Лишняя директива компиляции (CompilationDirectiveNeedLess)

## Описание диагностики

Директивы компиляции (`&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста`) предназначены исключительно для модулей управляемых форм и модулей команд. В остальных модулях для управления доступностью кода следует применять инструкции препроцессора.

В общих модулях с однозначным контекстом исполнения (только серверные или только клиентские) директивы компиляции избыточны -- контекст определяется свойствами самого модуля. В общих модулях с признаками "Клиент" и "Сервер" одновременно директивы компиляции создают путаницу относительно реальной доступности процедур и функций.

## Примеры

Неправильно (серверный общий модуль):

```bsl
&НаСервере
Процедура ПересчитатьОстатки()
    // Директива избыточна -- модуль и так серверный
КонецПроцедуры
```

Правильно:

```bsl
Процедура ПересчитатьОстатки()
    // Контекст определяется свойствами общего модуля
КонецПроцедуры
```
