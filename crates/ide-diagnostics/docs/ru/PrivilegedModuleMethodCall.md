# Обращение к методам привилегированных модулей (PrivilegedModuleMethodCall)

## Описание диагностики

Вызов экспортных процедур и функций из привилегированных общих модулей может приводить к обходу ограничений прав доступа, установленных в конфигурации. Код привилегированного модуля выполняется без проверки прав, поэтому любое обращение к его публичным методам требует аудита на предмет нежелательного повышения привилегий.

## Примеры

Допустим, в конфигурации есть привилегированный модуль `СистемныеЗадания` с экспортной функцией:

```bsl
// В привилегированном модуле СистемныеЗадания
Функция ВыполнитьОперацию(Знач ИмяОперации, Знач Параметры) Экспорт
    // выполняется без проверки прав
КонецФункции
```

Вызов из произвольного места конфигурации:

```bsl
СистемныеЗадания.ВыполнитьОперацию("УдалитьДанные", Параметры);
```

Необходимо убедиться, что вызываемая операция не выполняет деструктивных действий и не раскрывает данные, закрытые ограничениями доступа.
