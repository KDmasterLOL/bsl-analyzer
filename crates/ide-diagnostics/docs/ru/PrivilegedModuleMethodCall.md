# Обращение к методам привилегированных модулей (PrivilegedModuleMethodCall)

## Описание диагностики

Диагностика выявляет обращения к экспортным методам привилегированных общих
модулей.

Привилегированные модули выполняются с повышенными правами и могут обходить
обычные проверки доступа. Поэтому каждый вызов их публичного API требует
ручной проверки: вызывающий код может случайно или намеренно получить доступ к
операциям, которые должны оставаться за явной границей безопасности.

Диагностика также поддерживает локальный параметр `validateNestedCalls`. Если
он выключен, внутренние вызовы из того же привилегированного модуля не
проверяются.

## Примеры

Допустим, в конфигурации есть привилегированный модуль `СистемныеЗадания`:

```bsl
Функция ВыполнитьОперацию(ИмяОперации, Параметры) Экспорт
КонецФункции
```

Вызов из другого модуля:

```bsl
СистемныеЗадания.ВыполнитьОперацию("УдалитьДанные", Параметры);
```

Такие вызовы стоит отдельно проверять, чтобы привилегированная операция была
действительно безопасна для данного контекста вызова.
