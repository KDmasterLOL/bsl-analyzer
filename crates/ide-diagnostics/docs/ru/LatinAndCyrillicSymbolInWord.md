# Смешивание латинских и кириллических символов в одном идентификаторе (LatinAndCyrillicSymbolInWord)

## Описание диагностики

Идентификаторы, содержащие одновременно символы латиницы и кириллицы, затрудняют работу с кодом, поскольку требуют переключения раскладки клавиатуры. Кроме того, диагностика обнаруживает случайное использование визуально схожих символов из другого алфавита (например, латинская `o` вместо кириллической `о`, `c` вместо `с`, `B` вместо `В` и т.п.).

Для уменьшения ложных срабатываний на составных именах, где одно из слов записано на другом языке, предусмотрен параметр (включен по умолчанию). При его активации имена вида `PrinterДрайвер`, `КодHTML`, `SMSОтправка` считаются допустимыми.

## Примеры

Неправильно:
```bsl
// Латинская "c" вместо кириллической "с"
Перем КодТовараВcистеме; // буква "c" латинская

// Смешение алфавитов внутри одного слова
Перем Сontрагент; // часть букв латинские
```

Правильно:
```bsl
Перем КодТовараВСистеме;

Перем Контрагент;
```
