# Избыточная проверка параметра АвтоТест (ExcessiveAutoTestCheck)

## Описание диагностики

Проверки параметра `"АвтоТест"` с немедленным `Возврат` больше не нужны. Это наследие старого подхода к взаимодействию с автотестами, которое теперь только оставляет в модуле мёртвый код.

Диагностика срабатывает на ветви `Если`, которые проверяют `"АвтоТест"` / `"AutoTest"` и содержат только один оператор `Возврат`.

## Примеры

### В обработчике открытия формы (удалить)

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    Если Параметры.Свойство("АвтоТест") Тогда // лишняя проверка
        Возврат;
    КонецЕсли;
    // основная логика
КонецПроцедуры
```

### В обработчике ОбработкаЗаполнения (удалить)

```bsl
Процедура ОбработкаЗаполнения(ДанныеЗаполнения, ТекстЗаполнения, СтандартнаяОбработка)
    Если ДанныеЗаполнения = "АвтоТест" Тогда // лишняя проверка
        Возврат;
    КонецЕсли;
    // основная логика
КонецПроцедуры
```
