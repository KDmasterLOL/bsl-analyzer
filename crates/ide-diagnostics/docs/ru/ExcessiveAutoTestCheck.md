# Избыточная проверка параметра АвтоТест (ExcessiveAutoTestCheck)

## Описание диагностики

Ранее стандарт 772 требовал, чтобы обработчики открытия форм и заполнения объектов содержали раннее возврат при получении параметра `"АвтоТест"`. Этот стандарт отменён, и соответствующие проверки больше не нужны. Их наличие создаёт мёртвый код, который следует удалить.

## Примеры

### В обработчике открытия формы (удалить)

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    Если Параметры.Свойство("АвтоТест") Тогда // лишняя проверка
        Возврат;
    КонецЕсли;
    // основная логика
КонецПроцедуры
```

### В обработчике ОбработкаЗаполнения (удалить)

```bsl
Процедура ОбработкаЗаполнения(ДанныеЗаполнения, ТекстЗаполнения, СтандартнаяОбработка)
    Если ДанныеЗаполнения = "АвтоТест" Тогда // лишняя проверка
        Возврат;
    КонецЕсли;
    // основная логика
КонецПроцедуры
```
