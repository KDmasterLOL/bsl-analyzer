# Флажок "Устанавливать права для новых объектов" должен быть установлен только у роли ПолныеПрава (SetPermissionsForNewObjects)

## Описание диагностики

Атрибут «Устанавливать права для новых объектов» у роли приводит к тому, что при добавлении любого нового объекта метаданных в конфигурацию эта роль автоматически получает на него права. Если флажок ошибочно включён у роли, отличной от `ПолныеПрава`, со временем в ней накопятся права на все добавленные объекты, а пользователи с этой ролью получат избыточные полномочия.

Текущая реализация диагностики загружает метаданные ролей и сообщает о каждой роли с `setForNewObjects=true`, если её имя не входит в список явно разрешённых ролей.

## Примеры

Неправильно — флажок установлен у роли `Менеджер`

```
Роль: Менеджер
  УстанавливатьПраваДляНовыхОбъектов = Истина  // ошибка
```

Правильно — флажок установлен только у `ПолныеПрава`

```
Роль: ПолныеПрава
  УстанавливатьПраваДляНовыхОбъектов = Истина

Роль: Менеджер
  УстанавливатьПраваДляНовыхОбъектов = Ложь
```

## Параметры

- `namesFullAccessRole` (строка, по умолчанию `FullAccess,ПолныеПрава`)  
  Список ролей, для которых этот флаг считается допустимым.
