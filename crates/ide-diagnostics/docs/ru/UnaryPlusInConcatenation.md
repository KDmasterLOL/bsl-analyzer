# Унарный плюс в конкатенации строк (UnaryPlusInConcatenation)

## Описание диагностики

При склеивании строк оператором `+` может быть допущен лишний знак плюса: `Строка1 + + Строка2`. Платформа интерпретирует второй `+` как унарный оператор и пытается преобразовать следующий операнд к числу. В большинстве случаев это приводит к ошибке времени выполнения.

## Примеры

Неправильно:

```bsl
Сообщение = "Документ: " + + НомерДокумента;
```

Правильно:

```bsl
Сообщение = "Документ: " + НомерДокумента;
```
