# Опечатка (Typo)

## Описание диагностики

Диагностика выявляет орфографические ошибки в идентификаторах и строковых литералах. Идентификаторы в формате camelCase разбиваются на составные слова, каждое из которых проверяется по встроенным словарям Hunspell (русский и английский).

Диагностика отключена по умолчанию, поскольку словарная проверка может давать ложные срабатывания на специфичных терминах предметной области 1С.

### Параметры

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `minWordLength` | Число | 3 | Минимальная длина слова для проверки |
| `userWordsToIgnore` | Строка | "" | Список слов-исключений через запятую |

## Примеры

### Неправильно

```bsl
Функция ВаринатыОплаты()
    Сообщить("Атмена");
КонецФункции
```

### Правильно

```bsl
Функция ВариантыОплаты()
    Сообщить("Отмена");
КонецФункции
```
