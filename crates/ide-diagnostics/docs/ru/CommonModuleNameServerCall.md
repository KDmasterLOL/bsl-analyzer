# Пропущен постфикс "ВызовСервера" (CommonModuleNameServerCall)

## Описание диагностики

Общие модули с признаком "Сервер" и установленным флагом "Вызов сервера" предназначены для размещения серверных процедур и функций, которые могут вызываться из клиентского кода. Такие модули образуют клиентский программный интерфейс серверной части приложения.

Имя подобного модуля должно заканчиваться постфиксом "ВызовСервера" (англ. "ServerCall"). Это позволяет сразу понять, что методы модуля доступны для вызова с клиента.

## Примеры

Неправильно:

```
УправлениеДоступомСервер
UserAccessServer
```

Правильно:

```
УправлениеДоступомВызовСервера
UserAccessServerCall
```
