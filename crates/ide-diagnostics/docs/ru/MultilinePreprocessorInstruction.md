# Инструкция препроцессора разорвана переводом строки

Части инструкции препроцессора — условие, его операнды, закрывающее `Тогда` —
обязаны стоять на строке самой инструкции. Платформа такой разрыв не принимает,
хотя синтаксически конструкция однозначна и читается без затруднений.

Проверка покрывает `#Если`, `#ИначеЕсли` и имя после `#Область`. Тело
инструкции переводами строки полно по построению и разрывом не считается:
граница — закрывающее `Тогда`.

## Неправильно

```bsl
#Если
Сервер Тогда
	А = 1;
#КонецЕсли

#Если Сервер
И Клиент Тогда
	Б = 2;
#КонецЕсли

#Если Сервер
Тогда
	В = 3;
#КонецЕсли
```

## Правильно

```bsl
#Если Сервер Тогда
	А = 1;
#КонецЕсли

#Если Сервер И Клиент Тогда
	Б = 2;
#КонецЕсли
```

## Имя области

```bsl
// Неправильно
#Область
Служебные

// Правильно
#Область Служебные
```

Здесь разрыв меняет и сам разбор: имя за переводом строки областью не берётся,
иначе директива утащила бы первое слово следующего оператора. Поэтому такое имя
остаётся отдельным словом, и разбор сообщает о нём как о неверном операторе.
То сообщение верное, но о следствии; причину называет эта проверка.

Унесённое имя опознаётся по трём признакам сразу: у директивы нет имени, следом
идёт ровно одно значимое слово, и точки с запятой за ним нет. Поэтому вызов без
скобок (`Метод;`), оператор (`А = 1`) и лишнее слово после уже названной
области сюда не попадают.

## Замечания

Про область, у которой имени нет вовсе, проверка не утверждает ничего.

Инструкция без `Тогда` пропускается: она уже сломана, и об этом сообщает
разбор. Второе сообщение о том же месте пользы не несёт.
