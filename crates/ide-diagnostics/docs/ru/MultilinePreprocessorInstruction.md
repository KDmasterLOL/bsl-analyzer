# Инструкция препроцессора разорвана переводом строки

Части инструкции препроцессора — условие, его операнды, закрывающее `Тогда` —
обязаны стоять на строке самой инструкции. Платформа такой разрыв не принимает,
хотя синтаксически конструкция однозначна и читается без затруднений.

Проверка покрывает `#Если` и `#ИначеЕсли`. Тело инструкции переводами строки
полно по построению и разрывом не считается: граница — закрывающее `Тогда`.

## Неправильно

```bsl
#Если
Сервер Тогда
	А = 1;
#КонецЕсли

#Если Сервер
И Клиент Тогда
	Б = 2;
#КонецЕсли

#Если Сервер
Тогда
	В = 3;
#КонецЕсли
```

## Правильно

```bsl
#Если Сервер Тогда
	А = 1;
#КонецЕсли

#Если Сервер И Клиент Тогда
	Б = 2;
#КонецЕсли
```

## Замечания

Имя после `#Область`, унесённое на следующую строку, этой проверкой не
покрывается: там разрыв меняет сам разбор — имя областью не берётся, — и о нём
сообщает разбор, а не диагностика.

Инструкция без `Тогда` пропускается: она уже сломана, и об этом сообщает
разбор. Второе сообщение о том же месте пользы не несёт.
