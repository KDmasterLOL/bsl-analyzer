# Использование объектов недоступных в Unix системах (UsingObjectNotAvailableUnix)

## Описание диагностики

В ОС Linux отсутствует поддержка технологий `COM`, `OLE` и `ActiveDocument`. Для интеграции с внешними системами на Linux следует применять альтернативные механизмы: файловый обмен в формате XML, HTTP-сервисы, web-сервисы. Внешние компоненты, построенные на COM-технологии, рекомендуется переработать с использованием технологии `NativeAPI`.

Объекты, отслеживаемые диагностикой:

* `COMОбъект`
* `Почта`

### Дополнительно

Диагностика учитывает условия, содержащие проверку платформы. Срабатывание подавляется, если в условии присутствуют ключевые слова:

* `Linux_x86`
* `Windows`
* `MacOs`

## Примеры

### Неправильно

```bsl
Объект = Новый COMОбъект("Scripting.FileSystemObject");
```

```bsl
Письмо = Новый Почта;
```

### Правильно

```bsl
Инфо = Новый СистемнаяИнформация();
Если Инфо.ТипПлатформы = ТипПлатформы.Windows_x86
    Или Инфо.ТипПлатформы = ТипПлатформы.Windows_x86_64 Тогда
    Объект = Новый COMОбъект("Scripting.FileSystemObject");
КонецЕсли;
```
