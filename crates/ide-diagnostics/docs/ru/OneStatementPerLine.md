# Одно выражение в одной строке (OneStatementPerLine)

## Описание диагностики

Диагностика выявляет несколько операторов, расположенных в одной строке.

Общая логика правила опирается на рекомендации 1С по оформлению текстов
модулей: разнесение операторов по строкам улучшает читаемость и упрощает
отладку. Текущая реализация строгая: если несколько операторов начинаются в
одной строке, они считаются нарушением, кроме случаев, которые исключаются на
этапе lowering-а (препроцессор, пустые операторы, parse error cases).

## Примеры

Неправильно:

```bsl
Сумма = 0; Если Количество > 0 Тогда Сумма = Цена * Количество; КонецЕсли;
```

Правильно:

```bsl
Сумма = 0;
Если Количество > 0 Тогда
    Сумма = Цена * Количество;
КонецЕсли;
```
