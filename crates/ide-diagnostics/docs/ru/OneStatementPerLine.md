# Одно выражение в одной строке (OneStatementPerLine)

## Описание диагностики

Каждый оператор в модуле должен располагаться на отдельной строке. Размещение нескольких операторов в одной строке допускается только для однотипных присваиваний, например инициализации счётчиков.

## Примеры

Неправильно:

```bsl
Сумма = 0; Если Количество > 0 Тогда Сумма = Цена * Количество; КонецЕсли;
```

Правильно:

```bsl
Сумма = 0;
Если Количество > 0 Тогда
    Сумма = Цена * Количество;
КонецЕсли;
```

Допустимо (однотипные присваивания):

```bsl
Индекс = 0; Счетчик = 0; Итого = 0;
```
