# Директива подавления без указания кода (SuppressionWithoutCode)

## Описание диагностики

Директива подавления в комментарии (`// bsl-analyzer:off`, `disable-next-line`, `disable-line`) не перечисляет коды диагностик, поэтому подавляет в своей области **все** замечания. Это скрывает не только осознанно исключаемое замечание, но и любые будущие, включая действительно важные.

Рекомендуется всегда перечислять конкретные коды, которые нужно подавить.

## Примеры

Неправильно

```bsl
// bsl-analyzer:off
А = А;
```

Правильно

```bsl
// bsl-analyzer:off SelfAssign
А = А;
```
