# Соединение с вложенными запросами (JoinWithSubQuery)

## Описание диагностики

В запросах не следует выполнять соединения с вложенными запросами. Вместо
этого рекомендуется соединять только объекты метаданных или временные
таблицы.

Соединение с подзапросом может привести к следующим проблемам:

- существенное замедление выполнения даже при низкой нагрузке на сервер
- нестабильная производительность: при одних условиях запрос выполняется быстро, при других -- крайне медленно
- различная скорость выполнения на разных СУБД
- высокая зависимость от актуальности статистик базы данных

## Примеры

Неправильно:
```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Заказы.Ссылка
|ИЗ
|    Документ.ЗаказПокупателя КАК Заказы
|    ЛЕВОЕ СОЕДИНЕНИЕ (
|        ВЫБРАТЬ Регистратор
|        ИЗ РегистрНакопления.ОстаткиТоваров.Остатки
|        ГДЕ Склад = &Склад
|    ) КАК Остатки
|    ПО Заказы.Ссылка = Остатки.Регистратор
|");
```

Правильно:
```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ Регистратор
|ПОМЕСТИТЬ ВременныеОстатки
|ИЗ РегистрНакопления.ОстаткиТоваров.Остатки
|ГДЕ Склад = &Склад
|;
|ВЫБРАТЬ
|    Заказы.Ссылка
|ИЗ
|    Документ.ЗаказПокупателя КАК Заказы
|    ЛЕВОЕ СОЕДИНЕНИЕ ВременныеОстатки КАК Остатки
|    ПО Заказы.Ссылка = Остатки.Регистратор
|");
```

## Исключение для агрегирующих подзапросов

Подзапросы, которые агрегируют, исключаются из проверки: соединение с подзапросом
допустимо, если в его `ВЫБРАТЬ` присутствует `СГРУППИРОВАТЬ ПО` **или** прямой
вызов агрегатной функции (`СУММА`/`SUM`, `СРЕДНЕЕ`/`AVG`, `МИНИМУМ`/`MIN`,
`МАКСИМУМ`/`MAX`, `КОЛИЧЕСТВО`/`COUNT`). Такой подзапрос делает то, чего
исходная таблица не умеет, поэтому правило к нему не относится.

```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ Заказы.Ссылка
|ИЗ Документ.ЗаказПокупателя КАК Заказы
|    ЛЕВОЕ СОЕДИНЕНИЕ (
|        ВЫБРАТЬ Регистратор, СУММА(Сумма) КАК Итог
|        ИЗ РегистрНакопления.Х
|        СГРУППИРОВАТЬ ПО Регистратор
|    ) КАК Агрегат
|    ПО Заказы.Ссылка = Агрегат.Регистратор
|");  // OK: агрегирующий подзапрос
```

Проверка анализирует только позиции вызова функций, поэтому ссылка на колонку
или псевдоним, случайно названный `Сумма`/`Sum`, не подавляет диагностику.
