# Многострочный литерал в запросе (MultilineStringInQuery)

## Описание диагностики

Диагностика выявляет подозрительные многострочные строковые литералы внутри
текста запроса.

На практике такие литералы обычно появляются не намеренно, а из-за ошибки в
экранировании двойных кавычек. Частый случай: вместо пустой строки в SDBL
используется `""`, хотя для нее требуется `""""`. В результате часть текста
запроса начинает интерпретироваться как одна длинная строковая константа.

## Примеры

Неправильно:

```bsl
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ
|   Товары.Номенклатура КАК Номенклатура,
|   ЕСТЬNULL(Товары.Номенклатура.Код, "") КАК КодНоменклатуры,
|   ЕСТЬNULL(Товары.Номенклатура.Наименование, "") КАК НаименованиеНоменклатуры
|ИЗ
|   Документ.ЗаказПокупателя.Товары КАК Товары";
```

Правильно:

```bsl
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ
|   Товары.Номенклатура КАК Номенклатура,
|   ЕСТЬNULL(Товары.Номенклатура.Код, """") КАК КодНоменклатуры,
|   ЕСТЬNULL(Товары.Номенклатура.Наименование, """") КАК НаименованиеНоменклатуры
|ИЗ
|   Документ.ЗаказПокупателя.Товары КАК Товары";
```
