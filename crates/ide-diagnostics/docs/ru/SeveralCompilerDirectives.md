# Ошибочное указание нескольких директив компиляции (SeveralCompilerDirectives)

## Описание диагностики

Метод или переменная модуля может иметь только одну директиву компиляции. Указание двух и более директив является синтаксической ошибкой. Кроме того, если указаны разные директивы, возникает неопределённость: будет ли этот код скомпилирован, и если да, то в каком контексте он будет исполняться.

Текущая реализация простая и точная:

- проверяются top-level процедуры, функции и module-level переменные из item tree;
- диагностика срабатывает на любой элемент, у которого больше одной аннотации;
- комментарии и пустые строки между директивами на результат не влияют.

## Примеры

Неправильно

```bsl
&НаСервере
&НаКлиенте
Перем Счётчик;

&НаКлиенте
&НаСервереБезКонтекста
Процедура ОбновитьДанные()
    // ...
КонецПроцедуры
```

Правильно

```bsl
&НаКлиенте
Перем Счётчик;

&НаСервереБезКонтекста
Процедура ОбновитьДанные()
    // ...
КонецПроцедуры
```
