# Обращение к Интернет-ресурсам (InternetAccess)

## Описание диагностики

Диагностика служит инструментом security-аудита для кода, который создает
объекты сетевого взаимодействия или доступа к Интернет-ресурсам.

По умолчанию она отключена. Её задача не автоматически запретить любой такой
код, а вынести его на дополнительную проверку, чтобы убедиться, что:

- внешнее взаимодействие действительно необходимо;
- передача данных разрешена и безопасна;
- протокол и конечная точка выбраны осознанно;
- доступ документирован и контролируется.

## Примеры

```bsl
Соединение = Новый HTTPСоединение("api.example.com", 443, , , , , Новый ЗащищенноеСоединениеOpenSSL);
ФайловоеСоединение = Новый FTPСоединение("files.example.com", 21, Логин, Пароль);
Почта = Новый ИнтернетПочта();
```
