# Пустой блок кода (EmptyCodeBlock)

## Описание диагностики

Пустой блок кода (тело условия, цикла, процедуры без единой инструкции) сигнализирует о потенциальной ошибке. Типичные причины появления: незавершённая реализация или случайное удаление содержимого при редактировании. Пустые блоки следует либо заполнить логикой, либо удалить вместе с окружающей конструкцией.
