# Ошибка разбора исходного кода (ParseError)

## Описание диагностики

Диагностика срабатывает при обнаружении синтаксических ошибок в исходном коде модуля. Причиной может быть нарушение грамматики языка BSL либо некорректное использование инструкций препроцессора.

Инструкции препроцессора и области не должны разрывать грамматические конструкции: выражения, объявления процедур и функций, блоки условных операторов и списки параметров при вызове.

## Примеры

Неправильно:

```bsl
Процедура Расчет()
    Результат = 1
#Область Вычисление
        + 2;
#КонецОбласти
КонецПроцедуры

#Область БлокОбработки
Процедура Обработать()
    // ...
#КонецОбласти
КонецПроцедуры

Если Условие Тогда
    // ...
#Если Сервер Тогда
Иначе
    // ...
#КонецЕсли
КонецЕсли;
```
