# Ошибка разбора исходного кода (ParseError)

## Описание диагностики

Диагностика выявляет фрагменты исходного кода, которые текущий BSL-парсер не
смог корректно разобрать.

С точки зрения реализации правило простое: каждый непустой узел `ERROR` в
синтаксическом дереве превращается в диагностику `ParseError`. Это означает,
что диагностика покрывает разные виды ошибок разбора: нарушения синтаксиса
языка, некорректное использование препроцессора, незакрытые строки и другие
parser-level проблемы.

Поэтому, хотя некорректные инструкции препроцессора действительно являются
одним из частых источников таких ошибок, текущее поведение диагностики шире,
чем один конкретный сценарий из стандарта.

## Примеры

Неправильно:

```bsl
Процедура Пример()
    Если НЕ Тогда
    КонецЕсли;
КонецПроцедуры
```

```bsl
Процедура Пример()
    Значение = "незакрытая строка
КонецПроцедуры
```
