# Несоответствие типов по описанию (TypeMismatchByDocComment)

## Описание диагностики

Эта диагностика сообщает о несоответствии типа в позиции аргумента, когда ожидаемый тип параметра был взят из описания (doc-comment) пользовательской функции, а не из платформы, модели метаданных или корпуса типов.

Описания типов в комментариях пишутся вручную и часто бывают неполными, устаревшими или неточными, поэтому несоответствие, выведенное из них, имеет низкую достоверность. По этой причине оно сообщается как замечание (информационный уровень), а не как ошибка: это подсказка пересмотреть вызов или описание, а не гарантированная ошибка.

Соответствующие высокодостоверные случаи — когда ожидаемый тип получен из платформы, метаданных или корпуса — сообщаются диагностикой `TypeMismatch` с её обычным уровнем серьёзности.

Из-за низкой достоверности эта диагностика **отключена по умолчанию**; включите её явно в конфигурации проекта, если хотите получать такие замечания.

## Примеры

```bsl
// Параметры:
//   Значение - Число - описание
Процедура Обработать(Значение) Экспорт
КонецПроцедуры

Обработать("текст"); // тип из описания — Число, передаётся Строка
```
