# Использование устаревшего свойства "ЭтаФорма" (UsingThisForm)

## Описание диагностики

Начиная с версии платформы 1С:Предприятие 8.3.3, свойство `ЭтаФорма` является устаревшим. Для получения ссылки на текущую форму следует использовать свойство `ЭтотОбъект`.

## Примеры

### Неправильно

```bsl
ЭтаФорма.Заголовок = "Карточка клиента";
```

### Правильно

```bsl
ЭтотОбъект.Заголовок = "Карточка клиента";
```
