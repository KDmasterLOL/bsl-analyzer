# Ограничение на длину строки (LineLength)

## Описание диагностики

Длина строки кода не должна превышать 120 символов. Если строка длиннее этого порога, её необходимо разбить на несколько строк с помощью переносов. Исключением являются ситуации, в которых перенос технически невозможен, например, при определении длинных строковых констант для вывода пользователю через объект `СообщениеПользователю`.

## Примеры

Неправильно:

```bsl
СообщениеДляПользователя = "Операция обработки документа " + ИмяДокумента + " завершена с ошибкой. Обратитесь к администратору системы для получения дополнительной информации по данной проблеме.";
```

Правильно:

```bsl
СообщениеДляПользователя = "Операция обработки документа " + ИмяДокумента
    + " завершена с ошибкой."
    + " Обратитесь к администратору системы для получения дополнительной информации.";
```
