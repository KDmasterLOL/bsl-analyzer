# Кеширование программного интерфейса (CachedPublic)

## Описание диагностики

Экспортные методы (программный интерфейс) не следует размещать в общих модулях с повторным использованием возвращаемых значений. Такое размещение жёстко привязывает потребителя к механизму кеширования конкретного модуля. Если в дальнейшем потребуется перенести функцию в обычный модуль или наоборот, все вызывающие места придётся переделывать.

Вместо этого экспортную функцию рекомендуется размещать в обычном модуле в разделе программного интерфейса, а внутри неё вызывать служебную функцию из модуля с повторным использованием. При смене проектного решения достаточно будет изменить реализацию внутри одной функции, не затрагивая её потребителей.

## Примеры

### Неправильно

```bsl
// Модуль НастройкиПовтИсп (с повторным использованием)
Функция ПолучитьНастройку(ИмяНастройки) Экспорт
    Возврат Константы[ИмяНастройки].Получить();
КонецФункции
```

### Правильно

```bsl
// Модуль Настройки (обычный)
Функция ПолучитьНастройку(ИмяНастройки) Экспорт
    Возврат НастройкиПовтИсп.ЗначениеНастройки(ИмяНастройки);
КонецФункции

// Модуль НастройкиПовтИсп (с повторным использованием)
Функция ЗначениеНастройки(ИмяНастройки)
    Возврат Константы[ИмяНастройки].Получить();
КонецФункции
```
