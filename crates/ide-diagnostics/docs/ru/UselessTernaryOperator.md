# Бесполезный тернарный оператор (UselessTernaryOperator)

## Описание диагностики

Тернарный оператор, возвращающий константы `Истина` и `Ложь` (или `True` и `False`), является избыточным. Условие само по себе уже представляет булево значение, и заворачивание его в тернарный оператор лишь усложняет код.

## Примеры

Бессмысленно:

```bsl
ЕстьОшибка = ?(КодОтвета <> 200, Истина, Ложь);
```

Правильно:

```bsl
ЕстьОшибка = КодОтвета <> 200;
```

Подозрительно:

```bsl
Результат = ?(Количество > 0, True, Истина);
```

```bsl
Значение = ?(Флаг, 0, False);
```
