# Бесполезный тернарный оператор (UselessTernaryOperator)

## Описание диагностики

Тернарный оператор, возвращающий константы `Истина` и `Ложь` (или `True` и `False`), является избыточным. Условие само по себе уже представляет булево значение, и заворачивание его в тернарный оператор лишь усложняет код.

Текущая реализация намеренно узкая. Она срабатывает только когда:

- условие тернарного оператора само является булевой константой;
- или обе ветки являются булевыми константами.

То есть диагностика не пытается распознавать все возможные эквивалентные или подозрительные формы тернарных операторов. Она ловит только небольшой набор очевидных случаев.

## Примеры

Бессмысленно:

```bsl
ЕстьОшибка = ?(КодОтвета <> 200, Истина, Ложь);
```

Правильно:

```bsl
ЕстьОшибка = КодОтвета <> 200;
```

Подозрительно:

```bsl
Результат = ?(Количество > 0, True, Истина);
```

Не срабатывает в текущей реализации:

```bsl
Значение = ?(Флаг, 0, False);
```

Здесь только одна ветка булева, поэтому rule это выражение пропускает.
