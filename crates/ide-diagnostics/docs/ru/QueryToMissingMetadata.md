# Обращение к несуществующим метаданным в запросе (QueryToMissingMetadata)

## Описание диагностики

В процессе развития конфигурации объекты метаданных могут переименовываться или удаляться. Если при этом тексты запросов не были скорректированы, в них остаются ссылки на устаревшие или несуществующие таблицы. Аналогичная ситуация возникает при ручном редактировании запроса без последующей проверки через конструктор запросов.

Выполнение такого запроса приведёт к ошибке времени исполнения.

## Примеры

Обращение к удалённому справочнику:
```sdbl
ВЫБРАТЬ
	Данные.Наименование КАК Наименование
ИЗ
	Справочник.СтароеИмяСправочника КАК Данные
```

Соединение с переименованным регистром:
```sdbl
ВЫБРАТЬ
	Остатки.Количество КАК Количество
ИЗ
	РегистрНакопления.ОстаткиТоваров КАК Остатки
	ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.НесуществующийРегистр КАК Фильтр
	ПО Фильтр.Номенклатура = Остатки.Номенклатура
```
