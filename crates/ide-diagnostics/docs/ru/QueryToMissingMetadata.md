# Обращение к несуществующим метаданным в запросе (QueryToMissingMetadata)

## Описание диагностики

Диагностика сообщает о таблицах запроса, которые не разрешаются в существующие объекты метаданных.

Такая ошибка обычно появляется после переименования или удаления объекта метаданных, либо после ручного редактирования текста запроса без проверки итогового результата.

## Примеры

Обращение к несуществующему справочнику:
```sdbl
ВЫБРАТЬ
	Данные.Наименование КАК Наименование
ИЗ
	Справочник.НесуществующийСправочник КАК Данные
```

Соединение с несуществующим регистром:
```sdbl
ВЫБРАТЬ
	Остатки.Количество КАК Количество
ИЗ
	РегистрНакопления.ОстаткиТоваров КАК Остатки
	ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений.НесуществующийРегистр КАК Фильтр
	ПО Фильтр.Номенклатура = Остатки.Номенклатура
```
