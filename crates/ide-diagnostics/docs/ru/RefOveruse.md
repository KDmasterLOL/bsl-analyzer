# Избыточное использование "Ссылка" в запросе (RefOveruse)

## Описание диагностики

Обращение к свойству `.Ссылка` у поля ссылочного типа не несёт полезной нагрузки — значение поля уже является ссылкой. При этом такое обращение вынуждает СУБД выполнять неявное левое соединение с таблицей-источником, что создаёт лишнюю нагрузку на сервер баз данных и замедляет выполнение запроса.

## Примеры

```bsl
Запрос.Текст = "ВЫБРАТЬ
| Вложения.Документ.Ссылка,
| Вложения.Документ
|ИЗ
| РегистрСведений.Вложения КАК Вложения";
```

В данном примере `Вложения.Документ.Ссылка` избыточно — достаточно использовать `Вложения.Документ`.
