# Избыточное использование "Ссылка" в запросе (RefOveruse)

## Описание диагностики

Если поле запроса уже имеет ссылочный тип, дополнительное обращение к `.Ссылка` обычно избыточно. Такое разыменование может приводить к лишним неявным соединениям и ухудшать производительность запроса.

Диагностика сообщает о случаях, когда в запросе используется `.Ссылка` у поля, которое уже известно как ссылка.

## Примеры

Неправильно:

```bsl
Запрос.Текст = "ВЫБРАТЬ
| Вложения.Документ.Ссылка,
| Вложения.Документ
|ИЗ
| РегистрСведений.Вложения КАК Вложения";
```

Правильно:

```bsl
Запрос.Текст = "ВЫБРАТЬ
| Вложения.Документ КАК Документ
|ИЗ
| РегистрСведений.Вложения КАК Вложения";
```
