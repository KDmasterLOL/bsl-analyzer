# Использование метода РольДоступна (IsInRoleMethod)

## Описание диагностики

Для проверки прав доступа к объектам метаданных следует использовать метод `ПравоДоступа`, а не `РольДоступна`. Метод `РольДоступна` допустим только для ролей, которые не предоставляют прав на объекты метаданных, а определяют дополнительные возможности пользователя.

При использовании Библиотеки стандартных подсистем (БСП) рекомендуется применять функцию `РолиДоступны` из общего модуля `Пользователи`. Если БСП не используется, вызов `РольДоступна()` обязательно должен сопровождаться проверкой `ПривилегированныйРежим()`.

## Примеры

Проверка прав на объект метаданных:

Неправильно:
```bsl
Если РольДоступна("РедактированиеТоваров") Тогда
    РазрешитьИзменение = Истина;
КонецЕсли;
```

Правильно:
```bsl
Если ПравоДоступа("Редактирование", Метаданные.Справочники.Товары) Тогда
    РазрешитьИзменение = Истина;
КонецЕсли;
```

Проверка дополнительного права без БСП:

Неправильно:
```bsl
Если РольДоступна("АдминистраторСистемы") Тогда
    ОткрытьПанельАдминистрирования();
КонецЕсли;
```

Правильно:
```bsl
Если РольДоступна("АдминистраторСистемы") ИЛИ ПривилегированныйРежим() Тогда
    ОткрытьПанельАдминистрирования();
КонецЕсли;
```
