# Использование метода РольДоступна (IsInRoleMethod)

## Описание диагностики

Для проверки прав доступа к объектам метаданных следует использовать метод
`ПравоДоступа`, а не `РольДоступна`.

Метод `РольДоступна` допустим только для ролей, которые не предоставляют прав
на объекты метаданных, а определяют дополнительное прикладное право.

Текущая реализация диагностики ищет случаи, когда `РольДоступна()` используется
в условии `Если` / `ИначеЕсли` без проверки `ПривилегированныйРежим()`. Также
отслеживаются локальные переменные, в которые ранее был записан результат
`РольДоступна()`.

## Примеры

Неправильно:
```bsl
Если РольДоступна("РедактированиеТоваров") Тогда
    РазрешитьИзменение = Истина;
КонецЕсли;
```

Правильно:
```bsl
Если ПравоДоступа("Редактирование", Метаданные.Справочники.Товары) Тогда
    РазрешитьИзменение = Истина;
КонецЕсли;
```

Неправильно:
```bsl
Если РольДоступна("АдминистраторСистемы") Тогда
    ОткрытьПанельАдминистрирования();
КонецЕсли;
```

Правильно:
```bsl
Если РольДоступна("АдминистраторСистемы") ИЛИ ПривилегированныйРежим() Тогда
    ОткрытьПанельАдминистрирования();
КонецЕсли;
```
