# Неправильный перенос выражения (IncorrectLineBreak)

## Описание диагностики

При переносе длинных выражений на несколько строк необходимо соблюдать единые правила форматирования:

**Арифметические выражения:** знаки операций размещаются в начале новой строки, а не в конце предыдущей. Операнды на новой строке выравниваются стандартным отступом либо по началу первого операнда.

**Параметры методов:** при переносе параметры выравниваются по первому параметру или предваряются стандартным отступом. Закрывающая скобка и разделитель `;` располагаются на одной строке с последним параметром.

**Логические условия:** если длина строки превышает 120 символов, каждое элементарное условие начинается с новой строки. Логические операторы `И`, `ИЛИ` ставятся в начале строки.

**Настройка исключений:**

- Если стандарт команды допускает закрывающую скобку и `;` на отдельной строке, нужно скорректировать параметр `listOfIncorrectFirstSymbol`: заменить подстроку `|\);` на `|\)\s*;\s*\S+`

## Примеры

Неправильно:
```bsl
ИтогоСумма = СуммаТоваров +
             СуммаУслуг +
             СуммаДоставки;
```

Правильно:
```bsl
ИтогоСумма = СуммаТоваров
    + СуммаУслуг
    + СуммаДоставки;
```

или

```bsl
ИтогоСумма = СуммаТоваров
             + СуммаУслуг
             + СуммаДоставки;
```

Перенос параметров метода:
```bsl
СписокТоваров = Новый СписокЗначений;
СписокТоваров.Добавить(Метаданные.Справочники.Товары.Имя,
                       Метаданные.Справочники.Товары.Синоним);
```

Вариант с закрывающей скобкой на отдельной строке (требует настройки параметра):
```bsl
СписокТоваров = Новый СписокЗначений;
СписокТоваров.Добавить(
    Метаданные.Справочники.Товары.Имя,
    Метаданные.Справочники.Товары.Синоним
);
```
