# Неправильный перенос выражения (IncorrectLineBreak)

## Описание диагностики

Диагностика отмечает несколько вариантов переноса строк, которые конфликтуют с
правилами переноса выражений из `#std444` и с текущей formatter-policy
`bsl-analyzer`.

Текущая реализация проверяет:

- арифметические операторы и логические операторы `И` / `ИЛИ` в конце строки;
- закрывающую скобку `)` или `;` в начале строки;
- запятую в начале строки, если после неё идёт содержательное продолжение.

Для многострочного продолжения строковых литералов диагностика специально не
ругается на `+` в конце строки, если следующая строка начинается со строкового
литерала или символа `|`.

## Примеры

Неправильно:
```bsl
ИтогоСумма = СуммаТоваров +
             СуммаУслуг +
             СуммаДоставки;
```

Правильно:
```bsl
ИтогоСумма = СуммаТоваров
    + СуммаУслуг
    + СуммаДоставки;
```

Логические операторы тоже должны переноситься в начало новой строки:

```bsl
Если Условие1
    ИЛИ Условие2 Тогда
КонецЕсли;
```

```bsl
Если Условие1 ИЛИ
    Условие2 Тогда
КонецЕсли;
```

```bsl
СписокТоваров.Добавить(
    Метаданные.Справочники.Товары.Имя,
    Метаданные.Справочники.Товары.Синоним);
```

```bsl
СписокТоваров.Добавить(
    Метаданные.Справочники.Товары.Имя,
    Метаданные.Справочники.Товары.Синоним
);
```
