# Неприменимая аннотация перехвата (WeavingAnnotationNotApplicable)

## Описание диагностики

Расширение конфигурации может перехватывать метод расширяемого модуля с помощью
аннотаций `&Вместо`, `&Перед` или `&После`. Платформа ограничивает, какую
аннотацию можно применить к **функции**: расширяемую функцию можно расширить
**только** аннотацией `&Вместо`. Аннотации `&Перед` и `&После` доступны лишь для
процедур.

Диагностика срабатывает на перехватчике с аннотацией `&Перед` / `&После`, целью
которого является функция. Платформа отклоняет такой перехват при проверке
применимости, и перехватчик молча не выполняется.

## Примеры

### Неправильно

```bsl
// Расширяемый метод: Функция ВычислитьСумму(Параметры) Экспорт ... КонецФункции

&После("ВычислитьСумму") // &После нельзя применить к функции
Процедура Расш1_ВычислитьСумму(Параметры)
    // ...
КонецПроцедуры
```

### Правильно

```bsl
&Вместо("ВычислитьСумму")
Функция Расш1_ВычислитьСумму(Параметры)
    Результат = ПродолжитьВызов(Параметры);
    // ...
    Возврат Результат;
КонецФункции
```
