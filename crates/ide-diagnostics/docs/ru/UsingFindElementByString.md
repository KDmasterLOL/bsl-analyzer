# Использование методов "НайтиПоНаименованию", "НайтиПоКоду" и "НайтиПоНомеру" (UsingFindElementByString)

## Описание диагностики

Диагностика обнаруживает вызовы методов `НайтиПоНаименованию`, `НайтиПоКоду` и `НайтиПоНомеру`, в которых аргументом передано жёстко заданное строковое или числовое значение (конкретное наименование, код или номер элемента справочника или документа).

Такой код привязан к данным конкретной информационной базы и не будет корректно работать в других базах. Кроме того, подобные конструкции могут быть признаком случайно оставленного тестового кода.

Константные значения данных рекомендуется хранить в константах информационной базы или в предопределённых элементах объектов метаданных.

Текущая реализация в первую очередь ловит прямые строковые и числовые литералы, а также пустые вызовы наподобие `НайтиПоНаименованию()`.

## Примеры

### Неправильно

```bsl
Сотрудник = Справочники.Сотрудники.НайтиПоНаименованию("Иванов Пётр Сергеевич");
```

```bsl
Валюта = Справочники.Валюты.НайтиПоКоду("840");
```

```bsl
Накладная = Документы.РасходнаяНакладная.НайтиПоНомеру("00-000123", ТекущаяДата());
```

### Правильно

```bsl
Сотрудник = Справочники.Сотрудники.НайтиПоНаименованию(ВыбранноеИмя);
```

```bsl
Валюта = Справочники.Валюты.НайтиПоКоду(КодВалюты);
```

```bsl
Накладная = Документы.РасходнаяНакладная.НайтиПоНомеру(НомерДокумента, ДатаДокумента);
```
