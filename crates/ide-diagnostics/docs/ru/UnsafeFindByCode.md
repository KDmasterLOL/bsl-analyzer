# Небезопасное использование метода НайтиПоКоду() (UnsafeFindByCode)

## Описание диагностики

Диагностика фиксирует вызовы метода `НайтиПоКоду()` (или `FindByCode()`) для справочников, в которых не гарантирована уникальность кода:

- отключён контроль уникальности кода;
- серии кодов настроены не по всему справочнику (например, в пределах подчинения).

В таких условиях метод может вернуть произвольный элемент из нескольких с одинаковым кодом, что приводит к непредсказуемому поведению.

## Примеры

Неправильно:

```bsl
// Справочник без контроля уникальности кода
Валюта = Справочники.Валюты.НайтиПоКоду("840");
```

```bsl
// Справочник с сериями кодов в пределах подчинения
Подразделение = Справочники.Подразделения.НайтиПоКоду("003");
```

Правильно:

```bsl
// Справочник с включённым контролем уникальности
Контрагент = Справочники.Контрагенты.НайтиПоКоду("000001");
```

```bsl
// Альтернатива — поиск по наименованию или запросом
Валюта = Справочники.Валюты.НайтиПоНаименованию("Доллар США");
```
