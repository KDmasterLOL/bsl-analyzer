# Функция всегда возвращает одно и то же примитивное значение (FunctionReturnsSamePrimitive)

## Описание диагностики

Если все ветви выполнения функции возвращают одно и то же примитивное значение, это означает, что возвращаемое значение не несет полезной информации. Такой метод следует оформить как процедуру, убрав бесполезный `Возврат`.

## Примеры

Неправильно:
```bsl
Функция ОбработатьЗаказ(Знач НомерЗаказа)

    Если СтатусЗаказа(НомерЗаказа) = "Новый" Тогда
        ОтправитьНаСклад(НомерЗаказа);
        Возврат Ложь;
    ИначеЕсли СтатусЗаказа(НомерЗаказа) = "Подтвержден" Тогда
        СформироватьНакладную(НомерЗаказа);
        Возврат Ложь;
    Иначе
        Возврат Ложь;
    КонецЕсли;

КонецФункции
```

Правильно:
```bsl
Процедура ОбработатьЗаказ(Знач НомерЗаказа)

    Если СтатусЗаказа(НомерЗаказа) = "Новый" Тогда
        ОтправитьНаСклад(НомерЗаказа);
    ИначеЕсли СтатусЗаказа(НомерЗаказа) = "Подтвержден" Тогда
        СформироватьНакладную(НомерЗаказа);
    КонецЕсли;

КонецПроцедуры
```

## Особенности

Подключаемые функции исключаются из проверки. Пример:
```bsl
Функция Подключаемый_ВыполнитьДействие(Команда)

    Если ЗначениеЗаполнено(Параметры) Тогда
        Возврат Неопределено;
    КонецЕсли;

    Возврат Неопределено;

КонецФункции
```
