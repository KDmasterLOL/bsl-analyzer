# Неэкспортные методы в областях ПрограммныйИнтерфейс и СлужебныйПрограммныйИнтерфейс (NonExportMethodsInApiRegion)

## Описание диагностики

Область "ПрограммныйИнтерфейс" предназначена исключительно для экспортных процедур и функций, доступных другим объектам конфигурации и внешним потребителям (например, через COM-соединение). Размещение неэкспортных методов в этой области нарушает её назначение.

Область "СлужебныйПрограммныйИнтерфейс" служит для экспортных методов, которые используются только внутри библиотеки (между подсистемами одной функциональной группы). В ней также не должно быть неэкспортных методов.

## Примеры

Неправильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ВнутренняяОбработка()  // Нет ключевого слова "Экспорт"
    // ...
КонецПроцедуры

#КонецОбласти
```

Правильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ОбработатьДанные() Экспорт
    // ...
КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

Процедура ВнутренняяОбработка()
    // ...
КонецПроцедуры

#КонецОбласти
```
