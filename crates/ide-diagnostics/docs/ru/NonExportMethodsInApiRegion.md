# Неэкспортные методы в областях ПрограммныйИнтерфейс и СлужебныйПрограммныйИнтерфейс (NonExportMethodsInApiRegion)

## Описание диагностики

Диагностика выявляет неэкспортные процедуры и функции, размещенные в областях
`ПрограммныйИнтерфейс`, `СлужебныйПрограммныйИнтерфейс`, `Public` и `Internal`.

Согласно стандартной структуре модуля, эти области предназначены для
интерфейса модуля. Методы, размещенные в них, должны относиться к этому
интерфейсу, поэтому неэкспортным методам там не место.

Для проектов с особыми соглашениями доступен дополнительный параметр
`skipAnnotatedMethods`, позволяющий пропускать методы со встроенными
аннотациями.

## Примеры

Неправильно:

```bsl
#Область ПрограммныйИнтерфейс

Процедура ВнутренняяОбработка()
КонецПроцедуры

#КонецОбласти
```

Правильно:

```bsl
#Область ПрограммныйИнтерфейс

Процедура ОбработатьДанные() Экспорт
КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

Процедура ВнутренняяОбработка()
КонецПроцедуры

#КонецОбласти
```
