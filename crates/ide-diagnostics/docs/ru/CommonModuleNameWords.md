# Нерекомендуемое имя общего модуля (CommonModuleNameWords)

## Описание диагностики

В названиях общих модулей не следует использовать неинформативные общие слова: "Процедуры", "Функции", "Обработчики", "Модуль", "Функциональность" и подобные. Такие слова не отражают назначение модуля и затрудняют навигацию по конфигурации.

## Примеры

Неправильно:

```
ОбщиеПроцедурыИФункции
МодульОбработкиДокументов
```

Правильно:

```
ОбработкаДокументов
РаботаСКонтрагентами
```
