# Повторное использование строкового литерала (DuplicateStringLiteral)

## Описание диагностики

Если один и тот же строковый литерал используется в модуле или методе многократно, это создаёт проблемы сопровождения. При необходимости изменить значение легко пропустить одно из вхождений. Кроме того, дублирование литералов часто возникает при копировании блоков кода, когда разработчик забывает скорректировать строку. Повторяющиеся литералы рекомендуется выносить в переменную (внутри метода) или в отдельную функцию (при использовании в нескольких методах).

### Особенности реализации диагностики

- По умолчанию сравнение литералов выполняется без учёта регистра: `"Привет"` и `"привет"` считаются одинаковыми.
- Минимальная длина анализируемого литерала не может быть меньше значения по умолчанию, поскольку короткие служебные строки (`""`, `"0"`, `"1"`) встречаются повсеместно и создают ложные срабатывания.
- Допустимое количество повторений не может быть меньше 1.

## Примеры

### Неправильно

```bsl
Процедура ОбработатьДанные(Режим)
    Сообщение = "Обработка завершена";
    Если Режим = "Полная" Тогда
        Журнал.Записать(ВРег("Обработка завершена"));
    Иначе
        Журнал.Записать(НРег("Обработка завершена"));
    КонецЕсли;
КонецПроцедуры
```

### Правильно (вынесено в переменную)

```bsl
Процедура ОбработатьДанные(Режим)
    Сообщение = "Обработка завершена";
    Если Режим = "Полная" Тогда
        Журнал.Записать(ВРег(Сообщение));
    Иначе
        Журнал.Записать(НРег(Сообщение));
    КонецЕсли;
КонецПроцедуры
```

### Неправильно (литерал в нескольких методах)

```bsl
Процедура ЗаписатьВЛог()
    ДобавитьСтроку("Результат операции");
КонецПроцедуры

Процедура ПоказатьПользователю()
    Сообщить("Результат операции");
КонецПроцедуры
```

### Правильно (вынесено в функцию)

```bsl
Функция ТекстРезультата()
    Возврат "Результат операции";
КонецФункции

Процедура ЗаписатьВЛог()
    ДобавитьСтроку(ТекстРезультата());
КонецПроцедуры

Процедура ПоказатьПользователю()
    Сообщить(ТекстРезультата());
КонецПроцедуры
```
