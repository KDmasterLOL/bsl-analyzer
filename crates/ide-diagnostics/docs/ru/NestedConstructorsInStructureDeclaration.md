# Использование конструкторов с параметрами при объявлении структуры (NestedConstructorsInStructureDeclaration)

## Описание диагностики

Диагностика выявляет объявления структуры, в которых значения свойств создаются
через вложенные конструкторы с параметрами прямо внутри внешнего конструктора.

Такой код корректен, но быстро становится трудным для чтения, особенно когда
во внешнем `Структура` или `ФиксированнаяСтруктура` создается сразу несколько
вложенных объектов. Обычно понятнее сначала подготовить вложенные значения в
отдельных переменных, а затем передать их во внешний конструктор.

## Примеры

Неправильно:

```bsl
ПараметрыОбработки = Новый Структура(
    "РежимПроверки, РежимОбновления",
    Новый Структура("Документ", "Проверка"),
    Новый Структура("Документ", "Обновление")
);
```

Правильно:

```bsl
НастройкаПроверки = Новый Структура("Документ", "Проверка");
НастройкаОбновления = Новый Структура("Документ", "Обновление");

ПараметрыОбработки = Новый Структура(
    "РежимПроверки, РежимОбновления",
    НастройкаПроверки,
    НастройкаОбновления
);
```
