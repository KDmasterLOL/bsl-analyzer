# Использование конструкторов с параметрами при объявлении структуры (NestedConstructorsInStructureDeclaration)

## Описание диагностики

При создании структуры не следует передавать в качестве значений свойств результаты вызова других конструкторов с параметрами. В особенности это касается случаев, когда внутри конструктора одной структуры создаются другие структуры с указанием значений. Такой код сложно читать и сопровождать. Вместо этого рекомендуется выносить создание вложенных объектов в отдельные переменные.

## Примеры

Неправильно

```bsl
ПараметрыОбработки = Новый Структура(
    "РежимПроверки, РежимОбновления",
    Новый Структура("Документ", "Проверка"),
    Новый Структура("Документ", "Обновление")
);
```

Правильно

```bsl
НастройкаПроверки = Новый Структура("Документ", "Проверка");
НастройкаОбновления = Новый Структура("Документ", "Обновление");

ПараметрыОбработки = Новый Структура;
ПараметрыОбработки.Вставить("РежимПроверки", НастройкаПроверки);
ПараметрыОбработки.Вставить("РежимОбновления", НастройкаОбновления);
```
