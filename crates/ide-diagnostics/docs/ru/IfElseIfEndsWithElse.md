# Использование синтаксической конструкции Если...Тогда...ИначеЕсли... (IfElseIfEndsWithElse)

## Описание диагностики

Каждая цепочка `Если...Тогда...ИначеЕсли...`, содержащая хотя бы одну ветвь `ИначеЕсли`, должна завершаться блоком `Иначе`. Это принцип защитного программирования: явная обработка всех возможных вариантов делает код устойчивым к будущим изменениям и предотвращает скрытые ошибки.

Блок `Иначе` должен либо содержать обработку непредвиденного случая, либо включать комментарий, поясняющий, почему действие не требуется.

## Примеры

Неправильно:
```bsl
Если ТипДоговора = "Поставка" Тогда
    ОбработатьПоставку(Договор);
ИначеЕсли ТипДоговора = "Услуги" Тогда
    ОбработатьУслугу(Договор);
КонецЕсли;
```

Правильно:
```bsl
Если ТипДоговора = "Поставка" Тогда
    ОбработатьПоставку(Договор);
ИначеЕсли ТипДоговора = "Услуги" Тогда
    ОбработатьУслугу(Договор);
Иначе
    ВызватьИсключение "Неизвестный тип договора: " + ТипДоговора;
КонецЕсли;
```
