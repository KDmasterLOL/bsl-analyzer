# Использование синтаксической конструкции Если...Тогда...ИначеЕсли... (IfElseIfEndsWithElse)

## Описание диагностики

Диагностика отмечает цепочки `Если`, в которых есть хотя бы одна ветвь
`ИначеЕсли`, но отсутствует завершающий блок `Иначе`.

Это локальное правило защитного программирования: если в конструкции уже
перечислено несколько явных вариантов, блок `Иначе` делает обработку остальных
случаев явной. Он может либо выполнять нужное действие, либо документировать,
почему дополнительная обработка не требуется.

## Примеры

Неправильно:
```bsl
Если ТипДоговора = "Поставка" Тогда
    ОбработатьПоставку(Договор);
ИначеЕсли ТипДоговора = "Услуги" Тогда
    ОбработатьУслугу(Договор);
КонецЕсли;
```

Правильно:
```bsl
Если ТипДоговора = "Поставка" Тогда
    ОбработатьПоставку(Договор);
ИначеЕсли ТипДоговора = "Услуги" Тогда
    ОбработатьУслугу(Договор);
Иначе
    ВызватьИсключение "Неизвестный тип договора: " + ТипДоговора;
КонецЕсли;
```

## Источники

Для этой диагностики нет прямого нормативного стандарта 1С. Это локальное
правило защитного программирования, реализованное в `bsl-analyzer`.
