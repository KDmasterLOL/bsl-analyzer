# Несоответствие типов (TypeMismatch)

## Описание диагностики

Эта диагностика предназначена для случаев, когда выведенный тип выражения не совпадает с типом, который ожидает окружающий контекст.

Сейчас handler и metadata уже существуют, но live-emitter в type inference ещё отключён. Поэтому в текущем состоянии диагностика фактически не появляется в пользовательском коде.

После включения emitter-а ожидаемый сценарий использования — сообщения о передаче аргумента неподходящего типа, присваивании значения несовместимого типа или возврате значения, не соответствующего ожидаемому типу контекста.

## Примеры

Планируемый пример на будущее:

```bsl
Значение = 1;
Значение = "текст"; // несоответствие типов в более строгом контексте
```
