# Ограничение на количество параметров метода (NumberOfParams)

## Описание диагностики

Общее количество параметров процедуры или функции не должно превышать семи. Большое число аргументов снижает понятность кода и увеличивает вероятность ошибок при вызове. Когда методу необходимо передать много связанных значений, их следует группировать в структуру.

## Примеры

Неправильно:

```bsl
Процедура СоздатьДокумент(Дата, Номер, Контрагент, Договор, Склад, Ответственный, Организация, Комментарий)
КонецПроцедуры
```

Правильно:

```bsl
Процедура СоздатьДокумент(РеквизитыДокумента)
КонецПроцедуры
```
