# Ограничение на количество параметров метода (NumberOfParams)

## Описание диагностики

Диагностика выявляет процедуры и функции, в которых объявлено слишком много
параметров.

Общая логика правила опирается на рекомендации 1С по оформлению параметров
процедур и функций: слишком длинный список параметров ухудшает читаемость и
усложняет понимание вызова. Когда методу нужно передать много связанных
значений, обычно понятнее сгруппировать их в структуру или другой составной
параметр.

По умолчанию диагностика допускает не более `7` параметров, но порог можно
изменить через `maxParamsCount`.

## Примеры

Неправильно:

```bsl
Процедура СоздатьДокумент(Дата, Номер, Контрагент, Договор, Склад, Ответственный, Организация, Комментарий)
КонецПроцедуры
```

Правильно:

```bsl
Процедура СоздатьДокумент(РеквизитыДокумента)
КонецПроцедуры
```
