# Назначение псевдонимов выбранным полям в запросе (AssignAliasFieldsInQuery)

## Описание диагностики

Каждому полю в секции `ВЫБРАТЬ` запроса рекомендуется явно задавать псевдоним с помощью ключевого слова `КАК`. Это повышает читаемость текста запроса и делает прикладной код более устойчивым к изменениям метаданных.

Если псевдоним не задан, платформа формирует его автоматически на основе имени реквизита. При переименовании реквизита в конфигураторе автоматический псевдоним изменится, и весь код, обращающийся к результату запроса по старому имени, перестанет работать. Явный псевдоним изолирует прикладной код от таких изменений: потребуется скорректировать только текст запроса.

Особого внимания заслуживают составные выражения (например, `Касса.Валюта.Наименование`), поскольку автоматически сформированный псевдоним может оказаться неочевидным (`ВалютаНаименование` вместо ожидаемого `Наименование`).

Ключевое слово `КАК` перед псевдонимом обязательно. Поля из вторичных запросов в конструкции `ОБЪЕДИНИТЬ` диагностикой не проверяются.

## Примеры

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|   Товары.Наименование,                        // Неправильно: нет псевдонима
|   Товары.Наименование КАК НаименованиеТовара, // Правильно
|   Товары.Цена Цена                             // Неправильно: нет КАК перед псевдонимом
|ИЗ
|   Справочник.Товары КАК Товары                 // Игнорируется (источник)
|
|ОБЪЕДИНИТЬ ВСЕ
|
|ВЫБРАТЬ
|   Услуги.Наименование,                         // Игнорируется (вторичный запрос)
|   Услуги.Наименование,                         // Игнорируется
|   Услуги.Цена                                  // Игнорируется
|ИЗ
|   Справочник.Услуги КАК Услуги";               // Игнорируется
```
