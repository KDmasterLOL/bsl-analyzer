# Использование устаревшего метода "Найти" (DeprecatedFind)

## Описание диагностики

Глобальная функция `Найти()` признана устаревшей. Вместо неё следует применять `СтрНайти()`, которая обладает расширенными возможностями поиска (направление, начальная позиция, номер вхождения).

## Примеры

Неправильно:

```bsl
Позиция = Найти(НазваниеТовара, "Кабель");
```

Правильно:

```bsl
Позиция = СтрНайти(НазваниеТовара, "Кабель");
```
