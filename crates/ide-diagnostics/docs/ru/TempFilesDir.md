# Вызов функции КаталогВременныхФайлов() (TempFilesDir)

## Описание диагностики

Для работы с временными файлами следует использовать метод `ПолучитьИмяВременногоФайла()`. Платформа отслеживает файлы, созданные через этот метод, и автоматически удаляет их при перезапуске рабочего процесса сервера или клиентского приложения.

Если имя временного файла формируется иным способом (например, через `КаталогВременныхФайлов()`), платформа не контролирует такие файлы. При сбое или если код не удалил файл, он остаётся в файловой системе бессрочно. Накопление неудалённых временных файлов может стать серьёзной проблемой, особенно в системах с большим числом пользователей.

## Примеры

Неправильно — ручное формирование имени через `КаталогВременныхФайлов()`

```bsl
Каталог = КаталогВременныхФайлов();
ИмяФайла = Каталог + Строка(Новый УникальныйИдентификатор) + ".csv";
ТабДок.Записать(ИмяФайла);
```

Правильно — имя файла получено через `ПолучитьИмяВременногоФайла()`

```bsl
ИмяФайла = ПолучитьИмяВременногоФайла("csv");
ТабДок.Записать(ИмяФайла);
```

Для временных каталогов также рекомендуется формировать имя на основе `ПолучитьИмяВременногоФайла`.

Неправильно

```bsl
КаталогРаспаковки = КаталогВременныхФайлов() + "архив\";
СоздатьКаталог(КаталогРаспаковки);
```

Правильно

```bsl
КаталогРаспаковки = ПолучитьИмяВременногоФайла() + "\архив\";
СоздатьКаталог(КаталогРаспаковки);
```
