# Неиспользуемый локальный метод (UnusedLocalMethod)

## Описание диагностики

Модуль не должен содержать локальных процедур и функций, которые нигде не вызываются. Неиспользуемые методы засоряют код, усложняют навигацию и часто остаются после незавершённого рефакторинга.

Диагностика не ругается на методы, которые ожидаемо вызываются косвенно: экспортные методы, методы расширений, обработчики платформенных событий и подключаемые методы с настроенными префиксами.

В модулях форм метод также считается используемым, если строковый литерал в форме идентификатора в том же модуле совпадает с его именем. Динамическая привязка обработчиков — `УстановитьДействие`, созданная кодом команда с `Действие = "Имя"`, помощник из другого модуля, получающий структуру параметров, — всегда оставляет имя обработчика таким литералом. Обратная сторона: строковые *данные*, случайно совпавшие с именем метода, тоже снимают диагностику — реально мёртвый метод модуля формы, чьё имя встречается в постороннем литерале, отмечен не будет.
