# Неиспользуемый локальный метод (UnusedLocalMethod)

## Описание диагностики

Модуль не должен содержать процедур и функций, которые нигде не вызываются. Неиспользуемые методы засоряют код и затрудняют его сопровождение. Диагностика позволяет исключать подключаемые методы с определёнными префиксами через параметр настройки.
