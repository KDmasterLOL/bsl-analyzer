# Неиспользуемый локальный метод (UnusedLocalMethod)

## Описание диагностики

Модуль не должен содержать локальных процедур и функций, которые нигде не вызываются. Неиспользуемые методы засоряют код, усложняют навигацию и часто остаются после незавершённого рефакторинга.

Диагностика не ругается на методы, которые ожидаемо вызываются косвенно: экспортные методы, методы расширений, обработчики платформенных событий и подключаемые методы с настроенными префиксами.
