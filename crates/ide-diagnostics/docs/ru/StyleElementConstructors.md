# Конструктор элемента стиля (StyleElementConstructors)

## Описание диагностики

Для управления внешним видом элементов интерфейса следует использовать элементы стиля конфигурации, а не задавать значения цвета, шрифта или рамки непосредственно в коде. Это гарантирует единообразное оформление одинаковых элементов во всех формах и упрощает централизованное изменение внешнего вида.

Текущая реализация уже, чем общий стандарт по стилям. Диагностика ловит прямые конструкторы следующих типов:

* `Цвет` — значение в формате RGB
* `Шрифт` — гарнитура, размер и начертание
* `Рамка` — тип и толщина границ

Также она срабатывает на строковые формы вроде `Новый("Цвет", ...)` и на вложенные конструкторы внутри других `Новый(...)`.

## Примеры

Неправильно — цвет задан напрямую в коде

```bsl
Элемент.ЦветТекста = Новый Цвет(255, 0, 0);
```

Правильно — используется элемент стиля

```bsl
Элемент.ЦветТекста = ЭлементыСтиля.ЦветОшибки;
```
