# Диагностики

Используются для проверки кода на соответствие стандартам кодирования и для поиска возможных ошибок.

Некоторые диагностики выключены по умолчанию. Для их включения используйте
[конфигурационный файл](../../../../docs/configuration/DIAGNOSTICS.md).

Для подавления диагностик на отдельных строках, диапазонах или во всём файле
используйте директивы-комментарии в коде:

- `// bsl-analyzer:off Код1, Код2` … `// bsl-analyzer:on Код1` — подавить диапазон
  (`off` без парного `on` действует до конца файла; поставьте его на первую строку,
  чтобы заглушить весь файл);
- `// bsl-analyzer:disable-next-line Код1` — подавить следующую строку;
- `// bsl-analyzer:disable-line Код1` — подавить строку самой директивы (в конце строки).

Директива без указания кодов подавляет все диагностики в области. Опечатка в коде
вызывает `UnknownSuppressionCode`, директива без кода — `SuppressionWithoutCode`.

Директивы bsl-language-server (`// BSLLS:КлючДиагностики-выкл`/`-вкл`, `// BSLLS-выкл`/`-вкл`)
распознаются как алиасы по умолчанию, чтобы существующие комментарии проекта продолжали
работать; чтобы отключить их, задайте `bsllsSuppressionCompat = false` в конфигурации.
