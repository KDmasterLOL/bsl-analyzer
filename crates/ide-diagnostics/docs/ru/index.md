# Диагностики

Используются для проверки кода на соответствие стандартам кодирования и для поиска возможных ошибок.

Некоторые диагностики выключены по умолчанию. Для их включения используйте
[конфигурационный файл](../../../../docs/configuration/DIAGNOSTICS.md).

Для экранирования отдельных участков кода или файлов от срабатывания диагностик
можно использовать специальные комментарии вида
`// BSLLS:КлючДиагностики-выкл`.
