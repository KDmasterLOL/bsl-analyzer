# Отсутствует обработчик подписки на событие (MissingEventSubscriptionHandler)

## Описание диагностики

Каждая подписка на событие должна иметь корректно указанный обработчик. Если обработчик не задан или ссылается на несуществующий метод, при работе приложения возникнет ошибка времени выполнения.

Текущая реализация проверяет:

- что обработчик не пустой;
- что в строке обработчика есть имя метода;
- что общий модуль существует;
- что общий модуль серверный;
- что метод существует;
- что метод помечен `Экспорт`.

**Внимание:** замечания диагностики прикрепляются к модулю сеанса, потому что источник проблемы находится в метаданных подписок, а не в конкретной строке BSL-кода.

## Примеры

Неправильно:

```bsl
// Подписка на событие "ПриЗаписиДокумента" указывает на метод
// ОбщийМодуль.ОбработчикиСобытий.ПриЗаписиДокумента,
// но такой метод в модуле не определён.
```

Правильно:

```bsl
// В общем модуле ОбработчикиСобытий определён экспортный метод:
Процедура ПриЗаписиДокумента(Источник, Отказ) Экспорт
    // Логика обработки
КонецПроцедуры
```
