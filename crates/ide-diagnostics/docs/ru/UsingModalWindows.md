# Использование модальных окон (UsingModalWindows)

## Описание диагностики

Модальные окна и диалоги не рекомендуется использовать при разработке конфигураций, предназначенных для веб-клиента. Модальные окна не входят в стандарт веб-разработки, и ряд браузеров блокирует их отображение. В результате конфигурация может оказаться неработоспособной. Современный подход предполагает работу пользователя в едином окне приложения.

### Ограничения диагностики

В текущей реализации проверяются **только вызовы методов глобального контекста**.

Список методов:

|Метод|Английский вариант|
| :-- | :-- |
|ВОПРОС|DOQUERYBOX|
|ОТКРЫТЬФОРМУМОДАЛЬНО|OPENFORMMODAL|
|ОТКРЫТЬЗНАЧЕНИЕ|OPENVALUE|
|ПРЕДУПРЕЖДЕНИЕ|DOMESSAGEBOX|
|ВВЕСТИДАТУ|INPUTDATE|
|ВВЕСТИЗНАЧЕНИЕ|INPUTVALUE|
|ВВЕСТИСТРОКУ|INPUTSTRING|
|ВВЕСТИЧИСЛО|INPUTNUMBER|
|УСТАНОВИТЬВНЕШНЮЮКОМПОНЕНТУ|INSTALLADDIN|
|УСТАНОВИТЬРАСШИРЕНИЕРАБОТЫСФАЙЛАМИ|INSTALLFILESYSTEMEXTENSION|
|УСТАНОВИТЬРАСШИРЕНИЕРАБОТЫСКРИПТОГРАФИЕЙ|INSTALLCRYPTOEXTENSION|
|ПОМЕСТИТЬФАЙЛ|PUTFILE|

## Примеры

### Неправильно

```bsl
Предупреждение("Операция завершена успешно");
```

### Правильно

```bsl
ПоказатьПредупреждение(, "Операция завершена успешно");
```
