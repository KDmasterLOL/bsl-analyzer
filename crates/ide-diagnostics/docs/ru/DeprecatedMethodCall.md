# Устаревшие методы не должны использоваться (DeprecatedMethodCall)

## Описание диагностики

Процедуры и функции, в первой строке описания которых указано слово "Устарела." (англ. "Deprecated."), помечены для последующего удаления. Такие методы сохраняются временно для обратной совместимости и будут исключены из будущих версий конфигурации.

Вызов устаревших методов из актуального кода недопустим. Необходимо использовать рекомендованные замены, указанные в описании устаревшего метода.

Исключение: вызов устаревшего метода из другого устаревшего метода допустим.

## Примеры

```bsl
// Устарела. Используйте ПолучитьОстатокНовый.
Функция ПолучитьОстаток(Номенклатура) Экспорт
    Возврат 0;
КонецФункции

// Вызов из актуального кода -- срабатывание диагностики
Остаток = ПолучитьОстаток(ТекНоменклатура);

// Правильно: использовать новый метод
Остаток = ПолучитьОстатокНовый(ТекНоменклатура);
```
