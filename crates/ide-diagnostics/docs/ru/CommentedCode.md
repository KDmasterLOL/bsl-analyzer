# Закомментированный фрагмент кода (CommentedCode)

## Описание диагностики

В программных модулях не должно оставаться закомментированных фрагментов кода. Такие фрагменты обычно появляются в процессе отладки или рефакторинга и представляют собой технический мусор, затрудняющий чтение и сопровождение. Также недопустимы служебные пометки, связанные с конкретными разработчиками или процессом разработки (например, `!!!`, `MRG`, именные комментарии).

Блок комментариев считается кодом, если хотя бы одна строка в нём распознаётся как инструкция встроенного языка.

## Примеры

### Неправильно

```bsl
Процедура ПриОткрытии()
//    Если ПроверитьЗаполнение() Тогда
//        ЗаполнитьДанные();
//    КонецЕсли;
КонецПроцедуры
```

Также неправильно:

```bsl
Процедура ОбработатьДанные()
    Если Истина Тогда
        // Петров: потом переделать
    КонецЕсли;
КонецПроцедуры
```

### Правильно

Закомментированный код и временные пометки следует удалить перед фиксацией изменений. Если код может понадобиться в будущем, его сохраняет система контроля версий.
