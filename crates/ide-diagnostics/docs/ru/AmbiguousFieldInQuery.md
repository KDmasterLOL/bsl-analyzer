# Неоднозначное поле в запросе (AmbiguousFieldInQuery)

## Описание диагностики

Диагностика сообщает о поле, указанном без имени источника, когда такое поле есть более чем в одной таблице запроса. Платформа отклоняет такой запрос: она не может выбрать источник за автора.

Проверка срабатывает только тогда, когда поле доказуемо есть в нескольких источниках. Если хотя бы у одного из них модель полей неполна (виртуальная таблица, временная таблица, подзапрос), неоднозначность не утверждается.

## Примеры

Поле `Наименование` есть в обеих таблицах соединения:
```sdbl
ВЫБРАТЬ
	Наименование КАК Значение
ИЗ
	Справочник.Товары КАК Товары
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Склады КАК Склады
		ПО Товары.Ссылка = Склады.Владелец
```

Исправление — указать источник явно:
```sdbl
ВЫБРАТЬ
	Товары.Наименование КАК Значение
ИЗ
	Справочник.Товары КАК Товары
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Склады КАК Склады
		ПО Товары.Ссылка = Склады.Владелец
```

## Голова квалифицированной ссылки

Отдельный вид той же неоднозначности: `Имя.Поле`, где `Имя` — одновременно псевдоним источника и имя поля, предлагаемого источником того же уровня запроса. Платформа отклоняет такой запрос, и исправление здесь другое — переименовать источник, а не дописать квалификатор, потому что квалификатор уже есть и он же и мешает.

Правило именное и разрешается до типов: совпадение с обычным реквизитом строкового типа даёт ту же ошибку, что и совпадение с именем табличной части. Объявить такой псевдоним можно — нельзя по нему обращаться. Одного источника достаточно: псевдоним может столкнуться с полем собственной таблицы. Уровни не смешиваются — то же совпадение внутри подзапроса допустимо.

```sdbl
ВЫБРАТЬ
	Заказ.Ссылка КАК Значение
ИЗ
	Документ.ЗаказКлиента КАК Заказ
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ЗаказКлиента.Товары КАК Товары
		ПО Заказ.Ссылка = Товары.Ссылка
```

Здесь `Товары` — и псевдоним присоединённой табличной части, и поле документа `Заказ`. Исправление — дать источнику другое имя:

```sdbl
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ЗаказКлиента.Товары КАК СтрокиТоваров
		ПО Заказ.Ссылка = СтрокиТоваров.Ссылка
```
