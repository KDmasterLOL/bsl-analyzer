# Когнитивная сложность (CognitiveComplexity)

## Описание диагностики

Когнитивная сложность -- метрика, оценивающая трудность восприятия кода человеком. Чем выше значение, тем сложнее понять логику метода при чтении. Превышение порогового значения сигнализирует о необходимости рефакторинга: разбиения метода на более мелкие части, упрощения условных выражений, снижения уровня вложенности.

### Правила подсчёта

#### Каждый следующий блок увеличивает сложность на 1

```bsl

// Цикл Для каждого
Для каждого Элемент Из Массив Цикл                     // +1
КонецЦикла;

// Цикл Для
Для Сч = 0 По Максимум Цикл                            // +1
КонецЦикла;

// Цикл Пока
Пока Остаток > 0 Цикл                                  // +1
КонецЦикла;

// Условие
Если Флаг Тогда                                        // +1

// Альтернативная ветвь
ИначеЕсли ДругойФлаг Тогда                             // +1

// Ветвь по умолчанию
Иначе
КонецЕсли;

// Тернарный оператор
Итог = ?(Условие, ЗначениеА, ЗначениеБ);              // +1

Попытка
// Обработка исключения
Исключение                                             // +1
КонецПопытки;

// Переход на метку
Перейти ~Метка;                                        // +1

// Бинарные логические операции
Пока А ИЛИ Б Цикл                                     // +2
КонецЦикла;

Если Х И У Тогда                                       // +2

ИначеЕсли Условие1                                     // +1
        ИЛИ Условие2 И Условие3 Тогда                  // +2

КонецЕсли;

Итог = ?(Р ИЛИ К ИЛИ НЕ М,                            // +3
            ЗначениеА, ЗначениеБ);

Итог = Первое ИЛИ Второе;                              // +1

Итог = Х <> У;                                         // +1

```

#### За каждый уровень вложенности следующие блоки получают дополнительную единицу сложности

```bsl

// Цикл Для каждого
Для каждого Элемент Из Массив Цикл
КонецЦикла;

// Цикл Для
Для Сч = 0 По Максимум Цикл
КонецЦикла;

// Цикл Пока
Пока Остаток > 0 Цикл
КонецЦикла;

// Условие
Если Флаг Тогда
КонецЕсли;

// Тернарный оператор
Итог = ?(Условие, ЗначениеА, ЗначениеБ);

Попытка
// Обработка исключения
Исключение
КонецПопытки;

~Метка:

```

#### Альтернативные ветки, бинарные операции и переход на метку не увеличивают когнитивную сложность при вложении

## Примеры

Ниже приведён расчёт когнитивной сложности на примерах.

```bsl
Функция ПоискЭлемента(Коллекция)
    Если Коллекция.Пустая() Тогда                                         // +1, условие, вложенность 0
        Возврат Неопределено;
    КонецЕсли;

    Найден = Ложь;
    Список = Коллекция.ПолучитьЭлементы();
    Для Каждого Элемент Из Список Цикл                                    // +1, цикл, вложенность 0
        Если Элемент.Подходит()                                           // +2, условие, вложенность 1
            И НЕ Элемент.Исключён() Тогда                                // +1, логическая операция

            Если МожноОбработать(Элемент) Тогда                          // +3, условие, вложенность 2
                Статус = ПроверитьСтатус(Элемент, Коллекция);
                Если Статус = Неопределено Тогда                         // +4, условие, вложенность 3
                    Если НЕ Найден Тогда                                 // +5, условие, вложенность 4
                        Найден = Истина;
                    КонецЕсли;
                ИначеЕсли Статус Тогда                                   // +1, альтернативная ветвь
                    Возврат Элемент;
                КонецЕсли;
            Иначе                                                        // +1, ветвь по умолчанию
                Продолжить;
            КонецЕсли;
        КонецЕсли;
    КонецЦикла;

    Если Найден Тогда                                                    // +1, вложенность 0
        Возврат Коллекция.ЭлементПоУмолчанию();
    КонецЕсли;

    Возврат Неопределено;
КонецФункции

```

```bsl
Функция ОбработатьДокумент(Ссылка)
    НачатьТранзакцию();
    Провести = ?(Ссылка.Проведен, Ложь,                                                       // +1, тернарный оператор
                                  ?(Ссылка.ПометкаУдаления, Ложь, Истина));                    // +2, вложенный тернарный, вложенность 1
    Попытка                                                                                    // +0, повышает вложенность
        Объект = Ссылка.ПолучитьОбъект();
        Если Объект.Проведен Тогда                                                             // +2, условие, вложенность 1
            Для Каждого Строка Из Объект.Товары Цикл                                           // +3, цикл, вложенность 2
                Если Строка.Количество = 0                                                     // +4, условие, вложенность 3
                        ИЛИ Строка.Цена = 0 Тогда                                             // +1, логическая операция
                    Продолжить;
                КонецЕсли;
                Если Строка.Сумма > 1000 Тогда                                                 // +4, условие, вложенность 3
                    Прервать;
                Иначе                                                                          // +1, ветвь по умолчанию
                    Если Строка.Количество + Строка.Цена = 2 Тогда                             // +5, условие, вложенность 4
                        Строка.Итого = Строка.Количество * 2;
                    КонецЕсли;
                КонецЕсли;
            КонецЦикла;
        Иначе                                                                                  // +1, ветвь по умолчанию
            Провести = Объект.Дата > ТекущаяДата();                                            // +1, логическая операция
            Перейти ~Метка;                                                                    // +1, переход на метку
        КонецЕсли;

        Если Провести Тогда                                                                    // +2, условие, вложенность 1
            Объект.Записать(РежимЗаписиДокумента.Проведение);
        ИначеЕсли НЕ Провести Тогда                                                            // +1, альтернативная ветвь
            Объект.Записать(РежимЗаписиДокумента.Запись);
        Иначе                                                                                  // +1, ветвь по умолчанию
            ВызватьИсключение "Непредвиденная ситуация";
        КонецЕсли;
    Исключение                                                                                 // +1, обработка исключения
        ПовторнаяЗапись = Ложь;
        Попытка                                                                                // +0, повышает вложенность
            Если Объект.Проведен Тогда                                                         // +3, условие, вложенность 2
                Объект.Записать(РежимЗаписиДокумента.Запись);
            КонецЕсли;
        Исключение                                                                             // +2, обработка исключения, вложенность 1
            ПовторнаяЗапись = Истина;
        КонецПопытки;
        Если Не ПовторнаяЗапись Тогда                                                          // +2, условие, вложенность 1
            Пока ТранзакцияАктивна() Цикл                                                     // +3, цикл, вложенность 2
                ОтменитьТранзакцию();
            КонецЦикла;
        КонецЕсли;
        ВызватьИсключение "Ошибка записи"
    КонецПопытки;

    ~Метка:
    Возврат Неопределено;
КонецФункции

```
