# Когнитивная сложность (CognitiveComplexity)

## Описание диагностики

Диагностика показывает процедуры и функции, у которых когнитивная сложность
превышает настроенный порог.

Когнитивная сложность оценивает, насколько тяжело читать и удерживать в голове
логику метода. Рост вложенности, большое количество ветвлений и составные
логические условия делают код заметно менее понятным и повышают стоимость
доработок.

## Как растет метрика

Реализация следует публичной спецификации SonarSource.

- Структурные конструкции вроде `Если`, циклов, `Исключение` и тернарного
  оператора увеличивают сложность.
- Каждый новый уровень вложенности добавляет дополнительный штраф.
- `ИначеЕсли`, `Иначе`, `Перейти`, а также логические `И` и `ИЛИ` тоже
  увеличивают значение, но без полного штрафа за вложенность.

## Как уменьшить сложность

- выносить вложенные блоки в небольшие функции с говорящими именами;
- использовать guard clauses вместо глубокой лесенки `Если`;
- упрощать составные условия, если они смешивают несколько независимых правил;
- убирать дублирование ветвей в общие вспомогательные процедуры.

## Пример

```bsl
Функция ПодготовитьДанные(Данные)
    Если Данные = Неопределено Тогда
        Возврат Неопределено;
    КонецЕсли;

    Для Каждого Элемент Из Данные Цикл
        Если Элемент.Актуален Тогда
            Если Элемент.НужнаПроверка Тогда
                Если Элемент.Значение > 0 Тогда
                    Возврат Элемент;
                КонецЕсли;
            КонецЕсли;
        КонецЕсли;
    КонецЦикла;

    Возврат Неопределено;
КонецФункции
```
