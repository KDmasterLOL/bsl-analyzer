# Серверные вызовы в событиях форм (ServerCallsInFormEvents)

## Описание диагностики

В обработчиках событий `ПриАктивизацииСтроки` и `НачалоВыбора` недопустимо вызывать серверные методы формы. Эти события предназначены для выполнения исключительно на клиенте. Серверные вызовы из них приводят к проблемам с производительностью и могут нарушать корректную работу формы.

Диагностика фиксирует только вызовы серверных методов текущей формы. Обращения к методам внешних серверных модулей (например, `МойСерверныйМодуль.МетодНаСервере()`) ошибкой не считаются.

## Примеры

### Неправильно

```bsl
&НаКлиенте
Процедура СписокПриАктивизацииСтроки(Элемент)
    ОбновитьДанныеНаСервере();
КонецПроцедуры

&НаСервере
Процедура ОбновитьДанныеНаСервере()
    // серверная логика
КонецПроцедуры
```

### Правильно

```bsl
&НаКлиенте
Процедура СписокПриАктивизацииСтроки(Элемент)
    ТекущиеДанные = Элемент.ТекущиеДанные;
    Если ТекущиеДанные = Неопределено Тогда
        Возврат;
    КонецЕсли;
    // только клиентская обработка
КонецПроцедуры
```
