# Серверные вызовы в событиях форм (ServerCallsInFormEvents)

## Описание диагностики

События формы `ПриАктивизацииСтроки` и `НачалоВыбора` срабатывают прямо во время активного взаимодействия пользователя с интерфейсом. Серверные вызовы из таких обработчиков увеличивают сетевой трафик и могут заметно замедлять работу формы.

Текущая реализация анализирует цепочки вызовов, начинающиеся из этих обработчиков, и сообщает:

- о локальных методах формы, которые в итоге переключаются на серверное выполнение с контекстом;
- о квалифицированных вызовах общих модулей, если целевой экспортный метод сразу является серверным.

Если путь до серверного вызова проходит через `ПодключитьОбработчикОжидания`, замечание понижается до информационного уровня.

## Примеры

Неправильно:

```bsl
&НаКлиенте
Процедура СписокПриАктивизацииСтроки(Элемент)
    ОбновитьДанныеНаСервере();
КонецПроцедуры

&НаСервере
Процедура ОбновитьДанныеНаСервере()
    // серверная логика
КонецПроцедуры
```

Правильно:

```bsl
&НаКлиенте
Процедура СписокПриАктивизацииСтроки(Элемент)
    ТекущиеДанные = Элемент.ТекущиеДанные;
    Если ТекущиеДанные = Неопределено Тогда
        Возврат;
    КонецЕсли;
    // только клиентская обработка
КонецПроцедуры
```
