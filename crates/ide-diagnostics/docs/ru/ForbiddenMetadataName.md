# Объекту метаданных присвоено запрещенное имя (ForbiddenMetadataName)

## Описание диагностики

Имена объектов метаданных, их реквизитов и табличных частей не должны совпадать с зарезервированными словами, используемыми в синтаксисе запросов (например, `Документ`, `Справочник`, `Документы`, `Регистр`). Такие совпадения вызывают ошибки при выполнении запросов, делают невозможной работу конструктора запросов и существенно снижают наглядность текста запроса.

Диагностика также распространяется на измерения, ресурсы и другие подчинённые элементы, если их имя попадает в список запрещённых.

## Примеры

### Запрещённые имена

- `Справочник.Справочник` -- имя справочника совпадает с ключевым словом
- `Справочник.Товары.Реквизит.Документ` -- реквизит носит зарезервированное имя
- `РегистрСведений.Настройки.Измерение.Регистр` -- измерение названо зарезервированным словом

### Допустимые имена

- `Справочник.ВидыНоменклатуры`
- `Справочник.Товары.Реквизит.ДокументОснование`
- `РегистрСведений.Настройки.Измерение.ВидРегистра`
