# Некорректное использование 'ПОДОБНО' (IncorrectUseLikeInQuery)

## Описание диагностики

Согласно стандарту `#std726`, в операторе `ПОДОБНО` языка запросов в качестве
шаблона допускается использовать только:

- константный строковый литерал;
- параметр запроса.

Формировать шаблон вычислениями, конкатенацией строк или использовать поле
таблицы в качестве шаблона нельзя.

Причина ограничения: запросы с вычисляемыми шаблонами `ПОДОБНО` могут
интерпретироваться по-разному на различных СУБД, что приводит к
непредсказуемым результатам.

## Примеры

### Конкатенация строк в шаблоне

Допустимо:
```sdbl
Наименование ПОДОБНО "Товар%"
```

```sdbl
Наименование ПОДОБНО &Шаблон
```

Недопустимо:
```sdbl
Наименование ПОДОБНО "Товар" + "%"
Наименование ПОДОБНО &Шаблон + "%"
Наименование ПОДОБНО Таблица.ПолеШаблон
```

Если нужно добавить спецсимволы шаблона, их следует подготовить до передачи
параметра.

Неправильно:
```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Контрагенты.Ссылка
|ИЗ
|    Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|    Контрагенты.ИНН ПОДОБНО &ШаблонИНН + "_"
|");

Запрос.УстановитьПараметр("ШаблонИНН", "77");
```

Правильно:
```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Контрагенты.Ссылка
|ИЗ
|    Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|    Контрагенты.ИНН ПОДОБНО &ШаблонИНН
|");

Запрос.УстановитьПараметр("ШаблонИНН", "77_");
```
