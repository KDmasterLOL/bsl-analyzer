# Некорректное использование 'ПОДОБНО' (IncorrectUseLikeInQuery)

## Описание диагностики

В операторе `ПОДОБНО` языка запросов допускается использовать только константные строковые литералы или параметры запроса в качестве шаблона. Формирование шаблона через конкатенацию строк или использование полей таблиц в качестве шаблона запрещено.

Причина ограничения: запросы с вычисляемыми шаблонами `ПОДОБНО` интерпретируются по-разному на различных СУБД (MS SQL и PostgreSQL), что приводит к непредсказуемым результатам.

## Примеры

### Конкатенация строк в шаблоне

Допустимо:
```
Наименование ПОДОБНО "Товар%"
```

Недопустимо:
```
Наименование ПОДОБНО "Товар" + "%"
Наименование ПОДОБНО Таблица.ПолеШаблон
```

### Управляющие символы в вычисляемых выражениях

Неправильно:
```
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Контрагенты.Ссылка
|ИЗ
|    Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|    Контрагенты.ИНН ПОДОБНО &ШаблонИНН + "_"
|");

Запрос.УстановитьПараметр("ШаблонИНН", "77");
```

Правильно:
```
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Контрагенты.Ссылка
|ИЗ
|    Справочник.Контрагенты КАК Контрагенты
|ГДЕ
|    Контрагенты.ИНН ПОДОБНО &ШаблонИНН
|");

Запрос.УстановитьПараметр("ШаблонИНН", "77_");
```
