# Использование логического "ИЛИ" в секции "ГДЕ" запроса (LogicalOrInTheWhereSectionOfQuery)

## Описание диагностики

Применение оператора `ИЛИ` в секции `ГДЕ` может помешать СУБД использовать индексы таблиц. Вместо индексированного поиска будет выполнено полное сканирование, что увеличивает время выполнения запроса и повышает вероятность блокировок. Рекомендуется разделить запрос на несколько частей и объединить результаты через `ОБЪЕДИНИТЬ ВСЕ`.

> **Важно** -- текущая реализация диагностики реагирует на любое вхождение `ИЛИ` в секции `ГДЕ` и может давать ложноположительные срабатывания в отдельных случаях.

## Примеры

Неправильно:

```bsl
ВЫБРАТЬ Номенклатура.Наименование ИЗ Справочник.Номенклатура КАК Номенклатура
ГДЕ Номенклатура.Артикул = "А01" ИЛИ Номенклатура.Цена = 500
```

Правильно -- разбиение через `ОБЪЕДИНИТЬ ВСЕ`:

```bsl
ВЫБРАТЬ Номенклатура.Наименование ИЗ Справочник.Номенклатура КАК Номенклатура
ГДЕ Номенклатура.Артикул = "А01"
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ Номенклатура.Наименование ИЗ Справочник.Номенклатура КАК Номенклатура
ГДЕ Номенклатура.Цена = 500
```

1) Допустимо использовать `ИЛИ` для вариантов одного поля, так как СУБД преобразует это в оператор `В`:

Правильно:

```bsl
ГДЕ
    Таблица.Статус = &Статус1
    ИЛИ Таблица.Статус = &Статус2
```

Эквивалент:

```bsl
ГДЕ
    Таблица.Статус В (&СписокСтатусов)
```

Неправильно -- `ИЛИ` по разным полям:

```bsl
ГДЕ
    Таблица.Склад = &Склад
    ИЛИ Таблица.Организация = &Организация
```

Следует переписать через `ОБЪЕДИНИТЬ ВСЕ` (при условии индексирования обоих полей):

```bsl
ГДЕ
    Таблица.Склад = &Склад

ОБЪЕДИНИТЬ ВСЕ

ГДЕ
    Таблица.Организация = &Организация
```

> Примечание: замена `ИЛИ` на `ОБЪЕДИНИТЬ ВСЕ` допустима не всегда. Необходимо убедиться, что результат запроса останется корректным.

2) В дополнительном условии `ИЛИ` можно применять без ограничений:

Правильно:

```bsl
ГДЕ
    Таблица.Склад = &Склад
    И (Таблица.Количество > 0 ИЛИ Таблица.Резерв > 0)
```

Правильно:

```bsl
ГДЕ
    (Таблица.Статус = &Статус1 ИЛИ Таблица.Статус = &Статус2)
    И (Таблица.Тип = &Тип1 ИЛИ Таблица.Тип = &Тип2)
```

Эквивалент:

```bsl
ГДЕ
    Таблица.Статус В (&Статусы)
    И Таблица.Тип В (&Типы)
```
