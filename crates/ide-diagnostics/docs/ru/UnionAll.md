# Использование ключевого слова "ОБЪЕДИНИТЬ" в запросах (UnionAll)

## Описание диагностики

При объединении результатов нескольких запросов следует применять `ОБЪЕДИНИТЬ ВСЕ` вместо `ОБЪЕДИНИТЬ`. Конструкция без `ВСЕ` удаляет дублирующиеся строки из результата, что требует дополнительных вычислительных ресурсов. В подавляющем большинстве случаев устранение дубликатов не требуется, а производительность запроса снижается.

Использование `ОБЪЕДИНИТЬ` допустимо только тогда, когда удаление повторяющихся строк является необходимым условием корректной работы запроса.

Текущая реализация диагностики консервативна: она сообщает о каждом использовании `ОБЪЕДИНИТЬ` / `UNION` без `ВСЕ` / `ALL`.

## Примеры

Неправильно:

```bsl
ВЫБРАТЬ Товары.Наименование ИЗ Справочник.Товары КАК Товары

ОБЪЕДИНИТЬ

ВЫБРАТЬ Услуги.Наименование ИЗ Справочник.Услуги КАК Услуги
```

Правильно:

```bsl
ВЫБРАТЬ Товары.Наименование ИЗ Справочник.Товары КАК Товары

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ Услуги.Наименование ИЗ Справочник.Услуги КАК Услуги
```
