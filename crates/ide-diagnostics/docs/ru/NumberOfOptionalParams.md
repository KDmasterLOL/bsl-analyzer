# Ограничение на количество необязательных параметров метода (NumberOfOptionalParams)

## Описание диагностики

Диагностика выявляет процедуры и функции, в которых объявлено слишком много
необязательных параметров.

Общая логика правила опирается на рекомендации 1С по оформлению параметров
процедур и функций: большое количество необязательных аргументов ухудшает
читаемость вызова и повышает риск ошибки. На практике становится трудно понять,
какие значения передаются осознанно, а какие просто пропускаются через позиции
со значениями по умолчанию.

По умолчанию диагностика допускает не более `3` необязательных параметров, но
порог можно изменить через `maxOptionalParamsCount`.

## Примеры

Неправильно:

```bsl
Функция ПолучитьОтчет(Период, Организация, Склад = Неопределено, Менеджер = Неопределено, Валюта = Неопределено, ТолькоАктивные = Истина)
КонецФункции
```

Правильно:

```bsl
Функция ПолучитьОтчет(Период, Организация, ДополнительныеПараметры = Неопределено)
КонецФункции
```
