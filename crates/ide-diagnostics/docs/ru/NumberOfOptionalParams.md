# Ограничение на количество не обязательных параметров метода (NumberOfOptionalParams)

## Описание диагностики

Количество необязательных параметров (параметров со значениями по умолчанию) в процедуре или функции не должно превышать трёх. Избыточное число таких параметров ухудшает читаемость вызывающего кода: легко допустить ошибку при подсчёте запятых-разделителей. Если методу требуется передать много значений, рекомендуется объединять их в структуру.

## Примеры

Неправильно:

```bsl
Функция ПолучитьОтчет(Период, Организация, Склад = Неопределено, Менеджер = Неопределено, Валюта = Неопределено, ТолькоАктивные = Истина)
КонецФункции
```

Правильно:

```bsl
Функция ПолучитьОтчет(Период, Организация, ДополнительныеПараметры = Неопределено)
КонецФункции
```
