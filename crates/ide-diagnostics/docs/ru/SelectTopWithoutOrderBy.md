# Использование 'ВЫБРАТЬ ПЕРВЫЕ' без 'УПОРЯДОЧИТЬ ПО' (SelectTopWithoutOrderBy)

## Описание диагностики

Конструкция `ПЕРВЫЕ N` без явного `УПОРЯДОЧИТЬ ПО` может приводить к недетерминированному результату. Порядок строк способен различаться между СУБД, версиями платформы и разными экземплярами одной и той же базы.

Текущая реализация диагностики фиксирует следующие случаи:

- `ПЕРВЫЕ N` внутри `ОБЪЕДИНИТЬ` — сортировка в отдельных частях объединения невозможна, поэтому это всегда ошибка
- `ПЕРВЫЕ N` (N > 1) без `УПОРЯДОЧИТЬ ПО`
- `ПЕРВЫЕ 1` без `УПОРЯДОЧИТЬ ПО` и без условий `ГДЕ` (по умолчанию отключено в настройках)

## Примеры

Неправильно:

```bsl
ВЫБРАТЬ ПЕРВЫЕ 10
   Контрагенты.Ссылка
ИЗ
   Справочник.Контрагенты КАК Контрагенты
```

Правильно:

```bsl
ВЫБРАТЬ ПЕРВЫЕ 10
   Контрагенты.Ссылка
ИЗ
   Справочник.Контрагенты КАК Контрагенты
УПОРЯДОЧИТЬ ПО
   Контрагенты.Код
```
