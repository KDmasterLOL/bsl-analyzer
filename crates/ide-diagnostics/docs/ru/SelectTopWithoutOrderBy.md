# Использование 'ВЫБРАТЬ ПЕРВЫЕ' без 'УПОРЯДОЧИТЬ ПО' (SelectTopWithoutOrderBy)

## Описание диагностики

Конструкция `ПЕРВЫЕ N` без явного указания порядка сортировки (`УПОРЯДОЧИТЬ ПО`) или условий отбора (`ГДЕ`) приводит к недетерминированному результату. Порядок записей может различаться в зависимости от используемой СУБД и конкретной копии информационной базы.

Отсутствие `УПОРЯДОЧИТЬ ПО` допускается только когда:

- Логика обработки не зависит от порядка записей
- Результат не выводится пользователю
- Запрос гарантированно возвращает единственную запись

В остальных случаях сортировка обязательна.

### Логика срабатывания

Диагностика фиксирует следующие случаи:

- `ПЕРВЫЕ N` внутри `ОБЪЕДИНИТЬ` — сортировка в отдельных частях объединения невозможна, поэтому это всегда ошибка
- `ПЕРВЫЕ N` (N > 1) без `УПОРЯДОЧИТЬ ПО`
- `ПЕРВЫЕ 1` без `УПОРЯДОЧИТЬ ПО` и без условий `ГДЕ` (по умолчанию отключено в настройках)

## Примеры

```bsl
ВЫБРАТЬ ПЕРВЫЕ 1
   Контрагенты.Ссылка
ИЗ
   Справочник.Контрагенты КАК Контрагенты
ГДЕ
   Контрагенты.ИНН = "7707083893"

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ ПЕРВЫЕ 5
   Организации.Ссылка
ИЗ
   Справочник.Организации КАК Организации

УПОРЯДОЧИТЬ ПО
   Ссылка
```

В этом примере:
- Первый `ПЕРВЫЕ 1` — допустимо, есть условие `ГДЕ`
- Второй `ПЕРВЫЕ 5` в `ОБЪЕДИНИТЬ` — ошибка, `УПОРЯДОЧИТЬ ПО` применяется ко всему объединению, а не к отдельной его части
