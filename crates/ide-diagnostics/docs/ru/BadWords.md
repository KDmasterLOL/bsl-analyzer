# Запрещённые слова (BadWords)

## Описание диагностики

Диагностика обнаруживает в тексте модулей слова и выражения, запрещённые политикой проекта. Перечень нежелательных слов задаётся регулярным выражением в параметрах диагностики. Проверка выполняется без учёта регистра символов.

**Примеры настройки:**

"нецензурное|жаргон|оскорбление"

"недопустим(ый|ое|ая)"
