# Запрещённые слова (BadWords)

## Описание диагностики

Диагностика ищет в тексте модулей слова и выражения, запрещённые политикой
проекта.

Список нежелательных слов задаётся регулярным выражением в параметрах
диагностики. Поиск выполняется без учёта регистра. При необходимости можно
включать или отключать проверку комментариев.

Такая проверка полезна, когда команда хочет:

- не допускать жаргон, оскорбительные или токсичные слова в коде;
- запрещать временные маркеры вроде `legacy`, `draft`, `temporary`;
- закреплять внутренние требования к терминологии.

**Примеры настройки:**

`"legacy|draft|temporary"`

`"deprecated_|tmp_|unsafe"`
