# Поле неограниченной длины в недопустимой позиции запроса (UnlimitedLengthStringUsageInQuery)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Поля, объявленные как строка неограниченной длины (`Строка(0)`, квалификатор
«неограниченная длина»), нельзя использовать в большинстве операций языка
запросов. Платформа 1С:Предприятие завершает такой запрос ошибкой исполнения:

```
Неверные параметры в операции сравнения.
Нельзя сравнивать поля неограниченной длины и поля несовместимых типов.
```

Диагностика сообщает об использовании полей неограниченной длины:

- в операциях сравнения (`=`, `<>`, `<`, `<=`, `>`, `>=`) в секциях `ГДЕ`,
  `ИМЕЮЩИЕ` и в условиях соединений (`СОЕДИНЕНИЕ ... ПО`);
- в операторах `В` и `МЕЖДУ`;
- в предложении `СГРУППИРОВАТЬ ПО`;
- в предложении `УПОРЯДОЧИТЬ ПО`;
- в выборке `ВЫБРАТЬ РАЗЛИЧНЫЕ`;
- в предложении `ИТОГИ ... ПО`.

Чтобы использовать такое поле в перечисленных позициях, приведите его к строке
ограниченной длины: `ВЫРАЗИТЬ(... КАК СТРОКА(N))`. Оператор `ПОДОБНО` и
проверка `ЕСТЬ NULL` платформой разрешены и диагностикой не отмечаются.

## Примеры
Диагностика сработает:

```bsl
ВЫБРАТЬ Лог.Ссылка
ИЗ Справочник.ЖурналЗапросов КАК Лог
ГДЕ Лог.ПредложеноAI <> ""
```

Исправленный вариант:

```bsl
ВЫБРАТЬ Лог.Ссылка
ИЗ Справочник.ЖурналЗапросов КАК Лог
ГДЕ ВЫРАЗИТЬ(Лог.ПредложеноAI КАК СТРОКА(1000)) <> ""
```
