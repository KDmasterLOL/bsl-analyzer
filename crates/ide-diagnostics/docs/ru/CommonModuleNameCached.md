# Пропущен постфикс "ПовтИсп" (CommonModuleNameCached)

## Описание диагностики

Общие модули с включённым повторным использованием возвращаемых значений (на время вызова или на время сеанса) должны содержать в имени постфикс `ПовтИсп` (англ. `Cached`). Для клиентских модулей с кешированием используется постфикс `КлиентПовтИсп` (англ. `ClientCached`). Постфикс позволяет сразу определить, что вызов функции этого модуля может вернуть кешированный результат, а не выполнить код заново.

## Примеры

Допустимые имена: `ПараметрыСеансаПовтИсп`, `РаботаСФайламиКлиентПовтИсп`, `UsersInternalCached`

Недопустимые имена: `ПараметрыСеанса`, `РаботаСФайламиКлиент` (при включённом повторном использовании)
