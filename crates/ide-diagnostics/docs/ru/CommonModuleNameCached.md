# Пропущен постфикс "ПовтИсп" (CommonModuleNameCached)

## Описание диагностики

Общие модули с включенным повторным использованием возвращаемых значений
(на время вызова или на время сеанса) должны содержать в имени постфикс
`ПовтИсп` (англ. `Cached`). Для клиентских модулей с кешированием используется
постфикс `КлиентПовтИсп` (англ. `ClientCached`).

Такое имя сразу показывает, что вызов функций модуля может вернуть повторно
используемый результат, а не заново выполнять вычисление при каждом обращении.

## Примеры

Допустимые имена: `ПараметрыСеансаПовтИсп`, `РаботаСФайламиКлиентПовтИсп`, `UsersInternalCached`

Недопустимые имена: `ПараметрыСеанса`, `РаботаСФайламиКлиент` (при включённом повторном использовании)
