# Запуск внешних приложений (ExternalAppStarting)

## Описание диагностики

Запуск внешних программ из кода 1С требует контроля в целях безопасности. Вредоносный или некорректный вызов может привести к утечке данных, выполнению произвольных команд ОС или отказу в обслуживании. При обнаружении таких вызовов рекомендуется провести ручной аудит для подтверждения их безопасности.

Диагностика распространяется на следующие методы:
- `КомандаСистемы`
- `ЗапуститьСистему`
- `ЗапуститьПриложение`
- `НачатьЗапускПриложения`
- `ЗапуститьПриложениеАсинх`
- `ФайловаяСистемаКлиент.ЗапуститьПрограмму` / `ФайловаяСистема.ЗапуститьПрограмму`
- `ФайловаяСистемаКлиент.ОткрытьПроводник`
- `ФайловаяСистемаКлиент.ОткрытьФайл` / `РаботаСФайламиКлиент.ОткрытьФайл`

Последние три — методы общих модулей библиотеки, а не глобального контекста,
поэтому учитывается получатель вызова. Одноимённые методы платформенных типов
работают с файлом или потоком и приложения не запускают, так что
`ЗаписьXML.ОткрытьФайл(...)` замечания не даёт.

## Примеры

```bsl
Процедура ОткрытьВнешнююПрограмму()
    Путь = "C:\Tools\utility.exe";
    КомандаСистемы(Путь); // срабатывание диагностики
КонецПроцедуры

&НаКлиенте
Процедура ЗапуститьУтилиту()
    ПараметрыЗапуска = Новый Структура;
    ФайловаяСистемаКлиент.ЗапуститьПрограмму("cmd /c dir", ПараметрыЗапуска); // срабатывание диагностики
КонецПроцедуры

&НаКлиенте
Асинх Процедура Подключить()
    Ждать ЗапуститьПриложениеАсинх("calc.exe", "", Истина); // срабатывание диагностики
КонецПроцедуры
```
