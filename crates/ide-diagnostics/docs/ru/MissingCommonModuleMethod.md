# Обращение к отсутствующему методу общего модуля (MissingCommonModuleMethod)

## Описание диагностики

Диагностика выявляет некорректные обращения к методам общих модулей. Фиксируются следующие ситуации:

- Указанный метод не существует в общем модуле.
- Метод присутствует в модуле, но не объявлен как экспортный.
- Исходный код общего модуля отсутствует -- в этом случае любое обращение к его методам считается ошибкой.

Диагностика не срабатывает, если имя переменной совпадает с именем общего модуля.

## Примеры

Неправильно:

```bsl
// Метод "РассчитатьСкидку" отсутствует в модуле ЦеноваяПолитика
Скидка = ЦеноваяПолитика.РассчитатьСкидку(Сумма);
```

```bsl
// Метод существует, но не является экспортным
Результат = ОбщегоНазначения.ВнутренняяФункция();
```

Правильно:

```bsl
// Метод существует и является экспортным
Скидка = ЦеноваяПолитика.ПолучитьСкидку(Сумма);
```
