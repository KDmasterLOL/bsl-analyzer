# Пробел в начале комментария (SpaceAtStartComment)

## Описание диагностики

После символов комментария `//` необходимо ставить пробел перед текстом. Это повышает читаемость кода и соответствует стандартам оформления модулей.

Диагностика не срабатывает на строки-разделители, состоящие только из символов `/` и пробелов, а также пропускает комментарии-аннотации с поддерживаемыми префиксами, например `//@`, `//(c)` и `//©`.

## Примеры

Неправильно

```bsl
//Получить список контрагентов
Результат = ПолучитьКонтрагентов();
```

Правильно

```bsl
// Получить список контрагентов
Результат = ПолучитьКонтрагентов();
```
