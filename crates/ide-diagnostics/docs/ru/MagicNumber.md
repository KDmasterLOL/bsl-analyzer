# Магические числа (MagicNumber)

## Описание диагностики

Магическое число -- это числовой литерал в коде, назначение которого неочевидно без анализа контекста. Использование таких чисел снижает читаемость и затрудняет сопровождение. Рекомендуется заменять числовые литералы именованными переменными с понятными названиями.

## Примеры

Неправильно:

```bsl
Функция ВесВКилограммах(ВесВГраммах)
    Возврат ВесВГраммах / 1000;
КонецФункции
```

Правильно:

```bsl
Функция ВесВКилограммах(ВесВГраммах)
    ГраммовВКилограмме = 1000;
    Возврат ВесВГраммах / ГраммовВКилограмме;
КонецФункции
```

## Исключения

Числовые литералы в операциях со структурами и соответствиями не считаются ошибкой, поскольку их назначение определяется ключом или именем свойства:

```bsl
// Вставка в структуру
Параметры = Новый Структура;
Параметры.Вставить("Ширина", 800);
Параметры.Вставить("Высота", 600);

// Конструктор структуры
Размеры = Новый Структура("Длина, Ширина", 100, 50);

// Присваивание свойству структуры
Настройки = Новый Структура("Таймаут, Попытки");
Настройки.Таймаут = 30;
Настройки.Попытки = 3;

// Фиксированная структура
ФиксПараметры = Новый ФиксированнаяСтруктура("Порт", 8080);

// Соответствие (как ключ или значение)
КодыОтветов = Новый Соответствие;
КодыОтветов.Вставить("Успех", 200);
КодыОтветов.Вставить(404, "Не найдено");
```
