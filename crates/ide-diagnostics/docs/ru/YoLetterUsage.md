# Использование буквы "ё" в текстах модулей (YoLetterUsage)

## Описание диагностики

Буква "ё" не допускается в исходном коде модулей: в именах переменных, процедур, функций, а также в строковых литералах и комментариях. Исключение составляют интерфейсные тексты, предназначенные для отображения пользователю (сообщения, заголовки форм, справочная информация), где использование буквы "ё" допустимо.

## Примеры

### Неправильно

```bsl
Перем ПодсчётИтогов;
```

### Правильно

```bsl
Перем ПодсчетИтогов;
```
