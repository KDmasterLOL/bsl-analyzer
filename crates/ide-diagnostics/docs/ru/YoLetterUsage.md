# Использование буквы "ё" в текстах модулей (YoLetterUsage)

## Описание диагностики

Согласно требованиям к текстам модулей, буква `ё` не должна использоваться в идентификаторах исходного кода.

Текущая реализация проверяет только идентификаторы: имена переменных, процедур, функций и обращения к ним. Строковые литералы, комментарии и другие пользовательские тексты эта диагностика не анализирует.

## Примеры

### Неправильно

```bsl
Перем ПодсчётИтогов;
```

### Правильно

```bsl
Перем ПодсчетИтогов;
```

### Допустимо

```bsl
Сообщить("Подсчёт итогов завершён");
```
