# Вложенный тернарный оператор (NestedTernaryOperator)

## Описание диагностики

Вложенные тернарные операторы значительно ухудшают восприятие кода. Конструкция `?(...)` внутри другой `?(...)` делает логику трудной для понимания и отладки. Вместо вложенных тернарных операторов следует применять конструкцию `Если ... ИначеЕсли ... КонецЕсли`.

## Примеры

Неправильно

```bsl
Категория = ?(Сумма > 1000, ?(Сумма > 5000, "Высокая", "Средняя"), "Низкая");
```

```bsl
Значение = ?(Параметр = Неопределено, 0, ?(Параметр > 100, 100, Параметр));
```

Правильно

```bsl
Если Сумма > 5000 Тогда
    Категория = "Высокая";
ИначеЕсли Сумма > 1000 Тогда
    Категория = "Средняя";
Иначе
    Категория = "Низкая";
КонецЕсли;
```

```bsl
Если Параметр = Неопределено Тогда
    Значение = 0;
ИначеЕсли Параметр > 100 Тогда
    Значение = 100;
Иначе
    Значение = Параметр;
КонецЕсли;
```
