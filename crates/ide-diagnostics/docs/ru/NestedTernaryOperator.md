# Вложенный тернарный оператор (NestedTernaryOperator)

## Описание диагностики

Диагностика выявляет тернарные операторы, которые либо вложены в другой
тернарный оператор, либо используются прямо в условии `Если` / `ИначеЕсли`.

Обе формы синтаксически корректны, но обычно ухудшают читаемость и усложняют
отладку. На практике код часто становится понятнее, если сначала вычислить
промежуточное значение или заменить сложную цепочку `?(...)` на явную
конструкцию `Если ... ИначеЕсли ... КонецЕсли`.

## Примеры

Неправильно:

```bsl
Категория = ?(Сумма > 1000, ?(Сумма > 5000, "Высокая", "Средняя"), "Низкая");
```

```bsl
Если ?(Параметр = Неопределено, 0, Параметр) = 0 Тогда
    Статус = "Готово";
КонецЕсли;
```

Правильно:

```bsl
Если Сумма > 5000 Тогда
    Категория = "Высокая";
ИначеЕсли Сумма > 1000 Тогда
    Категория = "Средняя";
Иначе
    Категория = "Низкая";
КонецЕсли;
```
