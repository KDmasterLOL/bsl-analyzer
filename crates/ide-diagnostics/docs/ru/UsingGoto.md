# Оператор "Перейти" не должен использоваться (UsingGoto)

## Описание диагностики

Оператор `Перейти` является неструктурным средством управления потоком выполнения. Его применение снижает читаемость и усложняет сопровождение кода. Вместо него следует применять структурные конструкции: `Если`, `Пока`, `Для`, `Продолжить`, `Прервать`.

## Примеры

### Неправильно

```bsl
Индекс = 0;
~Повтор: Сообщить(СтрШаблон("Индекс = %1", Индекс));
Индекс = Индекс + 1;

Если Индекс < 5 Тогда
    Перейти ~Повтор;
КонецЕсли;
```

### Правильно

```bsl
Для Индекс = 0 По 4 Цикл
    Сообщить(СтрШаблон("Индекс = %1", Индекс));
КонецЦикла;
```
