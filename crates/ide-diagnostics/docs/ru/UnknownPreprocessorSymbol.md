# Неизвестный символ препроцессора (UnknownPreprocessorSymbol)

## Описание диагностики

Применение неизвестных символов препроцессора недопустимо. Платформа может молча проигнорировать нераспознанную инструкцию, что приведёт к пропуску блока кода и логическим ошибкам в работе программы.

## Примеры

Неправильно:

```bsl
#Если НеизвестныйСимвол Тогда
    ВыполнитьДействие();
#КонецЕсли
```

Правильно:

```bsl
#Если Сервер Тогда
    ВыполнитьДействие();
#КонецЕсли
```
