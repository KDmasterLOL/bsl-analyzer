# Отсутствует проверка признака ОбменДанными.Загрузка в обработчике событий объекта (DataExchangeLoading)

## Описание диагностики

Обработчики событий `ПередЗаписью`, `ПриЗаписи` и `ПередУдалением` должны начинаться с проверки признака `ОбменДанными.Загрузка`. При загрузке данных через механизм обмена бизнес-логика объекта не должна повторно выполняться, так как она уже была отработана в узле-источнике. Данные при обмене должны записываться в информационную базу без дополнительных преобразований и проверок.

Отсутствие этой проверки может привести к ошибкам при загрузке данных или к нежелательному изменению загружаемых значений.

## Примеры

Неправильно:

```bsl
Процедура ПередЗаписью(Отказ)

    ВыполнитьДополнительныеПроверки();
    ЗаполнитьРеквизитыПоУмолчанию();

КонецПроцедуры
```

Правильно:

```bsl
Процедура ПередЗаписью(Отказ)

    Если ОбменДанными.Загрузка Тогда
        Возврат;
    КонецЕсли;

    ВыполнитьДополнительныеПроверки();
    ЗаполнитьРеквизитыПоУмолчанию();

КонецПроцедуры
```
