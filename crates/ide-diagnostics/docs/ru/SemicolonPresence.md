# Выражение должно заканчиваться символом ";" (SemicolonPresence)

## Описание диагностики

Каждый оператор в теле процедуры или функции должен завершаться точкой с запятой (`;`). Перенос строки сам по себе не является признаком конца оператора. Несмотря на то что платформа в ряде случаев допускает отсутствие точки с запятой, её следует указывать всегда для явного обозначения границ операторов.

**Замечание:** ключевые слова `Процедура`, `КонецПроцедуры`, `Функция`, `КонецФункции` являются операторными скобками, а не операторами, поэтому **не** должны завершаться точкой с запятой — это может привести к ошибке выполнения модуля.

## Примеры

Неправильно

```bsl
А = 1
Б = 2
```

Правильно

```bsl
А = 1;
Б = 2;
```
