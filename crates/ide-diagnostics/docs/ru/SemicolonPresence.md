# Выражение должно заканчиваться символом ";" (SemicolonPresence)

## Описание диагностики

В BSL перенос строки сам по себе не завершает оператор. Для разделения операторов используется символ `;`.

Даже там, где платформа допускает отсутствие точки с запятой, её лучше ставить явно: так границы операторов читаются однозначно и код проще сопровождать.

Текущая реализация узкая и синтаксическая:

- диагностика срабатывает на операторы, которые дошли до HIR lowering без завершающей точки с запятой;
- метки, пустые операторы и конструкции с ошибкой разбора пропускаются;
- для замечания предлагается auto-fix с добавлением `;` в конец диапазона.

`Процедура`, `КонецПроцедуры`, `Функция`, `КонецФункции` не являются обычными операторами и не должны завершаться точкой с запятой.

## Примеры

Неправильно

```bsl
А = 1
Б = 2
```

Правильно

```bsl
А = 1;
Б = 2;
```
