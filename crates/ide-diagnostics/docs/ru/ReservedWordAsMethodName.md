# Использование зарезервированного слова как имени процедуры/функции (ReservedWordAsMethodName)

## Описание диагностики

Имена процедур и функций не могут совпадать с зарезервированными словами языка BSL. Платформа 1С отклонит такой код с ошибкой компиляции: «Ожидается имя процедуры».

Список зарезервированных слов включает: `Процедура`/`Procedure`, `Функция`/`Function`, `Если`/`If`, `Тогда`/`Then`, `Иначе`/`Else`, `Для`/`For`, `Каждого`/`Each`, `Из`/`In`, `Пока`/`While`, `Цикл`/`Do`, `Возврат`/`Return`, `Попытка`/`Try`, `Исключение`/`Except`, `ВызватьИсключение`/`Raise`, `Перем`/`Var`, `Новый`/`New`, `Выполнить`/`Execute`, `Экспорт`/`Export`, `Знач`/`Val`, `Истина`/`True`, `Ложь`/`False`, `Неопределено`/`Undefined`, `Null`, `Не`/`Not`, `И`/`And`, `Или`/`Or`, `Асинх`/`Async`, `Ждать`/`Await`, `Перейти`/`Goto`, `Продолжить`/`Continue`, `Прервать`/`Break`, `ДобавитьОбработчик`/`AddHandler`, `УдалитьОбработчик`/`RemoveHandler` и другие ключевые слова языка.

## Примеры

Неправильно:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
    // ...
КонецПроцедуры
```

Правильно:

```bsl
&НаКлиенте
Процедура ВыполнитьКоманду(Команда)
    // ...
КонецПроцедуры
```
