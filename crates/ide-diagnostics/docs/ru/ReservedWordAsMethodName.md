# Использование зарезервированного слова как имени процедуры/функции (ReservedWordAsMethodName)

## Описание диагностики

Имена процедур и функций не могут совпадать с зарезервированными словами языка BSL. Такой код некорректен на уровне языка и не принимается парсером или компилятором платформы.

Текущая реализация намеренно простая:

- диагностика срабатывает на процедуры и функции, имя которых уже распознано как зарезервированное слово на этапе HIR lowering;
- поддерживаются и русские, и английские ключевые слова;
- правило не зависит от проектной конфигурации.

## Примеры

Неправильно:

```bsl
&НаКлиенте
Процедура Выполнить(Команда)
    // ...
КонецПроцедуры
```

Правильно:

```bsl
&НаКлиенте
Процедура ВыполнитьКоманду(Команда)
    // ...
КонецПроцедуры
```
