# Использование метода ДанныеФормыВЗначение (FormDataToValue)

## Описание диагностики

В модулях управляемых форм для преобразования данных формы в прикладной объект следует применять метод `РеквизитФормыВЗначение` вместо `ДанныеФормыВЗначение`. Метод `РеквизитФормыВЗначение` имеет более простой синтаксис (не требует явного указания типа), что снижает вероятность ошибки и обеспечивает единообразие кода.

## Примеры

### Неправильно

```bsl
&НаСервере
Процедура ОбработатьОбъектНаСервере()
    ДокументОбъект = ДанныеФормыВЗначение(Объект, Тип("ДокументОбъект.РасходнаяНакладная"));
    ДокументОбъект.Провести();
КонецПроцедуры
```

### Правильно

```bsl
&НаСервере
Процедура ОбработатьОбъектНаСервере()
    ДокументОбъект = РеквизитФормыВЗначение("Объект");
    ДокументОбъект.Провести();
КонецПроцедуры
```
