# Присвоение переменной самой себе (SelfAssign)

## Описание диагностики

Конструкция, в которой переменная или свойство присваиваются самим себе, не производит никакого эффекта. Обычно это признак опечатки или неаккуратного copy-paste.

Текущая реализация узкая и HIR-based:

- диагностика срабатывает, когда левая и правая части присваивания разрешаются в один и тот же путь;
- сравнение выполняется без учета регистра, потому что идентификаторы BSL регистронезависимы;
- простые самоприсваивания свойств вида `Объект.Поле = Объект.Поле` тоже считаются ошибкой.

## Примеры

Неправильно

```bsl
СуммаДокумента = СуммаДокумента;
```

Скорее всего, имелось в виду

```bsl
СуммаДокумента = СуммаИтого;
```
