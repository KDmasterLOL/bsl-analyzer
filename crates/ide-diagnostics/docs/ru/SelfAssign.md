# Присвоение переменной самой себе (SelfAssign)

## Описание диагностики

Конструкция, в которой переменная присваивается сама себе, не производит никакого эффекта. Как правило, это свидетельствует об опечатке — вместо одной из переменных должна использоваться другая.

## Примеры

Неправильно

```bsl
СуммаДокумента = СуммаДокумента;
```

Скорее всего, имелось в виду

```bsl
СуммаДокумента = СуммаИтого;
```
