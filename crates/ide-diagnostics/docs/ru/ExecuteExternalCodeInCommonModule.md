# Выполнение произвольного кода в общем модуле на сервере (ExecuteExternalCodeInCommonModule)

## Описание диагностики

Вызов методов `Выполнить` и `Вычислить` в серверных процедурах и функциях представляет угрозу безопасности, поскольку позволяет исполнить произвольный код на сервере приложений. Если такое динамическое выполнение необходимо, соответствующий код должен быть сосредоточен в специально выделенном общем модуле и пройти процедуру аудита безопасности.

Ограничение применяется только к серверному коду. На клиентский код оно не распространяется.

## Примеры

### Неправильно (серверная функция вне специализированного модуля)

```bsl
&НаСервере
Функция ПолучитьЗначениеИзВыражения(Выражение)
    Возврат Вычислить(Выражение); // опасно -- код вне аудированного модуля
КонецФункции
```

### Правильно (код в выделенном общем модуле, прошедшем аудит)

```bsl
// Общий модуль "БезопасноеВыполнение" (серверный, прошёл аудит)
Функция ВычислитьВыражение(Выражение) Экспорт
    Возврат Вычислить(Выражение);
КонецФункции
```
