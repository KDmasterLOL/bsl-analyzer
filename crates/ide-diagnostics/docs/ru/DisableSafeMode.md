# Отключение безопасного режима (DisableSafeMode)

## Описание диагностики

В прикладном решении помимо штатного кода конфигурации может выполняться внешний код: расширения, внешние обработки и отчёты, внешние компоненты и т.п. Разработчик не может гарантировать безопасность такого кода. Злоумышленник способен заложить в него деструктивные действия -- запуск произвольных приложений, обращение к COM-объектам, доступ к данным других пользователей.

Риск особенно высок в модели сервиса: компрометация одного приложения может открыть доступ ко всем данным сервиса.

Внешний код должен выполняться в безопасном режиме. Точечное снятие ограничений допускается только после ручной верификации конкретного участка кода.

Диагностика фиксирует вызовы `УстановитьБезопасныйРежим` и `УстановитьОтключениеБезопасногоРежима`, которые снимают контроль безопасности:
- `УстановитьБезопасныйРежим(Истина)` -- не вызывает срабатывания
- `УстановитьОтключениеБезопасногоРежима(Ложь)` -- не вызывает срабатывания

Текущая реализация также срабатывает на вызовы с переменными или другими неочевидно безопасными выражениями, например `УстановитьБезопасныйРежим(Флаг)` и `УстановитьОтключениеБезопасногоРежима(Флаг)`. При этом квалифицированные вызовы вроде `Модуль.УстановитьБезопасныйРежим(Ложь)` не анализируются.

## Примеры

```bsl
// Срабатывание диагностики: отключение безопасного режима
УстановитьБезопасныйРежим(Ложь);

Флаг = Ложь;
УстановитьБезопасныйРежим(Флаг);

// Срабатывание диагностики: разрешение отключения безопасного режима
УстановитьОтключениеБезопасногоРежима(Истина);

Флаг = Истина;
УстановитьОтключениеБезопасногоРежима(Флаг);

// Корректное использование -- диагностика не срабатывает
УстановитьБезопасныйРежим(Истина);
УстановитьОтключениеБезопасногоРежима(Ложь);
```
