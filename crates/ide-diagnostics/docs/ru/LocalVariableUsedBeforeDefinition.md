# Использование локальной переменной до определения (LocalVariableUsedBeforeDefinition)

Локальная переменная цикла `Для` или `Для Каждого` используется до того, как выполнение достигает определения этой переменной. Платформа 1С рассматривает такой код как ошибку компиляции.

## Неправильно

```bsl
Строка.Признак = Ложь;
Для Каждого Строка Из Коллекция Цикл
    // ...
КонецЦикла;
```

## Правильно

Перенесите использование переменной внутрь цикла или определите другое значение до первого чтения.
