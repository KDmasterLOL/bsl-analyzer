# Несовпадение количества аргументов (MismatchedArgCount)

## Описание диагностики

Диагностика срабатывает, когда количество переданных аргументов не совпадает с
сигнатурой вызванного метода или функции.

Текущая реализация работает для вызовов, которые удалось семантически
разрешить в конкретную цель, например:

- квалифицированные вызовы общих модулей;
- встроенные функции и методы платформы с известной сигнатурой.

Это именно семантическая ошибка: код может быть синтаксически корректным, но
вызов всё равно неверен, если аргументов передано слишком мало или слишком
много.

## Примеры

Неправильно:

```bsl
Процедура Сложение(Левый, Правый) Экспорт
КонецПроцедуры

Процедура Тест()
    ОбщийМодуль.Сложение(1);
КонецПроцедуры
```

Правильно:

```bsl
Процедура Сложение(Левый, Правый) Экспорт
КонецПроцедуры

Процедура Тест()
    ОбщийМодуль.Сложение(1, 2);
КонецПроцедуры
```

## Источники

У этой диагностики нет прямого нормативного источника уровня `v8std`.
