# Устаревшие объекты платформы 8.3.12 (DeprecatedAttributes8312)

## Описание диагностики

Начиная с версии платформы 8.3.12, ряд свойств, методов и перечислений признан устаревшим. Их использование в новом коде не рекомендуется.

Перечень устаревших элементов:

* Значение `ГруппировкаПодчиненныхЭлементовФормы.Горизонтальная` -- заменено на `ГоризонтальнаяВсегда`
* Перечисление `ОриентацияМетокДиаграммы` -- заменено на `ОриентацияПодписейДиаграммы`
* Свойства и методы объекта `Диаграмма`:
   * `ПалитраЦветов`
   * `ЦветНачалаГрадиентнойПалитры`
   * `ЦветКонцаГрадиентнойПалитры`
   * `МаксимальноеКоличествоЦветовГрадиентнойПалитры`
   * `ПолучитьПалитру()`
   * `УстановитьПалитру()`
* Свойства объекта `ОбластьПостроенияДиаграммы`:
   * `ОтображатьШкалу`
   * `ЛинииШкалы`
   * `ЦветШкалы`
* Устаревшие свойства `ОбластьПостроенияДиаграммы` с указанием замен:
   * `ОтображатьПодписиШкалыСерии` -- использовать `ШкалаСерий.ПоложениеПодписейШкалы`
   * `ОтображатьПодписиШкалыТочек` -- использовать `ШкалаТочек.ПоложениеПодписейШкалы`
   * `ОтображатьПодписиШкалыЗначений` -- использовать `ШкалаЗначений.ПоложениеПодписейШкалы`
   * `ОтображатьЛинииЗначенийШкалы` -- использовать `ШкалаЗначений.ОтображениеЛинийСетки`
   * `ФорматШкалыЗначений` -- использовать `ШкалаЗначений.ФорматПодписей`
   * `ОриентацияМеток` -- использовать `ШкалаТочек.ОриентацияПодписей`
* Свойства `ОтображатьЛегенду` и `ОтображатьЗаголовок` объектов `Диаграмма`, `ДиаграммаГанта`, `СводнаяДиаграмма`
* Метод глобального контекста `ОчиститьЖурналРегистрации()` -- применим только к журналу в формате SQLite
