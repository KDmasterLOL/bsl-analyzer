# Обработчик регламентного задания (ScheduledJobHandler)

## Описание диагностики

Метод-обработчик регламентного задания должен соответствовать ряду требований платформы. Обработчиком может быть только экспортная процедура или функция неглобального общего модуля с серверным контекстом выполнения. Если обработчик является функцией, возвращаемое значение не используется.

Для предопределённых регламентных заданий обработчик не должен принимать параметров. Для непредопределённых заданий допускаются параметры, но их состав должен точно совпадать с параметрами, заданными у регламентного задания.

Диагностика проверяет следующие условия:

- Общий модуль и метод, указанные как обработчик, существуют в конфигурации
- Общий модуль имеет серверный контекст выполнения
- Метод помечен ключевым словом `Экспорт`
- Тело метода не является пустым
- У предопределённого задания обработчик не содержит параметров
- Один и тот же метод не используется как обработчик в нескольких регламентных заданиях

## Примеры

Правильный обработчик предопределённого задания

```bsl
// Общий модуль "РегламентныеЗаданияСервер", серверный контекст
Процедура ОбновитьКурсыВалют() Экспорт
    // логика обновления курсов
КонецПроцедуры
```

Ошибочный обработчик — есть параметр у предопределённого задания

```bsl
Процедура ОбновитьКурсыВалют(ДатаНачала) Экспорт
    // не допускается для предопределённого задания
КонецПроцедуры
```
