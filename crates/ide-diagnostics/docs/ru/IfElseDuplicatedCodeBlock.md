# Повторяющиеся блоки кода в синтаксической конструкции Если...Тогда...ИначеЕсли... (IfElseDuplicatedCodeBlock)

## Описание диагностики

Диагностика отмечает ветви `Если` / `ИначеЕсли` / `Иначе`, в которых
выполняется один и тот же блок кода.

Обычно это означает одно из двух:

- условия можно объединить;
- одна из ветвей была скопирована и затем не была корректно изменена.

## Примеры

Неправильно:
```bsl
Если Статус = "Новый" Тогда
    Результат = 1;
ИначеЕсли Статус = "Активный" Тогда
    Результат = 2;
ИначеЕсли Статус = "Закрыт" Тогда
    Результат = 2;
Иначе
    Результат = 0;
КонецЕсли;
```

Правильно:
```bsl
Если Статус = "Новый" Тогда
    Результат = 1;
ИначеЕсли Статус = "Активный" ИЛИ Статус = "Закрыт" Тогда
    Результат = 2;
Иначе
    Результат = 0;
КонецЕсли;
```
