# Повторяющиеся блоки кода в синтаксической конструкции Если...Тогда...ИначеЕсли... (IfElseDuplicatedCodeBlock)

## Описание диагностики

В конструкции `Если...Тогда...ИначеЕсли...` не допускается наличие нескольких ветвей с идентичным телом. Дублирование блоков кода в разных ветвях условия указывает на ошибку копирования либо на возможность объединения условий.

## Примеры

Неправильно:
```bsl
Если Статус = "Новый" Тогда
    Результат = 1;
ИначеЕсли Статус = "Активный" Тогда
    Результат = 2;
ИначеЕсли Статус = "Закрыт" Тогда
    Результат = 2;
Иначе
    Результат = 0;
КонецЕсли;
```

Правильно:
```bsl
Если Статус = "Новый" Тогда
    Результат = 1;
ИначеЕсли Статус = "Активный" ИЛИ Статус = "Закрыт" Тогда
    Результат = 2;
Иначе
    Результат = 0;
КонецЕсли;
```
