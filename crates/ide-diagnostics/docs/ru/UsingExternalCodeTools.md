# Использование возможностей выполнения внешнего кода (UsingExternalCodeTools)

## Описание диагностики

В прикладных решениях запрещено выполнять в небезопасном режиме на сервере 1С:Предприятия любой код, не входящий в состав конфигурации. Данное ограничение не распространяется на код, прошедший аудит безопасности, а также на код, исполняемый на стороне клиента.

К недопустимому выполнению внешнего кода в небезопасном режиме относятся:

* внешние отчеты и обработки (в том числе печатные формы)
* расширения конфигурации

### Ограничения

В текущей реализации контекст выполнения (сервер/клиент) не анализируется: диагностика срабатывает независимо от контекста.

## Примеры

```bsl
// Срабатывание: подключение внешней обработки на сервере
ВнешниеОбработки.Создать("ВнешняяОбработка.epf");
```
