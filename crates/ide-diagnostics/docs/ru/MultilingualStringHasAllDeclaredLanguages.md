# Есть локализованный текст для всех заявленных в конфигурации языков (MultilingualStringHasAllDeclaredLanguages)

## Описание диагностики

В мультиязычной конфигурации функция `НСтр` должна содержать фрагменты для каждого языка, объявленного в настройках конфигурации. Если для какого-либо языка текст не указан и сеанс запущен именно под этим кодом языка, функция вернёт пустую строку, что приведёт к отображению пустых сообщений пользователю.

## Примеры

Конфигурация поддерживает языки `ru` и `en`.

Неправильно -- отсутствует перевод на английский:

```bsl
Сообщение = НСтр("ru = 'Документ успешно записан'");
```

Правильно:

```bsl
Сообщение = НСтр("ru = 'Документ успешно записан'; en = 'Document saved successfully'");
```
