# Хранение конфиденциальной информации в коде (UsingHardcodeSecretInformation)

## Описание диагностики

Не допускается размещение конфиденциальных данных непосредственно в исходном коде модулей.

Текущая реализация в первую очередь ориентирована на пароли и пароль-подобные поля. По умолчанию она ищет имена вроде `Пароль` / `Password`, а также проверяет несколько структурных случаев:

* присваивания полям с пароль-подобными именами
* `Вставить("Пароль", "...")` в структуры и соответствия
* `Новый Структура(..., "Пароль", "...")`
* аргумент пароля в `HTTPСоединение` / `FTPСоединение`

В решениях на базе БСП для безопасного хранения паролей следует использовать механизм безопасного хранилища.

### Дополнительно

Строки, состоящие только из символов `*`, не считаются паролями и не вызывают срабатывания:

```bsl
Пароль = "******";
```

## Примеры

### Неправильно

```bsl
КлючДоступа = "s3cr3t_k3y";
```

### Правильно

```bsl
СохранённыеДанные = ОбщегоНазначения.ПрочитатьДанныеИзБезопасногоХранилища("ИдентификаторСервиса", "КлючДоступа");
КлючДоступа = СохранённыеДанные.КлючДоступа;
```
