# Неверно задан обработчик операции web-сервиса (WrongWebServiceHandler)

## Описание диагностики

Диагностика проверяет корректность имени обработчика, назначенного операции web-сервиса в метаданных.

Она срабатывает в двух случаях:

- у операции web-сервиса не задано имя обработчика;
- указанный обработчик отсутствует в текущем модуле web-сервиса.

Текущая реализация работает по метаданным web-сервиса и по символьному дереву текущего модуля. Она не анализирует тело обработчика и не сверяет количество параметров функции с параметрами операции.

## Примеры

### Неправильно -- обработчик не задан

```bsl
// У операции web-сервиса не заполнено имя обработчика.
```

### Правильно

```bsl
Функция ПолучитьОстатки(КодСклада, ДатаОтчёта)
    Возврат СкладскойУчёт.Остатки(КодСклада, ДатаОтчёта);
КонецФункции
```
