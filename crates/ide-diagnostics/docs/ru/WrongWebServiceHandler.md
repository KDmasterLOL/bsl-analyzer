# Неверно задан обработчик операции web-сервиса (WrongWebServiceHandler)

## Описание диагностики

Если обработчик операции web-сервиса не реализован или задан с ошибками, вызов операции не вернёт данных и не сгенерирует сообщение об ошибке ни на стороне потребителя сервиса, ни на стороне самого сервера.

Обработчик операции web-сервиса должен удовлетворять двум условиям:
* Тело функции не должно быть пустым.
* Число параметров функции должно совпадать с количеством параметров, определённых в настройках операции web-сервиса.

Конфигуратор обнаруживает подобные нарушения только при включённом флаге "Проверка существования назначенных обработчиков".

## Примеры

### Неправильно -- пустое тело обработчика

```bsl
Функция ПолучитьОстатки(КодСклада, ДатаОтчёта)

КонецФункции
```

### Неправильно -- несовпадение числа параметров

```bsl
Функция ПолучитьОстатки(КодСклада, ДатаОтчёта, ФлагДетализации)
    Возврат СкладскойУчёт.Остатки(КодСклада, ДатаОтчёта);
КонецФункции
```

### Правильно

```bsl
Функция ПолучитьОстатки(КодСклада, ДатаОтчёта)
    Возврат СкладскойУчёт.Остатки(КодСклада, ДатаОтчёта);
КонецФункции
```
