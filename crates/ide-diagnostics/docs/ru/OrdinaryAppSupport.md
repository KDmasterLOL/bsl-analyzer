# Поддержка обычного приложения (OrdinaryAppSupport)

## Описание диагностики

Диагностика проверяет настройки конфигурации, связанные с поддержкой режима
обычного приложения.

Проверяются два свойства конфигурации:

- `Использовать управляемые формы в обычном приложении` должно быть равно `Истина`;
- `Использовать обычные формы в управляемом приложении` должно быть равно `Ложь`.

Правило опирается на рекомендации 1С по обратной совместимости и работе в
смешанных режимах. В текущем проекте диагностика выполняется только для файлов
`SessionModule` и только если в конфигурации анализатора явно включен флаг
`ordinary_app_support`.
