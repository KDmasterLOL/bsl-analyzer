# Поддержка обычного приложения (OrdinaryAppSupport)

## Описание диагностики

Конфигурация должна обеспечивать работоспособность в режиме обычного приложения (толстый клиент) и внешнего соединения для администраторов. Это необходимо для обратной совместимости со сторонними решениями и внешними обработками, созданными на платформе 1С:Предприятие 8.0 и 8.1.

Рекомендации:

* Свойство конфигурации "Использовать управляемые формы в обычном приложении" должно быть установлено в значение `Истина`.
* Свойство "Использовать обычные формы в управляемом режиме" должно быть установлено в значение `Ложь`.
* Разработку следует вести в режиме редактирования для обоих режимов запуска (управляемое и обычное приложение).

Отказ от поддержки обычного приложения допустим только в обоснованных исключительных случаях.
