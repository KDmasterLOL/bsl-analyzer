# Недостижимый код (UnreachableCode)

## Описание диагностики

Код, расположенный после безусловных операторов передачи управления (`Возврат`, `ВызватьИсключение`, `Продолжить`, `Прервать`, `Перейти`), никогда не выполняется. Такие фрагменты являются мёртвым кодом и, как правило, появляются в результате неаккуратного редактирования. Их следует удалить для повышения читаемости.

## Примеры

```bsl
Процедура ОбработатьЗаказ()
    ОтправитьУведомление();
    Возврат;
    // Следующий код никогда не выполнится
    ЗаписатьВЛог("Заказ обработан");
КонецПроцедуры
```

```bsl
Функция Вычислить(Параметр)
    Если Параметр < 0 Тогда
        ВызватьИсключение "Отрицательное значение недопустимо";
        Параметр = 0; // Недостижимая строка
    КонецЕсли;
    Возврат Параметр * 2;
КонецФункции
```
