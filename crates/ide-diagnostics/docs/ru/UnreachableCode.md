# Недостижимый код (UnreachableCode)

## Описание диагностики

Диагностика сообщает о коде, который не может выполниться, потому что управление уже покинуло текущий путь исполнения.

Типичные случаи — операторы после `Возврат`, `ВызватьИсключение`, `Прервать` или `Продолжить`.

Текущая реализация основана на CFG и работает точнее, чем простой поиск по тексту:

- строит множество достижимых вершин из точки входа, проходя только по живым рёбрам;
- для тел методов отдельно отличает локально недостижимый код после терминатора от кода, недостижимого только из-за внешней недостижимой ветки;
- объединяет соседние недостижимые операторы в один диагностический диапазон.

## Примеры

```bsl
Процедура ОбработатьЗаказ()
    Возврат;
    ЗаписатьВЛог("Заказ обработан");
КонецПроцедуры
```

```bsl
Функция Вычислить(Параметр)
    Если Параметр < 0 Тогда
        ВызватьИсключение "Отрицательное значение недопустимо";
        Параметр = 0; // Недостижимая строка
    КонецЕсли;
    Возврат Параметр * 2;
КонецФункции
```

Корректно:

```bsl
Процедура ОбработатьЗаказ(НужноПрервать)
    Если НужноПрервать Тогда
        Возврат;
    КонецЕсли;

    ЗаписатьВЛог("Код достижим");
КонецПроцедуры
```
