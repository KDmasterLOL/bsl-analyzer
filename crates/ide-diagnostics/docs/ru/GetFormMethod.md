# Использование метода ПолучитьФорму (GetFormMethod)

## Описание диагностики

Стандарт `#std404` рекомендует открывать формы через метод глобального
контекста `ОткрытьФорму` (для проектов на платформе `8.2` и ниже —
`ОткрытьФормуМодально`) вместо сценария, в котором форма сначала получается
через `ПолучитьФорму`, а затем открывается вручную.

Текущая реализация диагностики намеренно строже текста стандарта: она
срабатывает на любой прямой вызов `ПолучитьФорму` / `GetForm`, включая
объектные методы, а не только на точную последовательность
`ПолучитьФорму(...); ...Открыть()`.

## Примеры

Неправильно:
```bsl
Процедура ОткрытьКарточкуТовара()
    Товар = Справочники.Номенклатура.НайтиПоКоду("00001");
    Форма = Товар.ПолучитьФорму("ФормаЭлемента");
КонецПроцедуры
```

```bsl
Процедура ОткрытьНастройки()
    ФормаНастроек = ПолучитьФорму("Обработка.НастройкиПрограммы.Форма");
КонецПроцедуры
```

Правильно:
```bsl
Процедура ОткрытьКарточкуТовара()
    Товар = Справочники.Номенклатура.НайтиПоКоду("00001");
    ОткрытьФорму("Справочник.Номенклатура.ФормаОбъекта", Новый Структура("Ключ", Товар));
КонецПроцедуры
```
