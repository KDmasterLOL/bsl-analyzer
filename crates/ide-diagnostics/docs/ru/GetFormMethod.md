# Использование метода ПолучитьФорму (GetFormMethod)

## Описание диагностики

Для отображения форм рекомендуется применять метод глобального контекста `ОткрытьФорму` (в версиях платформы 8.2 и ранее допускается также `ОткрытьФормуМодально`). Альтернативный подход, при котором форма сначала получается через `ПолучитьФорму`, а затем открывается вручную, не соответствует стандартам разработки и не рекомендуется к использованию.

## Примеры

Неправильно:
```bsl
Процедура ОткрытьКарточкуТовара()
    Товар = Справочники.Номенклатура.НайтиПоКоду("00001");
    Форма = Товар.ПолучитьФорму("ФормаЭлемента");
    Форма.Открыть();
КонецПроцедуры
```

```bsl
Процедура ОткрытьНастройки()
    ФормаНастроек = ПолучитьФорму("Обработка.НастройкиПрограммы.Форма");
    ФормаНастроек.Открыть();
КонецПроцедуры
```

Правильно:
```bsl
Процедура ОткрытьКарточкуТовара()
    Товар = Справочники.Номенклатура.НайтиПоКоду("00001");
    ОткрытьФорму("Справочник.Номенклатура.ФормаОбъекта", Новый Структура("Ключ", Товар));
КонецПроцедуры
```
