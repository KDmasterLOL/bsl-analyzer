# Отсутствует описание возвращаемого значения функции (MissingReturnedValueDescription)

## Описание диагностики

Документирующий комментарий функции должен содержать секцию с описанием возвращаемого значения. Для каждого возможного типа результата необходимо указать тип и пояснение. Это позволяет вызывающему коду корректно обрабатывать результат без изучения тела функции.

Диагностика выявляет следующие проблемы:

- У функции отсутствует описание возвращаемого значения.
- У процедуры указано описание возвращаемого значения (процедура ничего не возвращает).
- Тип возвращаемого значения указан, но отсутствует его текстовое пояснение (эта проверка активируется при отключении параметра «краткая форма записи»).

Текущая реализация имеет несколько важных ограничений:

- отсутствие секции возвращаемого значения проверяется только у экспортных функций;
- для процедур проверяется только то, что секция возвращаемого значения отсутствует;
- комментарии-ссылки вида `См. ДругойМетод()` специально пропускаются;
- параметр `allowShortDescriptionReturnValues` управляет строгим режимом, где одного имени типа уже недостаточно.

## Примеры

Неправильно:

```bsl
// Вычисляет итоговую сумму заказа.
//
Функция ИтоговаяСуммаЗаказа(Заказ) Экспорт
```

Правильно:

```bsl
// Вычисляет итоговую сумму заказа.
//
// Параметры:
//   Заказ - ДокументСсылка.ЗаказПокупателя - ссылка на заказ
//
// Возвращаемое значение:
//   Число - сумма всех строк заказа с учётом скидок
//
Функция ИтоговаяСуммаЗаказа(Заказ) Экспорт
```
