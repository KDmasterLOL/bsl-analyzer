# Серверный экспортный метод формы (ServerSideExportFormMethod)

## Описание диагностики

Экспортные методы модуля формы могут вызываться только из клиентского контекста — через объект формы, полученный методом `ПолучитьФорму`, который доступен исключительно на клиенте. Поэтому единственная допустимая директива компиляции для экспортного метода формы — `&НаКлиенте`.

Указание директив `&НаСервере`, `&НаСервереБезКонтекста` или отсутствие директивы (что по умолчанию означает серверный контекст) у экспортного метода формы считается ошибкой.

*В отдельных версиях платформы существовала ошибка, позволявшая использовать серверные экспортные методы форм, однако проектировать решение с опорой на баги платформы недопустимо.*

## Примеры

Неправильно

```bsl
&НаСервере
Процедура ОбработатьДанные() Экспорт
    // ...
КонецПроцедуры

&НаСервереБезКонтекста
Функция ВычислитьИтог() Экспорт
    // ...
КонецФункции
```

Правильно

```bsl
&НаКлиенте
Процедура ОбработатьОповещение() Экспорт
    // доступно для вызова из другой формы
КонецПроцедуры
```
