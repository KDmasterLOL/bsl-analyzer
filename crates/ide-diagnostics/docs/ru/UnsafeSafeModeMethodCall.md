# Небезопасное использование функции БезопасныйРежим() (UnsafeSafeModeMethodCall)

## Описание диагностики

Метод глобального контекста `БезопасныйРежим()` в платформе 8.3 возвращает значение типа `Строка`, если безопасный режим активирован с указанием профиля безопасности. Неявное приведение результата к типу `Булево` (например, в условии `Если БезопасныйРежим() Тогда`) некорректно: непустая строка с именем профиля будет интерпретирована как `Истина`, но логика может отличаться от ожидаемой. Следует явно сравнивать результат со значением `Ложь`.

## Примеры

Неправильно:

```bsl
Если БезопасныйРежим() Тогда
    ОграничитьДоступ();
КонецЕсли;
```

```bsl
Если Не БезопасныйРежим() Тогда
    ВыполнитьПривилегированнуюОперацию();
КонецЕсли;
```

Правильно:

```bsl
Если БезопасныйРежим() <> Ложь Тогда
    ОграничитьДоступ();
КонецЕсли;
```
