# Управляющие конструкции не должны быть вложены слишком глубоко (NestedStatements)

## Описание диагностики

Чрезмерная вложенность управляющих конструкций (`Если`, `Для`, `Для Каждого`, `Пока`, `Попытка`) резко снижает читаемость кода. Глубоко вложенный код сложно понять, протестировать и модифицировать. Рекомендуется выносить внутреннюю логику в отдельные методы или использовать ранний выход из процедуры.

## Примеры

Неправильно

```bsl
Для Каждого Строка Из Таблица Цикл       // Уровень 1
    Если Строка.Активна Тогда             // Уровень 2
        Для Инд = 0 По Строка.Количество Цикл  // Уровень 3
            Попытка                        // Уровень 4
                Если Инд > 0 Тогда        // Уровень 5 — превышение
                    // ...
                КонецЕсли;
            Исключение
            КонецПопытки;
        КонецЦикла;
    КонецЕсли;
КонецЦикла;
```

Правильно

```bsl
Для Каждого Строка Из Таблица Цикл
    Если НЕ Строка.Активна Тогда
        Продолжить;
    КонецЕсли;
    ОбработатьСтроку(Строка);
КонецЦикла;
```
