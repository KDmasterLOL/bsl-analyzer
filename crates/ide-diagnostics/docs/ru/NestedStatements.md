# Управляющие конструкции не должны быть вложены слишком глубоко (NestedStatements)

## Описание диагностики

Диагностика выявляет чрезмерную вложенность управляющих конструкций.

Глубокая вложенность ухудшает читаемость кода, усложняет понимание ветвлений,
тестирование и рефакторинг. На практике это часто признак того, что часть
логики стоит вынести в отдельный метод или упростить за счет ранних выходов.

По умолчанию максимально допустимый уровень вложенности равен `4`, но его
можно изменить через параметр `maxAllowedLevel`.

## Примеры

Неправильно:

```bsl
Если ЧтоТо Тогда
    Если ДопУсловие Тогда
        Для Номер = 0 По 10 Цикл
            Попытка
                Если ЕщеУсловие Тогда
                    // уровень вложенности 5
                КонецЕсли;
            Исключение
            КонецПопытки;
        КонецЦикла;
    КонецЕсли;
КонецЕсли;
```

Правильно:

```bsl
Если НЕ ЧтоТо Тогда
    Возврат;
КонецЕсли;

Если НЕ ДопУсловие Тогда
    Возврат;
КонецЕсли;

ОбработатьЭлементы();
```
