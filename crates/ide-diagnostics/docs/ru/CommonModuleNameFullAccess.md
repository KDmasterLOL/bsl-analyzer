# Пропущен постфикс "ПолныеПрава" (CommonModuleNameFullAccess)

## Описание диагностики

Общие модули с установленным признаком `Привилегированный` выполняются в привилегированном режиме, то есть без проверки прав доступа. Имя такого модуля должно заканчиваться постфиксом `ПолныеПрава` (англ. `FullAccess`). Постфикс явно указывает разработчикам, что код модуля работает с полными правами, что важно учитывать при его вызове и сопровождении.

## Примеры

Допустимые имена: `РаботаСФайламиПолныеПрава`, `ОбновлениеИБПолныеПрава`, `FilesFullAccess`

Недопустимые имена: `РаботаСФайлами`, `ОбновлениеИБ` (при установленном флаге `Привилегированный`)
