# Пропущен постфикс "ПолныеПрава" (CommonModuleNameFullAccess)

## Описание диагностики

Общие модули с установленным признаком `Привилегированный` выполняются в
привилегированном режиме, то есть без обычной проверки прав доступа. Имя
такого модуля должно содержать постфикс `ПолныеПрава` (англ. `FullAccess`).

Этот постфикс явно показывает разработчикам и ревьюерам, что код модуля
работает с полными правами, а значит требует повышенного внимания при
сопровождении и вызове.

## Примеры

Допустимые имена: `РаботаСФайламиПолныеПрава`, `ОбновлениеИБПолныеПрава`, `FilesFullAccess`

Недопустимые имена: `РаботаСФайлами`, `ОбновлениеИБ` (при установленном флаге `Привилегированный`)
