# Инициализация параметров методов и конструкторов вызовом вложенных методов (NestedFunctionInParameters)

## Описание диагностики

При передаче аргументов в функцию или конструктор не следует использовать вложенные вызовы других функций. Цепочки вложенных вызовов затрудняют чтение и отладку кода. Рекомендуется разбивать такие выражения на отдельные операторы с промежуточными переменными.

Исключение допустимо, если вложенный вызов компактен, не требует переноса строки и легко воспринимается визуально.

## Примеры

Неправильно:

```bsl
ОтчетМенеджер.СформироватьОтчет(
    ПолучитьДанныеИзХранилища(
        МенеджерФайлов.ПолучитьАдрес(ФайлСсылка)));
```

Правильно:

```bsl
АдресФайла = МенеджерФайлов.ПолучитьАдрес(ФайлСсылка);
ДанныеФайла = ПолучитьДанныеИзХранилища(АдресФайла);
ОтчетМенеджер.СформироватьОтчет(ДанныеФайла);
```
