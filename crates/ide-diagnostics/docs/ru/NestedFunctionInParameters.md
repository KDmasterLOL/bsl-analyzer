# Инициализация параметров методов и конструкторов вызовом вложенных методов (NestedFunctionInParameters)

## Описание диагностики

Диагностика выявляет вложенные вызовы функций и конструкторы с параметрами,
которые передаются прямо в аргументы других вызовов и конструкторов.

Основная цель правила - сохранить читаемость кода. Длинные цепочки вложенных
вызовов сложнее читать, отлаживать и пошагово анализировать. На практике такой
код обычно понятнее, если разбить выражение на несколько промежуточных
переменных.

При этом компактные однострочные случаи могут быть допустимы. Поэтому
диагностика настраивается: можно разрешить однострочные выражения и оставить в
allowlist отдельные методы, например `НСтр` и `ПредопределенноеЗначение`.

## Примеры

Неправильно:

```bsl
ОтчетМенеджер.СформироватьОтчет(
    ПолучитьДанныеИзХранилища(
        МенеджерФайлов.ПолучитьАдрес(ФайлСсылка)));
```

Правильно:

```bsl
АдресФайла = МенеджерФайлов.ПолучитьАдрес(ФайлСсылка);
ДанныеФайла = ПолучитьДанныеИзХранилища(АдресФайла);
ОтчетМенеджер.СформироватьОтчет(ДанныеФайла);
```
