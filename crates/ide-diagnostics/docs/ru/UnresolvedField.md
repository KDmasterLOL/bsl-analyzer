# Обращение к неизвестному полю (UnresolvedField)

## Описание диагностики

Диагностика сообщает об обращении к полю выражения, тип которого известен достаточно точно, чтобы анализатор мог уверенно сказать: такого поля у этого типа нет.

Обычно это означает одно из следующих:

- в имени поля есть опечатка;
- код ожидает другой тип объекта метаданных;
- выражение на самом деле может иметь другой тип или быть `Неопределено`, но это не отражено в коде явно.

Текущая реализация консервативна. Она срабатывает только там, где inference уже получил уверенный metadata-based тип и lookup поля для этого типа завершился неуспешно. Для модулей заимствованных управляемых форм в расширении анализатор также сверяет элементы из сохранённого `<BaseForm>` с актуальной целевой конфигурацией: ссылка `Элементы.<Имя>` считается ошибочной, если элемент был заимствован из старой базовой формы, но отсутствует в текущей базе. Элементы, добавленные самим расширением, при этом не считаются ошибкой.

## Примеры

Неправильно:

```bsl
Ссылка = ОбщийМодуль.ПолучитьСсылку();
Наименование = Ссылка.НесуществующееПоле;
```

Правильно:

```bsl
Ссылка = ОбщийМодуль.ПолучитьСсылку();
Наименование = Ссылка.Наименование;
```
