# Некорректное использование метода ОтменитьТранзакцию() (WrongUseOfRollbackTransactionMethod)

## Описание диагностики

Метод `ОтменитьТранзакцию` должен вызываться внутри блока `Исключение` конструкции `Попытка-Исключение`. При этом `ОтменитьТранзакцию` должен быть первым значимым действием в блоке обработки ошибки -- до записи в журнал регистрации и других операций.

## Примеры

### Неправильно

```bsl
НачатьТранзакцию();
Попытка
    Документ.Записать();
    ЗафиксироватьТранзакцию();
Исключение
    ЗаписьЖурналаРегистрации("Ошибка записи",
        УровеньЖурналаРегистрации.Ошибка,,,
        ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
    ОтменитьТранзакцию(); // Неверно: откат должен быть первым действием
    ВызватьИсключение;
КонецПопытки;
```

### Правильно

```bsl
НачатьТранзакцию();
Попытка
    Документ.Записать();
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ЗаписьЖурналаРегистрации("Ошибка записи",
        УровеньЖурналаРегистрации.Ошибка,,,
        ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
    ВызватьИсключение;
КонецПопытки;
```
