# Использование служебных тегов (UsingServiceTag)

## Описание диагностики

Диагностика обнаруживает служебные теги, оставленные в комментариях исходного кода. Такие теги обычно указывают на незавершённую работу, временные решения или автогенерированный код, который не был заменён реальной реализацией. Перечень отслеживаемых тегов:

* TODO
* FIXME
* !!
* @
* MRG
* ОТЛАДКА
* ДЛЯ ОТЛАДКИ
* КОНСТРУКТОР_ЗАПРОСА_С_ОБРАБОТКОЙ_РЕЗУЛЬТАТА
* КОНСТРУКТОР_ДВИЖЕНИЙ_РЕГИСТРОВ
* КОНСТРУКТОР_ПЕЧАТИ
* КОНСТРУКТОР_ВВОДА_НА_ОСНОВАНИИ
* Вставить содержимое обработчика
* Insert handler code
* Insert handler contents
* Paste handler content

Перечень тегов может быть расширен через настройки диагностики.
