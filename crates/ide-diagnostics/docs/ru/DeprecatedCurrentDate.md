# Использование устаревшего метода "ТекущаяДата" (DeprecatedCurrentDate)

## Описание диагностики

Функция `ТекущаяДата()` возвращает дату и время компьютера, на котором выполняется код. В клиент-серверной архитектуре и в модели SaaS часовой пояс сервера может не совпадать с часовым поясом пользователя, что приводит к некорректным значениям дат в документах и отчётах.

В серверном коде вместо `ТекущаяДата()` следует использовать `ТекущаяДатаСеанса()`, которая автоматически приводит серверное время к часовому поясу пользовательского сеанса. В клиентском коде `ТекущаяДата()` также недопустима, поскольку значения времени, полученные на клиенте и сервере, не должны расходиться.

При использовании БСП рекомендуется вызывать `ОбщегоНазначенияКлиент.ДатаСеанса()`.

## Примеры

### На сервере

Неправильно:

```bsl
ДатаОтгрузки = ТекущаяДата();
```

Правильно:

```bsl
ДатаОтгрузки = ТекущаяДатаСеанса();
```

### На клиенте

Неправильно:

```bsl
ДатаДокумента = ТекущаяДата();
```

Правильно:

```bsl
ДатаДокумента = ОбщегоНазначенияКлиент.ДатаСеанса();
```
