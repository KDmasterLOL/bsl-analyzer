# Неопределённое имя (UnresolvedName)

Диагностика сообщает о чтении голого имени, отсутствие которого доказано во всех
применимых локальных, модульных, пользовательских глобальных и платформенных
поверхностях.

Правило не срабатывает, если какая-либо поверхность неполна: например, тело
глобального общего модуля не прочитано или версия встроенного каталога платформы
не подтверждена. Неизвестный член известного объекта относится к другой
диагностике.

## Пример

```bsl
Результат = НеизвестноеИмя.Свойство;
```

Исправьте имя либо объявите соответствующую переменную, метод или глобальный
символ.
