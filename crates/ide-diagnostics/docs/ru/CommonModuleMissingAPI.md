# Общий модуль должен иметь программный интерфейс (CommonModuleMissingAPI)

## Описание диагностики

Если общий модуль или модуль менеджера содержит методы, у него должна быть
понятная структура программного интерфейса. На практике это означает:

- наличие хотя бы одного экспортного метода;
- наличие области `ПрограммныйИнтерфейс` или
  `СлужебныйПрограммныйИнтерфейс`.

Без экспортных методов и API-областей модуль теряет четкую границу между
внешним контрактом и внутренней реализацией, а его структура перестает
соответствовать принятому для 1С разделению кода.

## Примеры

### Неправильно

```bsl
Процедура ВнутренняяОбработка(Данные)
    Данные = Данные + 1;
КонецПроцедуры
```

### Правильно

```bsl
#Область СлужебныйПрограммныйИнтерфейс

Процедура ОбработатьДанные(Данные) Экспорт
    Данные = Данные + 1;
КонецПроцедуры

#КонецОбласти
```
