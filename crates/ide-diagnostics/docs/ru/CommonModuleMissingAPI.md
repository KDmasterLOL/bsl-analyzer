# Общий модуль должен иметь программный интерфейс (CommonModuleMissingAPI)

## Описание диагностики

Каждый общий модуль должен содержать как минимум один экспортный метод и область `ПрограммныйИнтерфейс` (или `СлужебныйПрограммныйИнтерфейс`). Общий модуль без экспортных методов не может быть использован другими объектами конфигурации, что противоречит самому назначению общих модулей -- предоставлять общедоступную функциональность.

## Примеры

### Неправильно

```bsl
Процедура ВнутренняяОбработка(Данные)
    Данные = Данные + 1;
КонецПроцедуры
```

### Правильно

```bsl
#Область СлужебныйПрограммныйИнтерфейс

Процедура ОбработатьДанные(Данные) Экспорт
    Данные = Данные + 1;
КонецПроцедуры

#КонецОбласти
```
