# Передача параметров между клиентом и сервером (TransferringParametersBetweenClientAndServer)

## Описание диагностики

При вызове серверного метода с клиента параметры копируются в обе стороны: на сервер при вызове и обратно на клиент при возврате управления. Если параметр не изменяется на сервере, обратное копирование является избыточным и расходует ресурсы.

Модификатор `Знач` перед параметром отключает обратную передачу значения. Его следует указывать для всех параметров серверного метода, которые не должны возвращать изменения на клиент.

Диагностика находит серверные методы, вызываемые из клиентских, и отмечает параметры без модификатора `Знач`, значение которых не изменяется внутри серверного метода.

## Примеры

Неправильно:

```bsl
&НаСервереБезКонтекста
Функция ПолучитьОстатокНаСкладе(Номенклатура, Склад)
    Возврат РегистрыНакопления.ОстаткиТоваров.ПолучитьОстаток(Номенклатура, Склад);
КонецФункции

&НаКлиенте
Процедура ПоказатьОстаток(Команда)
    Остаток = ПолучитьОстатокНаСкладе(ТекущаяНоменклатура, ТекущийСклад);
    ПоказатьОповещениеПользователя("Остаток: " + Остаток);
КонецПроцедуры
```

Правильно — параметры помечены как `Знач`, поскольку не модифицируются:

```bsl
&НаСервереБезКонтекста
Функция ПолучитьОстатокНаСкладе(Знач Номенклатура, Знач Склад)
    Возврат РегистрыНакопления.ОстаткиТоваров.ПолучитьОстаток(Номенклатура, Склад);
КонецФункции

&НаКлиенте
Процедура ПоказатьОстаток(Команда)
    Остаток = ПолучитьОстатокНаСкладе(ТекущаяНоменклатура, ТекущийСклад);
    ПоказатьОповещениеПользователя("Остаток: " + Остаток);
КонецПроцедуры
```

## Параметры

### cachedValueNames

Тип: `Строка`
Значение по умолчанию: `` (пустая строка)

Список имен параметров, разделенных запятыми, которые должны игнорироваться диагностикой, если в модуле существует переменная с таким же именем и директивой компиляции `&НаКлиенте`.

Это полезно для кэшируемых значений, которые специально передаются с сервера на клиент для хранения в переменных модуля формы.

Пример:

```json
{
  "TransferringParametersBetweenClientAndServer": {
    "cachedValueNames": "КэшированныеЗначения,КэшДанных"
  }
}
```

Если в коде есть объявление:

```bsl
&НаКлиенте
Перем КэшированныеЗначения;
```

То следующий код не будет генерировать замечание:

```bsl
&НаКлиенте
Процедура ПриИзмененииРеквизита()
    ОбновитьКэш(КэшированныеЗначения);
КонецПроцедуры

&НаСервере
Процедура ОбновитьКэш(КэшированныеЗначения)
    КэшированныеЗначения = ПолучитьДанныеНаСервере();
КонецПроцедуры
```
