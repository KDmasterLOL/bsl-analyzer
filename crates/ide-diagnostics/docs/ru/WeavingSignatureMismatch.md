# Несоответствие сигнатуры перехватчика (WeavingSignatureMismatch)

## Описание диагностики

Расширение конфигурации может перехватывать метод расширяемого модуля с помощью
аннотаций `&Вместо`, `&Перед` или `&После`. Платформа применяет такой перехватчик
только тогда, когда его сигнатура в точности совпадает с расширяемым методом:

- должно совпадать **количество параметров**;
- по каждому параметру должен совпадать признак передачи по значению — ключевое
  слово `Знач`;
- перехватчик `&Вместо` должен быть того же **вида**, что и расширяемый метод:
  функцию можно заменить только функцией, процедуру — только процедурой
  (расширяемую функцию вообще можно расширить лишь аннотацией `&Вместо`).

Если сигнатуры расходятся, расширение не проходит проверку применимости и
перехват молча не выполняется, поэтому такое расхождение — реальная ошибка.

Имена параметров могут отличаться (рекомендуется префикс), а значения по
умолчанию в перехватчике не указываются — они берутся из расширяемого метода и
не сравниваются.

## Примеры

### Неправильно

```bsl
// Расширяемый метод: Процедура ПриЗаписи(Отказ, ПараметрыЗаписи)

&Перед("ПриЗаписи")
Процедура Расш1_ПриЗаписи(Отказ) // один параметр вместо двух
    // ...
КонецПроцедуры
```

### Правильно

```bsl
&Перед("ПриЗаписи")
Процедура Расш1_ПриЗаписи(Отказ, ПараметрыЗаписи)
    // ...
КонецПроцедуры
```
