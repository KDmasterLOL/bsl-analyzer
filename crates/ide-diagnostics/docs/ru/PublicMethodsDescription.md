# Все методы программного интерфейса должны иметь описание (PublicMethodsDescription)

## Описание диагностики

Каждая экспортная процедура или функция, размещённая в области "ПрограммныйИнтерфейс", обязана иметь документирующий комментарий. Отсутствие описания у публичных методов затрудняет их использование другими разработчиками.

## Примеры

Неправильно:

```bsl
#Область ПрограммныйИнтерфейс

Функция ПолучитьКурсВалюты(Валюта, Дата) Экспорт
    // ...
КонецФункции

#КонецОбласти
```

Правильно:

```bsl
#Область ПрограммныйИнтерфейс

// Возвращает курс указанной валюты на заданную дату.
//
// Параметры:
//  Валюта - СправочникСсылка.Валюты - валюта, курс которой запрашивается.
//  Дата - Дата - дата, на которую нужен курс.
//
// Возвращаемое значение:
//  Число - курс валюты.
//
Функция ПолучитьКурсВалюты(Валюта, Дата) Экспорт
    // ...
КонецФункции

#КонецОбласти
```
