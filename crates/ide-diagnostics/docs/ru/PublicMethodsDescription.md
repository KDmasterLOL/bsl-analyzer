# Все методы программного интерфейса должны иметь описание (PublicMethodsDescription)

## Описание диагностики

Диагностика выявляет экспортные методы без документирующего комментария.

Публичная логика правила опирается на рекомендации 1С по описанию процедур и
функций. В текущем проекте поведение по умолчанию уже, чем просто “все
экспортные методы”: по умолчанию проверяются только методы из области
`ПрограммныйИнтерфейс` / `Public`. Если включить `checkAllRegion = true`,
проверяются экспортные методы независимо от области.

## Примеры

Неправильно:

```bsl
#Область ПрограммныйИнтерфейс

Функция ПолучитьКурсВалюты(Валюта, Дата) Экспорт
КонецФункции

#КонецОбласти
```

Правильно:

```bsl
#Область ПрограммныйИнтерфейс

// Возвращает курс указанной валюты на заданную дату.
Функция ПолучитьКурсВалюты(Валюта, Дата) Экспорт
КонецФункции

#КонецОбласти
```
