# Хранение путей к файлам в коде (UsingHardcodePath)

## Описание диагностики

Не допускается жёсткое указание путей к файлам и каталогам (Windows, Unix) непосредственно в исходном коде. Такие значения привязаны к конкретной среде и делают код непереносимым.

Рекомендуемые способы хранения путей:

* Константа информационной базы.
* Регистр сведений.
* Справочник, узел плана обмена и другие объекты метаданных.
* Отдельный модуль с отключённой проверкой данного правила (не рекомендуется).

### Особенности

Текущая реализация, наоборот, исключает строки, похожие на URL с протоколами `http`, `https`, `ftp`, чтобы не давать лишних ложных срабатываний.

## Примеры

### Неправильно

```bsl
ПутьВыгрузки = "d:/backup/data";
```

### Правильно

```bsl
ПутьВыгрузки = Константы.КаталогВыгрузки.Получить();
```

или

```bsl
ПутьВыгрузки = НастройкиОбменаПовтИсп.КаталогВыгрузки();
```
