# Использование синхронных вызовов (UsingSynchronousCalls)

## Описание диагностики

Для конфигураций, работающих в веб-клиенте, недопустимо использование синхронных вызовов и модальных диалогов. Модальные окна не поддерживаются стандартами веб-разработки, и ряд браузеров блокирует их работу. Для взаимодействия с пользователем необходимо применять асинхронные аналоги соответствующих методов.

### Ограничение диагностики

В текущей реализации проверяются **только вызовы методов глобального контекста**.
