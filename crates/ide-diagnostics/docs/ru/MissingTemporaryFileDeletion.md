# Отсутствует удаление временного файла после использования (MissingTemporaryFileDeletion)

## Описание диагностики

По завершении работы с временным файлом или каталогом его необходимо удалять явно. Не следует рассчитывать на автоматическую очистку при перезапуске платформы: накопление неудалённых файлов может привести к исчерпанию свободного пространства в каталоге временных файлов.

## Примеры

Неправильно:

```bsl
ПутьКФайлу = ПолучитьИмяВременногоФайла("csv");
ТаблицаДанных.Записать(ПутьКФайлу);
// Временный файл не удаляется
```

Правильно:

```bsl
ПутьКФайлу = ПолучитьИмяВременногоФайла("csv");
ТаблицаДанных.Записать(ПутьКФайлу);

// Обработка файла
// ...

// Удаление временного файла
Попытка
    УдалитьФайлы(ПутьКФайлу);
Исключение
    ЗаписьЖурналаРегистрации(НСтр("ru = 'Обработка данных'"),
        УровеньЖурналаРегистрации.Ошибка,,,
        ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
КонецПопытки;
```

## Особенности работы

Диагностика проверяет наличие вызова удаления или перемещения файла после его создания.

Если в прикладном решении применяется собственный метод удаления или перемещения поверх платформенного, его имя следует добавить в параметр диагностики через разделитель `|`. Поддерживаются глобальные методы, методы общих модулей и модулей менеджеров.

Примеры настройки:

- Глобальный метод `УдалитьВременныйФайл` указывается как `УдалитьВременныйФайл`
- Метод `УдалитьВременныйФайл` в общем модуле `РаботаСФайлами` указывается как `РаботаСФайлами.УдалитьВременныйФайл`
- Метод `УдалитьВременныйФайл` в модуле менеджера справочника `ВременныеДанные` указывается как `Справочники.ВременныеДанные.УдалитьВременныйФайл`
