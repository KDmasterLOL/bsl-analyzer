# Повторяющиеся разделы модуля (DuplicateRegion)

## Описание диагностики

Код модуля должен быть организован в области (директива `#Область`), при этом каждая область должна встречаться не более одного раза. Наличие нескольких областей с одинаковым именем нарушает структуру модуля, затрудняет навигацию и может свидетельствовать о результате неудачного слияния веток.

## Примеры

### Неправильно

```bsl
#Область ОбработчикиСобытий

Процедура ПриОткрытии(Отказ)
    // ...
КонецПроцедуры

#КонецОбласти

#Область ОбработчикиСобытий // дубль -- вторая область с тем же именем

Процедура ПриЗакрытии()
    // ...
КонецПроцедуры

#КонецОбласти
```

### Правильно

```bsl
#Область ОбработчикиСобытий

Процедура ПриОткрытии(Отказ)
    // ...
КонецПроцедуры

Процедура ПриЗакрытии()
    // ...
КонецПроцедуры

#КонецОбласти
```
