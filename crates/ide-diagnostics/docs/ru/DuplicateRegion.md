# Повторяющиеся разделы модуля (DuplicateRegion)

## Описание диагностики

Код модуля должен быть организован в области, при этом каждая верхнеуровневая область должна встречаться не более одного раза. Повторяющиеся разделы нарушают структуру модуля, затрудняют навигацию и часто появляются после неудачного дробления кода или слияния веток.

Для стандартных областей диагностика считает русские и английские имена эквивалентными. Например, `ПрограммныйИнтерфейс` и `Public` рассматриваются как один и тот же раздел.

Регистр имени не важен: идентификаторы в BSL регистронезависимы, поэтому `#Область Расчёты` и `#Область РАСЧЁТЫ` — один и тот же раздел.

## Примеры

### Неправильно

```bsl
#Область ОбработчикиСобытий

Процедура ПриОткрытии(Отказ)
    // ...
КонецПроцедуры

#КонецОбласти

#Область ОбработчикиСобытий // дубль -- вторая область с тем же именем

Процедура ПриЗакрытии()
    // ...
КонецПроцедуры

#КонецОбласти
```

### Правильно

```bsl
#Область ОбработчикиСобытий

Процедура ПриОткрытии(Отказ)
    // ...
КонецПроцедуры

Процедура ПриЗакрытии()
    // ...
КонецПроцедуры

#КонецОбласти
```
