# Приведение к числу в попытке (TryNumber)

## Описание диагностики

Использование конструкции `Попытка...Исключение` для преобразования значения к числу считается неудачным подходом. Перехват исключений предназначен для обработки действительно исключительных ситуаций, а не для штатного приведения типов.

Текущая реализация диагностики помечает вызовы `Число()` / `Number()`, которые находятся внутри части `Попытка` блока `Попытка...Исключение`.

## Примеры

Неправильно:

```bsl
Попытка
    Цена = Число(ВведённоеЗначение);
Исключение
    Цена = 0;
КонецПопытки;
```

Правильно:

```bsl
ТипЧисло = Новый ОписаниеТипов("Число");
Цена = ТипЧисло.ПривестиЗначение(ВведённоеЗначение);
```
