# Приведение к числу в попытке (TryNumber)

## Описание диагностики

Использование конструкции `Попытка...Исключение` для преобразования значения к числу является неэффективным подходом. Перехват исключений предназначен для обработки непредвиденных ситуаций, а не для приведения типов. Для безопасного преобразования следует применять объект `ОписаниеТипов`.

## Примеры

Неправильно:

```bsl
Попытка
    Цена = Число(ВведённоеЗначение);
Исключение
    Цена = 0;
КонецПопытки;
```

Правильно:

```bsl
ТипЧисло = Новый ОписаниеТипов("Число");
Цена = ТипЧисло.ПривестиЗначение(ВведённоеЗначение);
```
