# Все возможные пути выполнения функции должны содержать оператор Возврат (AllFunctionPathMustHaveReturn)

## Описание диагностики

В языке 1С любая функция, в которой выполнение достигает строки `КонецФункции` без явного оператора `Возврат`, автоматически возвращает значение `Неопределено`. Такое поведение зачастую является непреднамеренным и приводит к трудноуловимым ошибкам.

Диагностика выявляет функции, в которых существует хотя бы один путь выполнения без явного оператора `Возврат`. Разработчик должен убедиться, что каждая ветвь кода завершается возвратом ожидаемого значения. Если возврат `Неопределено` предусмотрен логикой, это следует указать явно: `Возврат Неопределено`.

## Примеры

### Неправильно

```bsl
// При значении Категория, отличном от "A" и "B", функция неявно вернёт Неопределено
Функция ПолучитьКоэффициентСкидки(Знач Категория)
    Если Категория = "A" Тогда
        Возврат 0.15;
    ИначеЕсли Категория = "B" Тогда
        Возврат 0.10;
    КонецЕсли;

    // неявный Возврат Неопределено
КонецФункции
```

### Правильно

```bsl
Функция ПолучитьКоэффициентСкидки(Знач Категория)
    Если Категория = "A" Тогда
        Возврат 0.15;
    ИначеЕсли Категория = "B" Тогда
        Возврат 0.10;
    КонецЕсли;

    Возврат 0;
КонецФункции
```

### Ещё пример ошибочного кода

```bsl
// В ветви ИначеЕсли пропущен оператор Возврат перед вызовом функции
Функция ВычислитьИтог(Знач Документ)
    Если Документ.Вид = "Приход" Тогда
        Возврат Документ.Сумма;
    ИначеЕсли Документ.Вид = "Расход" Тогда
        // забыли написать Возврат
        ВычислитьСуммуРасхода(Документ);
    Иначе
        Возврат 0;
    КонецЕсли;
КонецФункции
```
