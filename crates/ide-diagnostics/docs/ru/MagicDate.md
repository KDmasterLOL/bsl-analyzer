# Магические даты (MagicDate)

## Описание диагностики

Магическая дата -- это литерал даты в коде, смысл которого невозможно понять без изучения окружающего контекста. Такие значения затрудняют чтение и сопровождение кода. Рекомендуется выносить даты в именованные переменные или возвращать их из функций с говорящими названиями.

## Примеры

Неправильно:

```bsl
Если ТекущаяДата < '20240301' Тогда
    ПрименитьСтаруюСтавку = Истина;
КонецЕсли;
```

Правильно -- дата вынесена в переменную:

```bsl
ДатаИзмененияСтавки = '20240301';
Если ТекущаяДата < ДатаИзмененияСтавки Тогда
    ПрименитьСтаруюСтавку = Истина;
КонецЕсли;
```

Правильно -- дата возвращается из функции:

```bsl
Функция ДатаИзмененияСтавкиНДС()
    Возврат '20240301';
КонецФункции

Если ТекущаяДата < ДатаИзмененияСтавкиНДС() Тогда
    ПрименитьСтаруюСтавку = Истина;
КонецЕсли;
```

## Исключения

Литералы дат в операциях со структурами и соответствиями не считаются ошибкой, так как контекст использования определяется ключом или именем свойства:

```bsl
// Вставка в структуру
Параметры = Новый Структура;
Параметры.Вставить("ДатаНачалаДействия", '20240101');
Параметры.Вставить("ДатаОкончанияДействия", '20241231');

// Конструктор структуры
Период = Новый Структура("Начало, Конец", '20240101', '20241231');

// Присваивание свойству структуры
Настройки = Новый Структура("ДатаЗапуска, ДатаОстановки");
Настройки.ДатаЗапуска = '20240601';
Настройки.ДатаОстановки = '20240630';

// Фиксированная структура
ФиксПараметры = Новый ФиксированнаяСтруктура("Дата", '20240101');

// Соответствие (как ключ или значение)
Даты = Новый Соответствие;
Даты.Вставить("Релиз", '20240315');
Даты.Вставить('19610412', "Полёт Гагарина");
```
