# Защищенные модули (ProtectedModule)

## Описание диагностики

Наличие защищённых (запароленных) модулей в конфигурации нежелательно. Когда исходный код модуля недоступен, невозможно провести ревью, отследить историю изменений в системе контроля версий и обеспечить надлежащий контроль качества кода.
