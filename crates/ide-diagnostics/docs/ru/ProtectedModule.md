# Защищенные модули (ProtectedModule)

## Описание диагностики

Диагностика выявляет защищенные паролем общие модули, найденные в метаданных
конфигурации.

Когда общий модуль защищен, его исходный код недоступен в обычном текстовом
виде. Это затрудняет ревью, аудит, поиск по коду и нормальную работу с
системой контроля версий. Поэтому такие модули требуют отдельного внимания.

В текущем проекте диагностика вычисляется только из `SessionModule` и создает
по одной диагностике на каждый защищенный общий модуль, найденный в
метаданных.
