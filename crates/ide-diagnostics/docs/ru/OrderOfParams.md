# Порядок параметров метода (OrderOfParams)

## Описание диагностики

Параметры со значениями по умолчанию (необязательные) должны располагаться после обязательных параметров в сигнатуре процедуры или функции. Нарушение этого порядка приводит к путанице при вызове метода и затрудняет чтение кода.

## Примеры

Неправильно:

```bsl
Функция РассчитатьСкидку(Процент = 5, СуммаПродажи)
КонецФункции
```

Правильно:

```bsl
Функция РассчитатьСкидку(СуммаПродажи, Процент = 5)
КонецФункции
```
