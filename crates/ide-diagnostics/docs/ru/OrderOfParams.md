# Порядок параметров метода (OrderOfParams)

## Описание диагностики

Диагностика выявляет процедуры и функции, в которых параметры со значениями по
умолчанию объявлены раньше обязательных параметров.

Логика правила опирается на рекомендации 1С по оформлению параметров процедур и
функций: необязательные параметры должны располагаться после обязательных.
Нарушение этого порядка ухудшает читаемость сигнатуры и создает путаницу при
вызове метода.

## Примеры

Неправильно:

```bsl
Функция РассчитатьСкидку(Процент = 5, СуммаПродажи)
КонецФункции
```

Правильно:

```bsl
Функция РассчитатьСкидку(СуммаПродажи, Процент = 5)
КонецФункции
```
