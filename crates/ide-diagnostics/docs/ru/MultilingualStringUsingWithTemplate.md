# Частично локализованный текст используется в функции СтрШаблон (MultilingualStringUsingWithTemplate)

## Описание диагностики

В мультиязычной конфигурации функция `НСтр` должна содержать тексты для всех заявленных языков. Если для какого-либо языка перевод отсутствует, `НСтр` возвращает пустую строку. При передаче такой пустой строки в функцию `СтрШаблон` будет выброшено исключение, поскольку `СтрШаблон` не может обработать пустой шаблон.

Текущая реализация уже, чем общая проверка `НСтр`:

- обязательные языки берутся из настройки `declaredLanguages`;
- по умолчанию считается, что обязателен только `ru`;
- проверяются только те `НСтр`, которые напрямую используются в `СтрШаблон`, либо сначала присваиваются переменной, а потом эта переменная передается в `СтрШаблон`;
- вызовы `НСтр` вне template-контекста эта диагностика намеренно игнорирует;
- пустой вызов `НСтр()` в template-контексте считается ошибкой для всех заявленных языков.

## Примеры

Конфигурация поддерживает языки `ru` и `en`.

Неправильно -- при запуске под английской локалью `НСтр` вернёт пустую строку и `СтрШаблон` вызовет ошибку:

```bsl
Текст = СтрШаблон(НСтр("ru = 'Обработано %1 из %2 документов'"), Обработано, Всего);
```

Правильно:

```bsl
Текст = СтрШаблон(НСтр("ru = 'Обработано %1 из %2 документов'; en = 'Processed %1 of %2 documents'"), Обработано, Всего);
```
