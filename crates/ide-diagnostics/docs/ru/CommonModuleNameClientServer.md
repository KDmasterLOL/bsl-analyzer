# Пропущен постфикс "КлиентСервер" (CommonModuleNameClientServer)

## Описание диагностики

Клиент-серверные общие модули содержат процедуры и функции, логика которых одинакова и на клиенте, и на сервере. Использование единого модуля позволяет избежать дублирования кода. У таких модулей установлены признаки:

* Клиент (управляемое приложение)
* Сервер (флаг `Вызов сервера` снят)
* Клиент (обычное приложение)
* Внешнее соединение

Имя клиент-серверного модуля должно заканчиваться постфиксом `КлиентСервер` (англ. `ClientServer`).

## Примеры

Допустимые имена: `РаботаСФайламиКлиентСервер`, `ОбщегоНазначенияКлиентСервер`, `UsersClientServer`

Недопустимые имена: `РаботаСФайлами`, `ОбщегоНазначения` (при клиент-серверных признаках модуля)
