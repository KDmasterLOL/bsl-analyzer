# Удаление элемента при обходе коллекции посредством оператора "Для каждого ... Из ... Цикл" (DeletingCollectionItem)

## Описание диагностики

Удаление элементов коллекции непосредственно внутри цикла `Для каждого ... Из ... Цикл` приводит к непредсказуемому поведению. После удаления элемента индексы оставшихся элементов сдвигаются, в результате чего часть элементов может быть пропущена или возникнет ошибка времени выполнения.

Для безопасного удаления элементов по условию следует обходить коллекцию с конца к началу, используя числовой индекс.

## Примеры

Неправильно:

```bsl
Для Каждого Строка Из ТаблицаДанных Цикл
    Если Строка.Пометка Тогда
        ТаблицаДанных.Удалить(Строка);
    КонецЕсли;
КонецЦикла;
```

Правильно:

```bsl
Индекс = ТаблицаДанных.Количество() - 1;
Пока Индекс >= 0 Цикл
    Если ТаблицаДанных[Индекс].Пометка Тогда
        ТаблицаДанных.Удалить(Индекс);
    КонецЕсли;
    Индекс = Индекс - 1;
КонецЦикла;
```
