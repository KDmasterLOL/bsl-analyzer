# Запрет незаполненных значений у измерений регистров (DenyIncompleteValues)

## Описание диагностики

Измерения регистров, как правило, должны содержать конкретные значения. Записи с пустыми измерениями обычно не несут смысловой нагрузки и свидетельствуют об ошибке при вводе или в программном коде.

Платформа предоставляет встроенный механизм контроля -- флаг "Запрет незаполненных значений" для измерений регистра. При его включении система автоматически проверяет заполненность измерений как при интерактивном, так и при программном создании записей. Это избавляет от необходимости реализовывать аналогичные проверки вручную.

Диагностика применяется к измерениям следующих регистров:

- сведений
- накопления
- бухгалтерских
- расчетных

Возможны ложные срабатывания для измерений, которые допускают пустые значения по бизнес-логике.
