# Пропущены пробелы слева или справа от операторов `+ - * / = % < > <> <= >=`, от ключевых слов, а так же справа от `,` и `;` (MissingSpace)

## Описание диагностики

Для повышения читаемости кода необходимо ставить пробелы по обе стороны от операторов `+ - * / = % < > <> <= >=`. После запятой `,` и точки с запятой `;` также должен стоять пробел.

## Примеры

Неправильно:

```bsl
Процедура РассчитатьИтоги(Цена,Количество)
    Если Цена>0 Тогда
        Итого=Цена*Количество;
    КонецЕсли;
КонецПроцедуры
```

Правильно:

```bsl
Процедура РассчитатьИтоги(Цена, Количество)
    Если Цена > 0 Тогда
        Итого = Цена * Количество;
    КонецЕсли;
КонецПроцедуры
```

### Использование параметра `checkSpaceToRightOfUnary`

Параметр влияет на проверку унарных операторов (актуален, только если унарный оператор указан в одном из основных параметров).

При значении `false`:

```bsl
Б = -А;     // Правильно
Б = - А;    // Правильно
```

При значении `true`:

```bsl
Б = -А;     // Неправильно
Б = - А;    // Правильно
```

### Использование параметра `allowMultipleCommas`

Параметр применяется, только если `,` включена в основные параметры. Значение по умолчанию -- `false`.

При значении `false`:

```bsl
    Метод(Значение1,,,, Значение5);        // Неправильно
    Метод(Значение1, , , , Значение5);      // Правильно
```

При значении `true`:

```bsl
    Метод(Значение1,,,, Значение5);        // Правильно
    Метод(Значение1, , , , Значение5);      // Правильно
```
