# Повторяющиеся условия в синтаксической конструкции Если...Тогда...ИначеЕсли... (IfElseDuplicatedCondition)

## Описание диагностики

В конструкции `Если...Тогда...ИначеЕсли...` каждое условие должно быть уникальным. Повторение одного и того же выражения в нескольких ветвях `ИначеЕсли` означает, что повторный блок кода никогда не будет выполнен, поскольку условие уже обработано ранее. Как правило, это следствие ошибки копирования.

## Примеры

Неправильно:
```bsl
Если Категория = "А" Тогда
    Коэффициент = 1.5;
ИначеЕсли Категория = "Б" Тогда
    Коэффициент = 1.2;
ИначеЕсли Категория = "Б" Тогда
    Коэффициент = 1.0;
Иначе
    Коэффициент = 0.8;
КонецЕсли;
```

Правильно:
```bsl
Если Категория = "А" Тогда
    Коэффициент = 1.5;
ИначеЕсли Категория = "Б" Тогда
    Коэффициент = 1.2;
ИначеЕсли Категория = "В" Тогда
    Коэффициент = 1.0;
Иначе
    Коэффициент = 0.8;
КонецЕсли;
```
