# Повторяющиеся условия в синтаксической конструкции Если...Тогда...ИначеЕсли... (IfElseDuplicatedCondition)

## Описание диагностики

Диагностика отмечает повтор одного и того же условия внутри одной цепочки
`Если` / `ИначеЕсли`.

Если одинаковое условие встречается повторно, более поздняя ветвь фактически
становится недостижимой: тот же случай уже обработан выше. На практике это
обычно означает ошибку копирования или незавершённое редактирование.

## Примеры

Неправильно:
```bsl
Если Категория = "А" Тогда
    Коэффициент = 1.5;
ИначеЕсли Категория = "Б" Тогда
    Коэффициент = 1.2;
ИначеЕсли Категория = "Б" Тогда
    Коэффициент = 1.0;
Иначе
    Коэффициент = 0.8;
КонецЕсли;
```

Правильно:
```bsl
Если Категория = "А" Тогда
    Коэффициент = 1.5;
ИначеЕсли Категория = "Б" Тогда
    Коэффициент = 1.2;
ИначеЕсли Категория = "В" Тогда
    Коэффициент = 1.0;
Иначе
    Коэффициент = 0.8;
КонецЕсли;
```

## Источники

Для этой диагностики нет прямого нормативного стандарта 1С. Это локальная
проверка на подозрительные повторяющиеся условия, реализованная в
`bsl-analyzer`.
