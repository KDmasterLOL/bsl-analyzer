# Ошибка разбора текста запроса (QueryParseError)

## Описание диагностики

Текст запроса должен формироваться так, чтобы его можно было открыть в конструкторе запросов. Динамическая сборка текста запроса через конкатенацию строк нарушает это требование и делает невозможной автоматическую проверку синтаксиса, а также существенно затрудняет дальнейшую доработку и сопровождение кода.

Вместо склеивания строк следует использовать подстановку параметров с последующей заменой через `СтрЗаменить`.

## Примеры

Неправильно

```bsl
ТекстЗапроса = "ВЫБРАТЬ
| Товары.Наименование КАК Наименование,
| Товары." + ИмяКолонки + " КАК ДопРеквизит
|ИЗ
| Справочник.Товары КАК Товары";
```

Правильно

```bsl
ТекстЗапроса = "ВЫБРАТЬ
| Товары.Наименование КАК Наименование,
| Товары.&ИмяДопКолонки КАК ДопРеквизит
|ИЗ
| Справочник.Товары КАК Товары";

ТекстЗапроса = СтрЗаменить(ТекстЗапроса,
                            "&ИмяДопКолонки",
                            ИмяКолонки);
```
