# Ошибка разбора текста запроса (QueryParseError)

## Описание диагностики

Диагностика сообщает о тексте запроса, который содержит синтаксические ошибки и не разбирается корректно.

## Примеры

Неправильно

```bsl
ТекстЗапроса = "ВЫБРАТЬ Поле
|ИЗ Справочник.Товары КАК";
```

Правильно

```bsl
ТекстЗапроса = "ВЫБРАТЬ Поле
|ИЗ Справочник.Товары КАК Товары";
```
