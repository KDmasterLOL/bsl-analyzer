# Неверное использование "СтрШаблон" (IncorrectUseOfStrTemplate)

## Описание диагностики

Диагностика проверяет корректность использования API `СтрШаблон`.

Текущая реализация выявляет несколько типовых ошибок:

- число аргументов не соответствует подстановкам в шаблоне;
- используются недопустимые номера подстановок, например `%0` или `%11`;
- неверно обрабатываются экранированные `%%`;
- шаблон передаётся через переменную, которая в итоге разворачивается в
  некорректную строку;
- из-за неправильно расставленных скобок вокруг `НСтр(...)` вызов получает
  неверное выражение шаблона.

Также важно помнить:

- `СтрШаблон` поддерживает подстановки от `%1` до `%10`;
- если сразу после подстановки должна идти цифра, нужно использовать запись со
  скобками: `"%(1)45"`.

## Примеры

Некорректно: число аргументов не совпадает с подстановками
```bsl
Текст = СтрШаблон("Документ №%1 от %2");
Текст = СтрШаблон("Склад: %1, Ячейка: %2", НаименованиеСклада);
```

Некорректно: ошибка в расстановке скобок с `НСтр`
```bsl
Сообщение = СтрШаблон(НСтр("ru='Версия программы: %1'", НомерВерсии()));
```

Корректно:
```bsl
Сообщение = СтрШаблон(НСтр("ru='Версия программы: %1'"), НомерВерсии());
Текст = СтрШаблон("%(1)07", Код);
```
