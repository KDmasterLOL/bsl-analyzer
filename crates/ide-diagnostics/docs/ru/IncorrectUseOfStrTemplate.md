# Неверное использование "СтрШаблон" (IncorrectUseOfStrTemplate)

## Описание диагностики

При вызове метода `СтрШаблон` необходимо следить за корректностью шаблонной строки и соответствием количества переданных параметров. Типичные ошибки:

- Количество аргументов после шаблонной строки не совпадает с максимальным номером подстановки `%N` в шаблоне
- Метод `СтрШаблон` поддерживает подстановки от `%1` до `%10`
- Для вставки числа непосредственно после подстановки используется синтаксис со скобками: `"%(1)45"`
- Неправильно расставленные скобки в комбинации с `НСтр` приводят к тому, что `СтрШаблон` получает пустую шаблонную строку

## Примеры

Несовпадение числа параметров:
```bsl
// Не передан параметр для %1
Текст = СтрШаблон("Документ №%1 от %2");

// Не передан параметр для %2
Текст = СтрШаблон("Склад: %1, Ячейка: %2", НаименованиеСклада);
```

Ошибка в расстановке скобок с `НСтр`:
```bsl
// Неправильно: скобка НСтр захватывает второй аргумент
Сообщение = СтрШаблон(НСтр("ru='Версия программы: %1'", НомерВерсии()));

// Правильно: скобка НСтр закрыта перед запятой
Сообщение = СтрШаблон(НСтр("ru='Версия программы: %1'"), НомерВерсии());
```

Вставка числа после подстановки:
```bsl
// Результат при Код = "ABC": "ABC07"
Текст = СтрШаблон("%(1)07", Код);
```
