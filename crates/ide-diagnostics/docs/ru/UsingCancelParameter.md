# Работа с параметром "Отказ" (UsingCancelParameter)

## Описание диагностики

В обработчиках событий модулей объектов, форм, наборов записей и других модулях, где доступен параметр `Отказ` (например, `ПриЗаписи`, `ОбработкаПроверкиЗаполнения`, `ТоварыПередНачаломДобавления`), запрещено присваивать этому параметру значение `Ложь`.

Причина запрета: обработчик события может содержать несколько последовательных проверок, а также могут существовать дополнительные подписки на это же событие. Если одна из проверок уже установила `Отказ = Истина`, последующее присвоение `Ложь` ошибочно сбросит результат предыдущей проверки. Кроме того, при доработке решения на конкретном внедрении количество проверок может возрасти, что усугубит проблему.

## Примеры

### Неправильно

```bsl
Процедура ПриЗаписи(Отказ)
    Отказ = НеПрошлаПроверка();
КонецПроцедуры
```

### Правильно

```bsl
Процедура ПриЗаписи(Отказ)
    Если НеПрошлаПроверка() Тогда
        Отказ = Истина;
    КонецЕсли;
КонецПроцедуры
```

или

```bsl
Отказ = Отказ Или НеПрошлаПроверка();
```
