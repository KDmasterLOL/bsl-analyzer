# У полей формы не указан путь к данным (WrongDataPathForFormElements)

## Описание диагностики

Диагностика находит элементы формы с уже поврежденной привязкой к данным.

При удалении или переименовании реквизита формы, смене основного реквизита или ручной правке запроса динамического списка часть элементов может потерять связь с данными. В XML-представлении формы это проявляется тем, что свойство `DataPath` начинаетcя с символа `~`, например `~Object.Description`.

Такие элементы указывают на неразрешимую ссылку на объект метаданных. В Конфигураторе это обычно проявляется ошибками вида:

```
Справочник.Контрагенты.Форма.ФормаЭлемента.Форма Неразрешимые ссылки на объекты метаданных
```

Текущая реализация работает по метаданным формы и проверяет только те элементы, у которых сохраненный `DataPath` начинается с `~`.

## Примеры

### Признак проблемы в XML

```xml
<DataPath>~Object.НесуществующийРеквизит</DataPath>
```

### Корректный вариант

```xml
<DataPath>Object.Наименование</DataPath>
```
