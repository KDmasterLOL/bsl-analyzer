# У полей формы не указан путь к данным (WrongDataPathForFormElements)

## Описание диагностики

В процессе активной доработки формы или связанных объектов метаданных на форме могут остаться элементы, утратившие связь с данными. Это происходит при удалении реквизитов, изменении состава метаданных или смене основного реквизита формы. Такие элементы не отображаются на форме, а при расширенной проверке в Конфигураторе возникают ошибки вида:

```
Справочник.Контрагенты.Форма.ФормаЭлемента.Форма Неразрешимые ссылки на объекты метаданных
```

В XML-выгрузке конфигурации у таких элементов значение свойства `DataPath` начинается с символа `~`, например: `<DataPath>~Object.Description</DataPath>`.

Аналогичная ситуация возникает при ручном редактировании запроса динамического списка: у колонок таблицы сбрасывается привязка к полям списка, и элементы исчезают из формы. В XML это выглядит как `<DataPath>~Список.Description</DataPath>`.

То же касается кнопок командной панели, связанных через свойство `Данные` со стандартным полем динамического списка, например: `<DataPath>~Items.Список.CurrentData.Ссылка</DataPath>`.

## Примеры

### Признак проблемы в XML

```xml
<DataPath>~Object.НесуществующийРеквизит</DataPath>
```

### Корректный вариант

```xml
<DataPath>Object.Наименование</DataPath>
```
