# Зарезервированные имена параметров (ReservedParameterNames)

## Описание диагностики

Когда имя параметра процедуры или функции совпадает с именем системного перечисления платформы, параметр перекрывает это перечисление в области видимости метода. В результате обращение к значениям перечисления становится невозможным, при этом синтаксическая проверка модуля такую ситуацию не обнаружит.

Чтобы избежать подобных конфликтов, имена параметров не должны совпадать с именами системных перечислений. Перечень запрещённых имён задаётся в настройках диагностики. Проверка выполняется без учёта регистра.

**Пример настройки:**

"ВидГруппыФормы|ВидПоляФормы"
