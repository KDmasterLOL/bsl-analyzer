# Зарезервированные имена параметров (ReservedParameterNames)

## Описание диагностики

Если имя параметра процедуры или функции совпадает с зарезервированным платформенным идентификатором, параметр перекрывает это имя в локальной области видимости. На практике это приводит к путанице и может ломать обращение к системным перечислениям или другим специальным именам.

Текущая реализация полностью зависит от конфигурации:

- проверяются только параметры процедур и функций;
- имя параметра сравнивается со списком `reservedWords`;
- сравнение выполняется без учёта регистра;
- совпадение должно быть полным, а не частичным.

Если `reservedWords` не задан или пуст, диагностика ничего не сообщает.

### Пример настройки

```json
{
  "diagnostics": {
    "ReservedParameterNames": {
      "reservedWords": ["ВидГруппыФормы", "ВидПоляФормы"]
    }
  }
}
```
