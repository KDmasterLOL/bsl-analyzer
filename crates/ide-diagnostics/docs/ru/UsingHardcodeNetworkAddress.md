# Хранение ip-адресов в коде (UsingHardcodeNetworkAddress)

## Описание диагностики

Не допускается жёсткое указание сетевых адресов (IPv4, IPv6) непосредственно в исходном коде модулей. При изменении сетевой инфраструктуры такой код потребует правки и повторного тестирования.

Рекомендуемые способы хранения сетевых адресов:

* Константа информационной базы.
* Регистр сведений.
* Справочник, узел плана обмена и другие объекты метаданных.
* Отдельный модуль с отключённой проверкой данного правила (не рекомендуется).

## Примеры

### Неправильно

```bsl
АдресСервера = "10.0.1.50";
```

### Правильно

```bsl
АдресСервера = Константы.АдресСервераОбмена.Получить();
```

или

```bsl
АдресСервера = НастройкиПодключенияПовтИсп.АдресСервера();
```
