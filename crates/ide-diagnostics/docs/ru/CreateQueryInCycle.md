# Выполнение запроса в цикле (CreateQueryInCycle)

## Описание диагностики

Создание и выполнение запроса внутри цикла -- грубая ошибка производительности. Каждая итерация порождает обращение к СУБД, что приводит к многократному увеличению времени выполнения и нагрузки на сервер. Вместо этого следует формировать запрос так, чтобы все необходимые данные извлекались за одно обращение, используя параметры-списки или временные таблицы.

## Примеры

Неправильно:

```bsl
МассивНоменклатуры = Новый Массив;
ИтоговаяСумма = 0;

Для Каждого ТекЭлемент Из МассивНоменклатуры Цикл
    Запрос = Новый Запрос;
    Запрос.Текст =
        "ВЫБРАТЬ
        |   Товары.Цена
        |ИЗ
        |   Справочник.Номенклатура КАК Товары
        |ГДЕ
        |   Товары.Ссылка = &ТекСсылка";
    Запрос.УстановитьПараметр("ТекСсылка", ТекЭлемент);
    Выборка = Запрос.Выполнить().Выбрать();
    Пока Выборка.Следующий() Цикл
        ИтоговаяСумма = ИтоговаяСумма + Выборка.Цена;
    КонецЦикла;
КонецЦикла;
```

Правильно:

```bsl
МассивНоменклатуры = Новый Массив;

Запрос = Новый Запрос;
Запрос.Текст =
    "ВЫБРАТЬ
    |   СУММА(Товары.Цена) КАК ИтогоЦена
    |ИЗ
    |   Справочник.Номенклатура КАК Товары
    |ГДЕ
    |   Товары.Ссылка В (&СписокНоменклатуры)";
Запрос.УстановитьПараметр("СписокНоменклатуры", МассивНоменклатуры);

Выборка = Запрос.Выполнить().Выбрать();
Пока Выборка.Следующий() Цикл
    ИтоговаяСумма = Выборка.ИтогоЦена;
КонецЦикла;
```
