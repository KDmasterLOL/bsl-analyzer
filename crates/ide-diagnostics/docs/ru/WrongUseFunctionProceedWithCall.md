# Некорректное использование функции ПродолжитьВызов() (WrongUseFunctionProceedWithCall)

## Описание диагностики

Функция `ПродолжитьВызов` предназначена для методов расширений, помеченных аннотацией `&Вместо`. Вызов этой функции в любом другом контексте приводит к некорректной работе расширения и обычно заканчивается ошибкой времени выполнения.

Текущая реализация находит глобальные вызовы `ПродолжитьВызов` / `ProceedWithCall`, если окружающий метод не помечен `&Вместо`. Поэтому диагностика срабатывает в обычных процедурах и функциях, а также в обработчиках с аннотациями `&Перед` и `&После`.

## Примеры

### Неправильно

```bsl
Процедура ОбновитьДанные()
    ПродолжитьВызов(); // Ошибка: метод не является перехватчиком расширения
КонецПроцедуры
```

### Правильно

```bsl
// В модуле расширения с аннотацией &Вместо
&Вместо("ОбновитьДанные")
Процедура Расш_ОбновитьДанные()
    // Дополнительная логика
    ПродолжитьВызов();
КонецПроцедуры
```
