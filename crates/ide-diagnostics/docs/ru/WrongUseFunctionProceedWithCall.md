# Некорректное использование функции ПродолжитьВызов() (WrongUseFunctionProceedWithCall)

## Описание диагностики

Функция `ПродолжитьВызов` предназначена исключительно для использования в методах расширений, помеченных аннотацией `&Вместо`. Вызов этой функции в любом другом контексте приведёт к ошибке времени выполнения. Как правило, подобный код появляется при копировании фрагментов из расширения в основную конфигурацию.

## Примеры

### Неправильно

```bsl
&НаСервере
Процедура ОбновитьДанные()
    ПродолжитьВызов(); // Ошибка: метод не является перехватчиком расширения
КонецПроцедуры
```

### Правильно

```bsl
// В модуле расширения с аннотацией &Вместо
&Вместо("ОбновитьДанные")
Процедура Расш_ОбновитьДанные()
    // Дополнительная логика
    ПродолжитьВызов();
КонецПроцедуры
```
