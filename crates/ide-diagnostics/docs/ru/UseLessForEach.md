# Бесполезный перебор коллекции (UseLessForEach)

## Описание диагностики

Если переменная итератора не используется внутри тела цикла `Для Каждого`, перебор коллекции не имеет смысла. Это указывает либо на ошибку (забыли обратиться к итератору), либо на лишний цикл, который можно удалить.

## Примеры

Неправильно:

```bsl
Для Каждого Элемент Из СписокДокументов Цикл
    ОбработатьСписок(СписокДокументов);
КонецЦикла;
```

Правильно:

```bsl
Для Каждого Элемент Из СписокДокументов Цикл
    ОбработатьДокумент(Элемент);
КонецЦикла;
```

Или, если обработка поэлементная не нужна:

```bsl
ОбработатьСписок(СписокДокументов);
```
