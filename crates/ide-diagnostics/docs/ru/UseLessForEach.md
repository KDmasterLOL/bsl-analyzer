# Бесполезный перебор коллекции (UseLessForEach)

## Описание диагностики

Если переменная итератора не используется внутри тела цикла `Для Каждого`, перебор коллекции не имеет смысла. Это указывает либо на ошибку (забыли обратиться к итератору), либо на лишний цикл, который можно удалить.

Текущая реализация уже, чем полная семантическая проверка цикла:

- диагностика срабатывает на циклы, которые уже были помечены на этапе HIR lowering как имеющие неиспользуемый итератор;
- обращение к свойствам итератора, передача его в метод, присваивание с его участием и вызовы методов у итератора считаются использованием;
- handler дополнительно подавляет срабатывание, если имя итератора совпадает с именем переменной модуля, чтобы не ловить известный ложноположительный случай.

## Примеры

Неправильно:

```bsl
Для Каждого Элемент Из СписокДокументов Цикл
    ОбработатьСписок(СписокДокументов);
КонецЦикла;
```

Правильно:

```bsl
Для Каждого Элемент Из СписокДокументов Цикл
    ОбработатьДокумент(Элемент);
КонецЦикла;
```

Или, если обработка поэлементная не нужна:

```bsl
ОбработатьСписок(СписокДокументов);
```
