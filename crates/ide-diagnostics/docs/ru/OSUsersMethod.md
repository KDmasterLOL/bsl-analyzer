# Использование метода ПользователиОС (OSUsersMethod)

## Описание диагностики

Вызов метода `ПользователиОС` представляет потенциальную угрозу безопасности. Метод возвращает список учётных записей операционной системы, что может быть использовано злоумышленником для получения информации о пользователях и последующей атаки на инфраструктуру. Наличие такого вызова в коде требует обязательной проверки на предмет умышленного внедрения.
