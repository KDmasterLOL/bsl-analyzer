# Использование метода ПользователиОС (OSUsersMethod)

## Описание диагностики

Диагностика выявляет вызовы глобального метода `ПользователиОС()` / `OSUsers()`.

Метод дает доступ к сведениям об учетных записях операционной системы. Во
многих проектах такой доступ рассматривается как чувствительная с точки зрения
безопасности операция, потому что он раскрывает детали окружения, которые
обычно не нужны для обычной бизнес-логики и поэтому требуют отдельной
проверки.

Это security hotspot, а не синтаксическая или стилeвая ошибка: каждый такой
вызов нужно проверять вручную.
