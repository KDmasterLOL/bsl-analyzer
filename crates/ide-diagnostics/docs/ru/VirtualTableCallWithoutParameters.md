# Обращение к виртуальной таблице без параметров (VirtualTableCallWithoutParameters)

## Описание диагностики

При работе с виртуальными таблицами в запросах все условия отбора, относящиеся к виртуальной таблице, необходимо передавать через её параметры, а не размещать в секции `ГДЕ` или других секциях запроса.

Если условия указаны вне параметров виртуальной таблицы, СУБД сначала вычислит полное содержимое таблицы, а затем применит фильтр. Это существенно снижает производительность и может привести к неоптимальному плану выполнения запроса.

## Примеры

### Неправильно

```bsl
Запрос.Текст = "ВЫБРАТЬ
    | Товар
    |ИЗ
    | РегистрНакопления.ОстаткиТоваров.Остатки()
    |ГДЕ
    | Магазин = &Магазин";
```

### Правильно

```bsl
Запрос.Текст = "ВЫБРАТЬ
    | Товар
    |ИЗ
    | РегистрНакопления.ОстаткиТоваров.Остатки(, Магазин = &Магазин)";
```
