# Обращение к виртуальной таблице без параметров (VirtualTableCallWithoutParameters)

## Описание диагностики

При работе с виртуальными таблицами в запросах релевантные условия отбора следует передавать через параметры виртуальной таблицы.

Текущая реализация сообщает о вызовах, где виртуальная таблица используется без параметров или с пустыми позициями параметров, например:

- без круглых скобок вообще;
- с пустыми скобками `()`;
- с двумя пустыми позициями `(, )`;
- с пустым обязательным хвостовым параметром, например `(&Период, )`.

Это консервативное performance-oriented правило: оно помогает находить обращения, которые с высокой вероятностью читают слишком много данных до применения фильтрации.

## Примеры

### Срабатывание

```bsl
Запрос.Текст = "ВЫБРАТЬ
    | Товар
    |ИЗ
    | РегистрНакопления.ОстаткиТоваров.Остатки()";
```

### Предпочтительно

```bsl
Запрос.Текст = "ВЫБРАТЬ
    | Товар
    |ИЗ
    | РегистрНакопления.ОстаткиТоваров.Остатки(, Магазин = &Магазин)";
```
