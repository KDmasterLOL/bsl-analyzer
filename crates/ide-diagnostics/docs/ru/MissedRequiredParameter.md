# Пропущен обязательный параметр метода (MissedRequiredParameter)

## Описание диагностики

Обязательные параметры процедур и функций нельзя пропускать при вызове. Если обязательный параметр опущен, вместо него будет подставлено значение `Неопределено`, к которому вызываемый метод может быть не готов. Если `Неопределено` является допустимым значением, следует либо передавать его явно, либо сделать параметр необязательным, указав `Неопределено` как значение по умолчанию.

## Примеры

Для процедуры с сигнатурой:

```bsl
Процедура УстановитьСтатус(Документ, НовыйСтатус, Комментарий)
```

Неправильно:

```bsl
УстановитьСтатус(, "Утверждён", "Готов к отгрузке"); // пропущен параметр Документ
УстановитьСтатус(,,);                                 // пропущены все обязательные параметры
```

Правильно:

```bsl
УстановитьСтатус(ТекущийДокумент, "Утверждён", "Готов к отгрузке");
```
