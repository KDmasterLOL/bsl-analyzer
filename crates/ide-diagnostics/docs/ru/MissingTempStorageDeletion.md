# Отсутствует удаление данных из временного хранилища после использования (MissingTempStorageDeletion)

## Описание диагностики

Диагностика проверяет, что для каждого вызова `ПолучитьИзВременногоХранилища` существует последующий вызов `УдалитьИзВременногоХранилища` в пределах того же метода или того же module-level body.

Хранение данных во временном хранилище расходует оперативную память сервера. Если не очищать хранилище после использования, данные могут накапливаться и увеличивать потребление памяти.

Текущая реализация уже, чем полные рекомендации платформы. Она делает локальную структурную проверку:

- находит вызов `ПолучитьИзВременногоХранилища`;
- ищет последующий вызов `УдалитьИзВременногоХранилища` в том же body;
- сравнивает первый аргумент структурно, а не по тексту.

Из-за этого диагностика хорошо покрывает случаи вроде `Результат.АдресРезультата`, но не пытается доказывать весь жизненный цикл временного хранилища или все допустимые сценарии переиспользования адресов.

## Примеры

### Корректная очистка после получения данных

```bsl
&НаСервере
Процедура ЗагрузитьПодобранныеТовары(АдресВХранилище)
    ТаблицаТоваров = ПолучитьИзВременногоХранилища(АдресВХранилище);
    Объект.Товары.Загрузить(ТаблицаТоваров);
    УдалитьИзВременногоХранилища(АдресВХранилище);
КонецПроцедуры
```

### Некорректно: удаление отсутствует

```bsl
&НаСервере
Процедура ЗагрузитьПодобранныеТовары(АдресВХранилище)
    ТаблицаТоваров = ПолучитьИзВременногоХранилища(АдресВХранилище);
    Объект.Товары.Загрузить(ТаблицаТоваров);
КонецПроцедуры
```
