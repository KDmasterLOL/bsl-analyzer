# Отсутствует удаление данных из временного хранилища после использования (MissingTempStorageDeletion)

## Описание диагностики

Диагностика проверяет, что для каждого вызова `ПолучитьИзВременногоХранилища` в рамках одного метода существует соответствующий вызов `УдалитьИзВременногоХранилища`.

Хранение данных во временном хранилище расходует оперативную память сервера. Если не очищать хранилище после использования, при многократном повторении операции (например, при подборе товаров в форме) данные накапливаются, что ведёт к избыточному потреблению памяти.

При работе с временным хранилищем следует придерживаться одного из подходов:

- Помещать данные с привязкой к идентификатору формы и очищать хранилище сразу после использования.
- Предварительно инициализировать хранилище и переиспользовать один и тот же адрес.

Значение из хранилища передаётся по ссылке и хранится в кеше 20 минут с момента последнего обращения. После этого данные сбрасываются на диск, а при следующем запросе загружаются обратно в кеш.

## Примеры

1 -- Корректная очистка после получения данных:

```bsl
&НаСервере
Процедура ЗагрузитьПодобранныеТовары(АдресВХранилище)
    ТаблицаТоваров = ПолучитьИзВременногоХранилища(АдресВХранилище);
    Объект.Товары.Загрузить(ТаблицаТоваров);
    УдалитьИзВременногоХранилища(АдресВХранилище);
КонецПроцедуры
```

2 -- Работа с фоновыми заданиями.

Неправильно -- при каждом запуске результат помещается в новое хранилище:

```bsl
ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияФункции(УникальныйИдентификатор);
ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения, ПараметрЗадания);
```

Правильно -- очистка хранилища после получения результата:

```bsl
Результат = ПолучитьИзВременногоХранилища(Результат.АдресРезультата);
УдалитьИзВременногоХранилища(Результат.АдресРезультата);
```

3 -- Переиспользование заранее инициализированного адреса:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ)
    АдресДанных = ПоместитьВоВременноеХранилище(Неопределено, УникальныйИдентификатор);
КонецПроцедуры

&НаСервере
Функция ПоместитьТоварыВХранилище()
    Возврат ПоместитьВоВременноеХранилище(Товары.Выгрузить(), АдресДанных);
КонецФункции

&НаСервере
Процедура ЗагрузитьТоварыИзХранилища(АдресВХранилище)
    ТаблицаТоваров = ПолучитьИзВременногоХранилища(АдресВХранилище);
    Объект.Товары.Загрузить(ТаблицаТоваров);
    // Удаление не требуется: адрес переиспользуется
КонецПроцедуры
```

4 -- Фиксированный адрес для фонового задания:

```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ)
    АдресРезультата = ПоместитьВоВременноеХранилище(Неопределено, УникальныйИдентификатор);
КонецПроцедуры

&НаСервере
Функция ЗапуститьФоновуюОбработку()
    ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияФункции(УникальныйИдентификатор);
    ПараметрыВыполнения.АдресРезультата = АдресРезультата;

    Возврат ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения,
        "Обработки.АнализДанных.ВыполнитьАнализ",
        ПараметрыАнализа);
КонецФункции
```
