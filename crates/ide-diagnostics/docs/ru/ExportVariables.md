# Запрет экспортных глобальных переменных модуля (ExportVariables)

## Описание диагностики

Экспортные переменные модуля (`Перем ... Экспорт`) расширяют область видимости состояния за пределы модуля, что затрудняет контроль над тем, кто и когда изменяет значение. Это приводит к трудновоспроизводимым ошибкам, зависящим от порядка вызовов. Вместо экспортных переменных рекомендуется использовать штатные механизмы платформы, в частности свойство `ДополнительныеСвойства` объекта.

## Примеры

### Неправильно

```bsl
Перем РежимОбработки Экспорт;

Процедура ПередЗаписью(Отказ)
    Если РежимОбработки Тогда
        // специальная логика
    КонецЕсли;
КонецПроцедуры
```

### Правильно

```bsl
Процедура ПередЗаписью(Отказ)
    Если ДополнительныеСвойства.Свойство("РежимОбработки") Тогда
        // специальная логика
    КонецЕсли;
КонецПроцедуры

// вызывающий код
ДокОбъект.ДополнительныеСвойства.Вставить("РежимОбработки", Истина);
ДокОбъект.Записать();
```
