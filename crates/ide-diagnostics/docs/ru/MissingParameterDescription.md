# Отсутствует описание параметров метода (MissingParameterDescription)

## Описание диагностики

Документирующий комментарий экспортной процедуры или функции с параметрами должен содержать корректное описание этих параметров. Это позволяет другим разработчикам правильно использовать метод без необходимости изучать его реализацию.

Для неэкспортных методов диагностика не требует добавлять секцию `Параметры`, если комментарий содержит только обычное пояснение назначения. Если секция `Параметры` уже есть, ее содержимое проверяется на соответствие сигнатуре независимо от экспортности метода.

Диагностика выявляет следующие проблемы:

- У экспортного метода с параметрами полностью отсутствует секция `Параметры`.
- Часть параметров не описана -- диагностика указывает, для какого именно параметра нет описания.
- В описании присутствуют параметры, которых нет в сигнатуре метода (например, оставшиеся после рефакторинга).
- Повторяются описания одного и того же параметра.
- Нарушен порядок описаний параметров относительно сигнатуры метода.

Текущая реализация также специально пропускает комментарии-ссылки вида `См. ДругойМетод()`.

### Строгий режим

Установите параметр диагностики `allowShortDescriptionParameters` в
`false`, чтобы дополнительно требовать пояснение после типа для каждого
параметра. В строгом режиме `Параметр1 - Строка` (только тип) выдаёт
диагностику с предложением добавить пояснение; форма
`Параметр1 - Строка - первое слагаемое` или структурный блок `Структура:`
с подполями принимаются. По умолчанию параметр равен `true` для совместимости
с распространённой в BSL практикой указывать только тип. Аналог
`allowShortDescriptionReturnValues` у `MissingReturnedValueDescription`.

> **Изменение поведения:** ключевые слова `Параметры:` и `Parameters:` теперь распознаются только в начале строки комментария. Раньше парсер реагировал и на упоминание этих слов в свободном тексте, что иногда приводило к ложным срабатываниям. Если в существующих комментариях слово «параметры:» встречалось в середине предложения и неявно «открывало» секцию, после обновления такие случаи нужно переоформить в виде явного заголовка секции.

## Примеры

Неправильно:

```bsl
// Записывает данные в файл.
//
Процедура ЗаписатьВФайл(ПутьКФайлу, Данные, Кодировка) Экспорт
```

Правильно:

```bsl
// Записывает данные в файл.
//
// Параметры:
//   ПутьКФайлу - Строка - полный путь к файлу на диске
//   Данные - Строка - содержимое для записи
//   Кодировка - Строка - кодировка файла, например "UTF-8"
//
Процедура ЗаписатьВФайл(ПутьКФайлу, Данные, Кодировка) Экспорт
```
