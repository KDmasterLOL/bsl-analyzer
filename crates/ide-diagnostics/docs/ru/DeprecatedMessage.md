# Ограничение на использование устаревшего метода "Сообщить" (DeprecatedMessage)

## Описание диагностики

Для информирования пользователя следует применять объект `СообщениеПользователю`, а не метод `Сообщить()`. Объект `СообщениеПользователю` позволяет привязать текст сообщения к конкретному реквизиту формы, что помогает пользователю быстрее найти и исправить ошибку.

При использовании БСП рекомендуется вызывать процедуру `ОбщегоНазначенияКлиентСервер.СообщитьПользователю()`.

## Примеры

Неправильно:

```bsl
Сообщить("Не заполнено наименование контрагента");
```

Правильно:

```bsl
Сообщение = Новый СообщениеПользователю;
Сообщение.Текст = "Не заполнено наименование контрагента";
Сообщение.Поле = "Наименование";
Сообщение.Сообщить();
```
