# Пропущен постфикс "Глобальный" (CommonModuleNameGlobal)

## Описание диагностики

Общие модули с признаком "Глобальный" должны содержать в имени соответствующий постфикс -- "Глобальный" (англ. "Global"). Это позволяет однозначно идентифицировать назначение модуля по его имени и отличать глобальные модули от прочих.

## Примеры

Неправильно:

```
ОбновлениеИнформационнойБазы
StandardSubsystems
```

Правильно:

```
ОбновлениеИнформационнойБазыГлобальный
StandardSubsystemsGlobal
```
