# Нарушение парности использования методов "НачатьТранзакцию()" и "ЗафиксироватьТранзакцию()" / "ОтменитьТранзакцию()" (PairingBrokenTransaction)

## Описание диагностики

Диагностика выявляет нарушение парности транзакционных вызовов внутри одного
метода.

Публичное правило здесь простое: `НачатьТранзакцию()` должна завершаться через
`ЗафиксироватьТранзакцию()` или `ОтменитьТранзакцию()`. В текущем проекте
проверка path-sensitive: анализируются все пути выполнения, поэтому
диагностика умеет находить как незакрытые транзакции, так и "осиротевшие"
вызовы `ЗафиксироватьТранзакцию()` / `ОтменитьТранзакцию()`.

В реализации также есть локальный защитный предел `maxTransactionLevel`,
который ограничивает глубину обхода в патологических случаях.

## Примеры

Правильно:

```bsl
Процедура СохранитьДанные()
    НачатьТранзакцию();
    Попытка
        Документ.Записать();
        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
        ВызватьИсключение;
    КонецПопытки;
КонецПроцедуры
```

Неправильно:

```bsl
Процедура НачатьЗапись()
    НачатьТранзакцию();
    ВыполнитьЗапись();
КонецПроцедуры

Процедура ВыполнитьЗапись()
    Попытка
        Документ.Записать();
        ЗафиксироватьТранзакцию();
    Исключение
        ОтменитьТранзакцию();
    КонецПопытки;
КонецПроцедуры
```
