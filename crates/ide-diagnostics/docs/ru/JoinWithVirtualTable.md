# Соединение с виртуальными таблицами (JoinWithVirtualTable)

## Описание диагностики

В запросах не рекомендуется выполнять соединения с виртуальными таблицами
языка запросов 1С:Предприятия (например,
`РегистрНакопления.Товары.Остатки`). Вместо этого следует соединять только
объекты метаданных или временные таблицы.

При неудовлетворительной производительности запроса с соединением виртуальной таблицы рекомендуется вынести обращение к ней в отдельный запрос и сохранить результат во временную таблицу, а затем использовать эту временную таблицу в основном запросе.

## Примеры

Неправильно:
```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Накладные.Ссылка,
|    Остатки.КоличествоОстаток
|ИЗ
|    Документ.РасходнаяНакладная КАК Накладные
|    ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ОстаткиТоваров.Остатки КАК Остатки
|    ПО Накладные.Номенклатура = Остатки.Номенклатура
|");
```

Правильно:
```bsl
Запрос = Новый Запрос("
|ВЫБРАТЬ
|    Номенклатура,
|    КоличествоОстаток
|ПОМЕСТИТЬ ВременныеОстатки
|ИЗ
|    РегистрНакопления.ОстаткиТоваров.Остатки
|;
|ВЫБРАТЬ
|    Накладные.Ссылка,
|    Остатки.КоличествоОстаток
|ИЗ
|    Документ.РасходнаяНакладная КАК Накладные
|    ЛЕВОЕ СОЕДИНЕНИЕ ВременныеОстатки КАК Остатки
|    ПО Накладные.Номенклатура = Остатки.Номенклатура
|");
```
