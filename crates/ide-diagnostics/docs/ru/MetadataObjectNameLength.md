# Имена объектов метаданных не должны превышать допустимой длины наименования (MetadataObjectNameLength)

## Описание диагностики

Длина имени объекта метаданных не должна превышать 80 символов. Слишком длинные имена создают неудобства при работе с объектами в коде, а также вызывают ошибки при выгрузке конфигурации в файлы.

## Примеры

Неправильно -- имена, длина которых превышает 80 символов:

```
СправочникСОченьДлиннымИменемКотороеНевозможноПрочитатьИПриводитКОшибкамПриВыгрузке
```

```
VeryLongCatalogNameThatExceedsTheMaximumAllowedLengthAndCausesExportIssuesInConfiguration
```

Правильно:

```
НоменклатурнаяГруппа
```
