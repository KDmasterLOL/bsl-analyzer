# Неиспользуемый параметр (UnusedParameters)

## Описание диагностики

Параметры процедур и функций, которые не задействованы в теле метода, подлежат удалению. Лишние параметры вводят в заблуждение при чтении кода и усложняют вызов метода.

Текущая реализация не ругается на методы с фиксированной сигнатурой, которые ожидаемо вызываются платформой или инфраструктурой: обработчики событий, HTTP-обработчики, подключаемые методы и локальные callback-методы, зарегистрированные через `ОписаниеОповещения`.

## Примеры

Неправильно:

```bsl
Функция ВычислитьПлощадь(Знач Длина, Знач Ширина, Знач Цвет)
    Возврат Длина * Ширина;
КонецФункции
```

Правильно:

```bsl
Функция ВычислитьПлощадь(Знач Длина, Знач Ширина)
    Возврат Длина * Ширина;
КонецФункции
```
