# Использование 'ПОДОБНО' в запросе (UsingLikeInQuery)

## Описание диагностики

Диагностика сообщает о любом использовании оператора `ПОДОБНО` в тексте запроса.

Правило реализовано консервативно: даже если в конкретном случае использование шаблона кажется допустимым, результат работы `ПОДОБНО` может зависеть от особенностей СУБД и семантики запроса. Поэтому текущая реализация помечает все такие вхождения и оставляет окончательное решение разработчику.

## Примеры

### Срабатывание

```bsl
Запрос.Текст = "ВЫБРАТЬ Наименование ИЗ Справочник.Номенклатура ГДЕ Артикул ПОДОБНО ""АРТ%""";
```

### Срабатывание

```bsl
Запрос.Текст = "ВЫБРАТЬ Наименование ИЗ Справочник.Номенклатура ГДЕ Артикул ПОДОБНО &Шаблон";
```
