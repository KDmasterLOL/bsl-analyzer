# Использование 'ПОДОБНО' в запросе (UsingLikeInQuery)

## Описание диагностики

В большинстве случаев алгоритм можно реализовать без оператора `ПОДОБНО`. Если же его применение необходимо, следует соблюдать осторожность: результат выполнения запроса с оператором `ПОДОБНО` может различаться в зависимости от используемой СУБД, что приводит к непредсказуемому поведению.

## Примеры

### Правильно

```bsl
Запрос.Текст = "ВЫБРАТЬ Наименование ИЗ Справочник.Номенклатура ГДЕ Артикул ПОДОБНО ""АРТ%""";
```

### Неправильно

```bsl
Запрос.Текст = "ВЫБРАТЬ Наименование ИЗ Справочник.Номенклатура ГДЕ Артикул ПОДОБНО &Шаблон";
```
