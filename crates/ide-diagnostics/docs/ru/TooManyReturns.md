# Метод не должен содержать много возвратов (TooManyReturns)

## Описание диагностики

Чрезмерное количество операторов `Возврат` в процедуре или функции усложняет понимание логики работы метода и затрудняет его отладку. Рекомендуется структурировать код так, чтобы метод имел минимальное число точек выхода.

Диагностика сообщает о методах, в которых число операторов `Возврат` превышает настроенный предел. По умолчанию в проекте используется порог `3`.

## Примеры

Плохо:

```bsl
Функция ПолучитьСкидку(Категория)
    Если Категория = "VIP" Тогда
        Возврат 30;
    ИначеЕсли Категория = "Постоянный" Тогда
        Возврат 15;
    ИначеЕсли Категория = "Новый" Тогда
        Возврат 5;
    ИначеЕсли Категория = "Сотрудник" Тогда
        Возврат 20;
    КонецЕсли;
    Возврат 0;
КонецФункции
```

Лучше:

```bsl
Функция ПолучитьСкидку(Категория)
    Скидка = 0;
    Если Категория = "VIP" Тогда
        Скидка = 30;
    ИначеЕсли Категория = "Постоянный" Тогда
        Скидка = 15;
    ИначеЕсли Категория = "Новый" Тогда
        Скидка = 5;
    ИначеЕсли Категория = "Сотрудник" Тогда
        Скидка = 20;
    КонецЕсли;
    Возврат Скидка;
КонецФункции
```
