# Неверно задан обработчик метода http-сервиса (WrongHttpServiceHandler)

## Описание диагностики

Диагностика проверяет корректность обработчиков, назначенных методам HTTP-сервиса в метаданных.

Она срабатывает в трех случаях:

- у метода HTTP-сервиса не задано имя обработчика;
- указанный обработчик отсутствует в текущем модуле HTTP-сервиса;
- обработчик найден, но у него не один параметр.

Текущая реализация работает по метаданным HTTP-сервиса и по символьному дереву текущего модуля. Она не анализирует тело обработчика и не проверяет его бизнес-логику.

## Примеры

### Неправильно -- обработчик не задан

```bsl
// У метода HTTP-сервиса не заполнено имя обработчика.
```

### Неправильно -- лишний параметр

```bsl
Функция ПолучитьДанныеGET(Запрос, Настройки)
    Возврат ОбработкаЗапросов.Выполнить(Запрос);
КонецФункции
```

### Правильно

```bsl
Функция ПолучитьДанныеGET(Запрос)
    Возврат ОбработкаЗапросов.Выполнить(Запрос);
КонецФункции
```
