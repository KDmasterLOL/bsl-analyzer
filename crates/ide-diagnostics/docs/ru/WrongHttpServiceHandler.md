# Неверно задан обработчик метода http-сервиса (WrongHttpServiceHandler)

## Описание диагностики

Если обработчик метода HTTP-сервиса отсутствует или задан некорректно, обращение к методу сервиса не вернёт ни данных, ни сообщения об ошибке -- ни на стороне клиента, ни на стороне сервера.

Обработчик метода HTTP-сервиса должен удовлетворять двум условиям:
* Тело функции не должно быть пустым.
* Функция должна принимать ровно один параметр (объект запроса).

Конфигуратор обнаруживает подобные нарушения только при включённом флаге "Проверка существования назначенных обработчиков".

## Примеры

### Неправильно -- пустое тело обработчика

```bsl
Функция ПолучитьДанныеGET(Запрос)

КонецФункции
```

### Неправильно -- лишний параметр

```bsl
Функция ПолучитьДанныеGET(Запрос, Настройки)
    Возврат ОбработкаЗапросов.Выполнить(Запрос);
КонецФункции
```

### Правильно

```bsl
Функция ПолучитьДанныеGET(Запрос)
    Возврат ОбработкаЗапросов.Выполнить(Запрос);
КонецФункции
```
