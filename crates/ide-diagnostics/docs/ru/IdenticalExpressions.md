# Одинаковые выражения слева и справа от "foo" оператора (IdenticalExpressions)

## Описание диагностики

Диагностика выявляет два вида проблем:

1. **Дублирование выражений по обе стороны оператора** -- когда оператор сравнения или логический оператор (<, >, <=, >=, =, <>, И, ИЛИ, -, /) имеет одинаковые подвыражения слева и справа, это с высокой вероятностью свидетельствует об ошибке копирования или невнимательности.

2. **Идентичный код в ветвях препроцессорной директивы** -- когда выражение разделено конструкцией `#Если/#Иначе/#КонецЕсли` и в каждой ветви содержится одинаковый код, условная компиляция теряет смысл, что указывает на ошибку.

## Примеры

### Дублирование выражений по обе стороны оператора

Неправильно:
```bsl
Если Количество > 0 И Количество > 0 Тогда
    ОбработатьДанные();
КонецЕсли;
```

Правильно:
```bsl
Если Количество > 0 И Цена > 0 Тогда
    ОбработатьДанные();
КонецЕсли;
```

Или, если дублирование было лишним:
```bsl
Если Количество > 0 Тогда
    ОбработатьДанные();
КонецЕсли;
```

### Идентичный код в ветвях препроцессора

Неправильно:
```bsl
РежимРаботы =
#Если Сервер Тогда
    РежимРаботыСервера
#Иначе
    РежимРаботыСервера
#КонецЕсли
    И ПравоДоступа("Чтение", Метаданные.Справочники.Контрагенты);
```

Правильно:
```bsl
РежимРаботы =
#Если Сервер Тогда
    РежимРаботыСервера
#Иначе
    РежимРаботыКлиента
#КонецЕсли
    И ПравоДоступа("Чтение", Метаданные.Справочники.Контрагенты);
```
