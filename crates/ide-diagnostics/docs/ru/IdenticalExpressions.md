# Одинаковые выражения слева и справа от "foo" оператора (IdenticalExpressions)

<!-- Блоки выше заполняются автоматически, не трогать -->
## Описание диагностики

Диагностика обнаруживает два типа проблем:

1. **Одинаковые выражения слева и справа от оператора** — если в тексте программы имеется оператор (<, >, <=, >=, =, <>, И, ИЛИ, -, /), слева и справа от которого расположены одинаковые подвыражения, это фрагмент кода, который, скорее всего, содержит логическую ошибку.

2. **Повторяющиеся выражения в коде, разбитом препроцессорной директивой** — если выражение разбито инструкциями препроцессора (#Если/#Иначе/#КонецЕсли) и в разных ветках содержится одинаковый код, это может указывать на ошибку копирования.

## Примеры

### Одинаковые выражения слева и справа от оператора

```bsl
Если Сумма <> 0 И Сумма <> 0 Тогда

    // Тут код

КонецЕсли;
```

Здесь оператор `И` окружен одинаковыми выражениями `Сумма <> 0`,
что наталкивает на мысли об ошибке по невнимательности при копировании. Правильное выражение будет выглядеть так:

```bsl
Если Сумма <> 0 И СуммаНДС <> 0 Тогда

    // Тут код

КонецЕсли;
```

ИЛИ

```bsl
Если Сумма <> 0 Тогда

    // Тут код

КонецЕсли;
```

### Повторяющиеся выражения в коде с препроцессором

```bsl
СхемаДоступнаДляРедактирования =
#Если Клиент Тогда
    СхемаДоступнаДляРедактирования
#Иначе
    СхемаДоступнаДляРедактирования
#КонецЕсли
    И ПравоДоступа("Редактирование", Метаданные.Справочники.Номенклатура);
```

Здесь в обеих ветках препроцессора используется одинаковое выражение `СхемаДоступнаДляРедактирования`, что делает условную компиляцию бессмысленной. Правильный вариант:

```bsl
СхемаДоступнаДляРедактирования =
#Если Клиент Тогда
    СхемаДоступнаДляРедактированияНаКлиенте
#Иначе
    СхемаДоступнаДляРедактированияНаСервере
#КонецЕсли
    И ПравоДоступа("Редактирование", Метаданные.Справочники.Номенклатура);
```
