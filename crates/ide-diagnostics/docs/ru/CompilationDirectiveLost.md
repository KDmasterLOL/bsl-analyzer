# Директивы компиляции методов (CompilationDirectiveLost)

## Описание диагностики

Каждый метод в модулях управляемых форм и модулях команд должен быть снабжен директивой компиляции (`&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста` и т.д.). Отсутствие директивы приводит к неявному выбору контекста исполнения, что затрудняет понимание кода и может стать причиной ошибок.

## Примеры

Неправильно:

```bsl
Процедура ОбработатьДанные(Отказ)
    // Контекст исполнения не указан явно
КонецПроцедуры
```

Правильно:

```bsl
&НаСервере
Процедура ОбработатьДанные(Отказ)
    // Метод выполняется на сервере
КонецПроцедуры
```
