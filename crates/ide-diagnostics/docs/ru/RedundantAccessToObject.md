# Избыточное обращение к объекту (RedundantAccessToObject)

## Описание диагностики

В модулях объектов и формах обращение к собственным реквизитам через `ЭтотОбъект` является избыточным — к ним можно обращаться напрямую по имени. В общих модулях (кроме модулей с повторным использованием) вызов собственных методов через имя модуля также излишен.

## Примеры

В модуле объекта справочника с реквизитом `ИНН` неправильно писать

```bsl
ЭтотОбъект.ИНН = ПолучитьИННКонтрагента();
```

правильно обратиться к реквизиту напрямую

```bsl
ИНН = ПолучитьИННКонтрагента();
```

В общем модуле `РаботаСФайлами` неправильно вызывать свой же метод через имя модуля

```bsl
РаботаСФайлами.СохранитьФайлНаДиск(Данные, Путь);
```

правильно вызывать без префикса

```bsl
СохранитьФайлНаДиск(Данные, Путь);
```
