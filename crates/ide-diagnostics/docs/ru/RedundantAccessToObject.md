# Избыточное обращение к объекту (RedundantAccessToObject)

## Описание диагностики

Диагностика сообщает об избыточном обращении к собственным членам через `ЭтотОбъект` или через имя текущего модуля.

В модулях объектов, формах и модулях набора записей к своим свойствам обычно можно обращаться напрямую, без префикса `ЭтотОбъект`. В общих и менеджерских модулях вызов собственного метода через полный путь модуля в поддерживаемых случаях тоже излишен.

## Примеры

В модуле объекта избыточно писать

```bsl
ЭтотОбъект.ИНН = ПолучитьИННКонтрагента();
```

лучше обратиться к реквизиту напрямую

```bsl
ИНН = ПолучитьИННКонтрагента();
```

В общем модуле избыточно вызывать свой же метод через имя модуля

```bsl
РаботаСФайлами.СохранитьФайлНаДиск(Данные, Путь);
```

лучше вызывать без префикса

```bsl
СохранитьФайлНаДиск(Данные, Путь);
```
