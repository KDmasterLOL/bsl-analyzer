# Двойные отрицания (DoubleNegatives)

## Описание диагностики

Конструкции с двойным отрицанием (например, `НЕ ... <> Неопределено`) снижают читаемость кода. При мысленном разборе такого выражения легко перепутать итоговое логическое значение. Подобные условия следует переформулировать в прямую форму, явно выражающую намерение разработчика.

## Примеры

### Неправильно

```bsl
Если Не Товары.Найти(Артикул, "Код") <> Неопределено Тогда
    ВызватьИсключение "Товар не найден";
КонецЕсли;
```

### Правильно

```bsl
Если Товары.Найти(Артикул, "Код") = Неопределено Тогда
    ВызватьИсключение "Товар не найден";
КонецЕсли;
```
