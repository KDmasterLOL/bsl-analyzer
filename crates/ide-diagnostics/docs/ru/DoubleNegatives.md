# Двойные отрицания (DoubleNegatives)

## Описание диагностики

Конструкции с двойным отрицанием снижают читаемость кода. При мысленном разборе такого выражения легко перепутать итоговое логическое значение. Такие условия обычно лучше переписывать в прямую форму, явно выражающую намерение разработчика.

Текущая реализация находит три структурных паттерна:

- `НЕ (НЕ X)`
- `НЕ (X <> Y)`
- `(НЕ X) <> Y`

Диагностика намеренно пропускает более сложные случаи, внутри которых уже есть логические операторы `И` / `ИЛИ`, потому что там автоматическая трактовка менее очевидна.

## Примеры

### Неправильно

```bsl
Если Не Товары.Найти(Артикул, "Код") <> Неопределено Тогда
    ВызватьИсключение "Товар не найден";
КонецЕсли;
```

### Правильно

```bsl
Если Товары.Найти(Артикул, "Код") = Неопределено Тогда
    ВызватьИсключение "Товар не найден";
КонецЕсли;
```
