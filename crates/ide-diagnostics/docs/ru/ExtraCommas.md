# Запятые без указания параметра в конце вызова метода (ExtraCommas)

## Описание диагностики

Завершающие запятые в конце списка аргументов при вызове метода (когда после запятой не указан параметр) не несут полезной информации и ухудшают читаемость. Необязательные параметры, которые не передаются, не требуют обозначения запятой в конце вызова.

## Примеры

### Неправильно

```bsl
ЗаполнитьЗначенияСвойств(Приёмник, Источник,,);
```

### Правильно

```bsl
ЗаполнитьЗначенияСвойств(Приёмник, Источник);
```
