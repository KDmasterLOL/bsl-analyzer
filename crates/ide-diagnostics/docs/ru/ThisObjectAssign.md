# Присвоение значения свойству ЭтотОбъект (ThisObjectAssign)

## Описание диагностики

В модулях управляемых форм и общих модулях `ЭтотОбъект` — это системное свойство платформы, а не обычная изменяемая переменная.

Прямое присваивание значения этому свойству является ошибкой, потому что свойство доступно только для чтения.

Проблема часто проявляется при переводе старого кода на режим совместимости `8.3.3+`: раньше `ЭтотОбъект` могли использовать как имя локальной переменной, а после появления встроенного свойства такой код начинает конфликтовать с платформенной семантикой.

## Примеры

Неправильно:

```bsl
ЭтотОбъект = РеквизитФормыВЗначение("Объект");
```

Правильно:

```bsl
ТекущийОбъект = РеквизитФормыВЗначение("Объект");
```

Текущая реализация намеренно узкая:

- диагностика срабатывает только на прямое присваивание `ЭтотОбъект` / `ThisObject`;
- применяется только к общим модулям и модулям форм;
- обращения вида `ЭтотОбъект.Реквизит = Значение` эта диагностика не ловит.
