# Присвоение значения свойству ЭтотОбъект (ThisObjectAssign)

## Описание диагностики

В модулях управляемых форм и общих модулях запрещено использовать идентификатор `ЭтотОбъект` в качестве переменной. Начиная с режима совместимости 8.3.3, платформа резервирует это имя как системное свойство. Код, в котором `ЭтотОбъект` применялся как обычная переменная, перестанет корректно работать после обновления режима совместимости.

## Примеры

Неправильно:

```bsl
ЭтотОбъект = РеквизитФормыВЗначение("Объект");
```

Правильно:

```bsl
ТекущийОбъект = РеквизитФормыВЗначение("Объект");
```
