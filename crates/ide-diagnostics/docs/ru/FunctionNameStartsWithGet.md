# Имя функции не должно начинаться с "Получить" (FunctionNameStartsWithGet)

## Описание диагностики

Согласно стандарту `#std647`, имя функции должно описывать возвращаемое
значение. Префикс `Получить` дублирует сам факт того, что метод объявлен как
функция и уже возвращает результат.

Предпочтительно называть функцию по тому, что она возвращает, а не по действию
получения этого значения.

Текущая реализация проверяет только имена функций, которые начинаются с
русского префикса `Получить` без учета регистра. Процедуры и английские имена
вида `Get...` этой диагностикой не анализируются.

## Примеры

Неправильно:
```bsl
Функция ПолучитьДатуДокумента()
    Возврат ТекущийДокумент.Дата;
КонецФункции
```

Правильно:
```bsl
Функция ДатаДокумента()
    Возврат ТекущийДокумент.Дата;
КонецФункции
```
