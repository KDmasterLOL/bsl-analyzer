# Имя функции не должно начинаться с "Получить" (FunctionNameStartsWithGet)

## Описание диагностики

Префикс "Получить" в названии функции является избыточным, поскольку сам факт того, что метод объявлен как функция, уже подразумевает возврат значения. Использование этого префикса создает тавтологию в именовании и нарушает стандарты наименования процедур и функций.

## Примеры

Неправильно:
```bsl
Функция ПолучитьДатуДокумента()
    Возврат ТекущийДокумент.Дата;
КонецФункции
```

Правильно:
```bsl
Функция ДатаДокумента()
    Возврат ТекущийДокумент.Дата;
КонецФункции
```
