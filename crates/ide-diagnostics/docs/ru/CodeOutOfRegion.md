# Код расположен вне области (CodeOutOfRegion)

## Описание диагностики

Весь код программного модуля должен находиться внутри областей (`#Область` / `#КонецОбласти`). Разделение модуля на именованные области обеспечивает единообразную структуру, упрощает навигацию по коду и снижает вероятность конфликтов при совместной разработке.

Имена вложенных областей не проверяются -- контролируются только области верхнего уровня в соответствии со стандартом.

## Примеры

### Неправильно

```bsl
// Код вне области
Процедура ОбработатьДанные()
    // ...
КонецПроцедуры
```

### Правильно

```bsl
#Область СлужебныеПроцедурыИФункции

#Область РаботаСДокументами
Процедура ОбработатьДанные()
    // ...
КонецПроцедуры
#КонецОбласти

#Область РаботаСОтчётами
Процедура СформироватьОтчёт()
    // ...
КонецПроцедуры
#КонецОбласти

#КонецОбласти
```

### Таблица стандартных имён областей

| русск.  | англ. |
| ------------- | ------------- |
| ПрограммныйИнтерфейс  | Public  |
| СлужебныйПрограммныйИнтерфейс  | Internal  |
| СлужебныеПроцедурыИФункции  | Private  |
| ОбработчикиСобытий  | EventHandlers  |
| ОбработчикиСобытийФормы  | FormEventHandlers  |
| ОбработчикиСобытийЭлементовШапкиФормы  | FormHeaderItemsEventHandlers  |
| ОбработчикиКомандФормы  | FormCommandsEventHandlers  |
| ОписаниеПеременных  | Variables  |
| Инициализация  | Initialize  |
| ОбработчикиСобытийЭлементовТаблицыФормы  | FormTableItemsEventHandlers  |
