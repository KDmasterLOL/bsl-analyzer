# Безумные многострочные литералы (CrazyMultilineString)

## Описание диагностики

В BSL многострочные строковые константы можно записывать двумя способами:

- Через оператор конкатенации (`+`) с явным объединением частей строки
- Через пробельные разделители между строковыми литералами (неявная конкатенация)

Второй способ значительно снижает читаемость кода. При его использовании легко допустить ошибку, которую трудно обнаружить при визуальном просмотре.

## Примеры

Нерекомендуемый вариант:

```bsl
Текст = "Первая часть" "Вторая часть"
"Третья часть";
```

Рекомендуемый вариант:

```bsl
Текст = "Первая часть" + "Вторая часть"
    + "Третья часть";
```
