# Пустой оператор (EmptyStatement)

## Описание диагностики

Пустой оператор -- это изолированная точка с запятой (`;`), не относящаяся ни к какому выражению. Обычно он появляется в результате рефакторинга (удалена строка, а завершающий символ остался), копирования фрагмента кода или случайного повторного нажатия клавиши. Пустой оператор не влияет на логику выполнения, однако загромождает модуль и снижает его читаемость.

## Примеры

### Неправильно

```bsl
Результат = ВычислитьИтог();;
```

### Правильно

```bsl
Результат = ВычислитьИтог();
```
