# Использование привилегированного режима (SetPrivilegedMode)

## Описание диагностики

Диагностика помечает вызовы `УстановитьПривилегированныйРежим`, которые включают привилегированный режим. Такой режим отключает обычную проверку прав доступа, поэтому каждый подобный вызов требует ручной проверки.

Текущая реализация намеренно простая:

- вызовы, включающие привилегированный режим, помечаются;
- `УстановитьПривилегированныйРежим(Ложь)` игнорируется;
- диагностика не пытается автоматически доказать, что конкретный вызов безопасен или небезопасен.

Поэтому это именно security-hotspot, а не автоматическое доказательство ошибки.

## Примеры

```bsl
УстановитьПривилегированныйРежим(Истина); // требует проверки

Значение = Истина;
УстановитьПривилегированныйРежим(Значение); // требует проверки

УстановитьПривилегированныйРежим(Ложь); // игнорируется
```
