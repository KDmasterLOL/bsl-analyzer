# Присвоение общему модулю (CommonModuleAssign)

## Описание диагностики

Попытка присвоить значение имени общего модуля приводит к исключению времени
выполнения. Имя общего модуля не является обычной записываемой переменной.

Проблема обычно возникает из-за конфликта имен: разработчик использует
идентификатор, который совпадает с именем общего модуля в метаданных, а
платформа интерпретирует левую часть присваивания как обращение именно к
общему модулю.

## Примеры

### Неправильно

```bsl
// В конфигурации есть общий модуль "ОбщиеФункции"
Перем ОбщиеФункции;

ОбщиеФункции = 42; // Исключение: присвоение значения общему модулю
```

### Правильно

```bsl
// Переименовать переменную, чтобы избежать конфликта имён
Перем ЛокальныеФункции;

ЛокальныеФункции = 42;
```
