# Присвоение общему модулю (CommonModuleAssign)

## Описание диагностики

Попытка присвоить значение имени общего модуля приводит к исключению времени выполнения. Такая ситуация возникает, когда в модуле объявлена переменная с именем, совпадающим с именем общего модуля конфигурации, и затем этой переменной присваивается значение. Платформа интерпретирует имя как ссылку на общий модуль, а присвоение значения модулю запрещено.

## Примеры

### Неправильно

```bsl
// В конфигурации есть общий модуль "ОбщиеФункции"
Перем ОбщиеФункции;

ОбщиеФункции = 42; // Исключение: присвоение значения общему модулю
```

### Правильно

```bsl
// Переименовать переменную, чтобы избежать конфликта имён
Перем ЛокальныеФункции;

ЛокальныеФункции = 42;
```
