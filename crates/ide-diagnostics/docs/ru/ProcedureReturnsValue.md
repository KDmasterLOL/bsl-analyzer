# Процедура не должна возвращать значение (ProcedureReturnsValue)

## Описание диагностики

В языке BSL оператор `Возврат` внутри процедуры не может содержать возвращаемое значение. Возврат значения допустим только в функциях. Диагностика обнаруживает процедуры, в которых `Возврат` используется с выражением.

## Примеры

Неправильно:

```bsl
Процедура ПолучитьИмя()
    Возврат "Тест";
КонецПроцедуры
```

Правильно:

```bsl
Функция ПолучитьИмя()
    Возврат "Тест";
КонецФункции
```
