# Процедура не должна возвращать значение (ProcedureReturnsValue)

## Описание диагностики

Диагностика выявляет операторы `Возврат` с выражением внутри процедур.

В языке BSL возвращать значение могут только функции. Процедура может
использовать `Возврат;` для досрочного выхода, но не должна возвращать
выражение.

## Примеры

Неправильно:

```bsl
Процедура ПолучитьИмя()
    Возврат "Тест";
КонецПроцедуры
```

Правильно:

```bsl
Функция ПолучитьИмя()
    Возврат "Тест";
КонецФункции
```

```bsl
Процедура ПрерватьВыполнение()
    Возврат;
КонецПроцедуры
```
