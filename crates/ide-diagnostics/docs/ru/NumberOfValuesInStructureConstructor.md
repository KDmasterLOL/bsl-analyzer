# Ограничение на количество значений свойств, передаваемых в конструктор структуры (NumberOfValuesInStructureConstructor)

## Описание диагностики

В конструктор структуры не рекомендуется передавать более трёх значений свойств. При большом количестве аргументов становится сложно сопоставить имена ключей с передаваемыми значениями. Вместо этого следует создавать пустую структуру и заполнять её через метод `Вставить` или прямым присваиванием свойств.

## Примеры

Неправильно:

```bsl
Настройки = Новый Структура(
    "Организация, Период, Склад, Валюта, Ответственный",
    ВыбраннаяОрганизация,
    ТекущаяДата(),
    ОсновнойСклад,
    ВалютаУчета,
    ТекущийПользователь);
```

Правильно:

```bsl
Настройки = Новый Структура;
Настройки.Вставить("Организация", ВыбраннаяОрганизация);
Настройки.Вставить("Период", ТекущаяДата());
Настройки.Вставить("Склад", ОсновнойСклад);
Настройки.Вставить("Валюта", ВалютаУчета);
Настройки.Вставить("Ответственный", ТекущийПользователь);
```
