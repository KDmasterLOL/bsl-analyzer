# Ограничение на количество значений свойств, передаваемых в конструктор структуры (NumberOfValuesInStructureConstructor)

## Описание диагностики

Диагностика выявляет конструкторы `Структура` и `ФиксированнаяСтруктура`, в
которые передается слишком много значений свойств прямо в вызове конструктора.

Общая логика правила опирается на рекомендации 1С по использованию `Структура`:
длинные вызовы конструктора трудно читать, потому что приходится мысленно
сопоставлять список ключей с позициями передаваемых значений. Во многих случаях
понятнее сначала создать пустую структуру, а затем заполнить ее через
`Вставить`.

По умолчанию диагностика допускает не более `3` значений в конструкторе, но
порог можно изменить через `maxValuesCount`.

## Примеры

Неправильно:

```bsl
Настройки = Новый Структура(
    "Организация, Период, Склад, Валюта, Ответственный",
    ВыбраннаяОрганизация,
    ТекущаяДата(),
    ОсновнойСклад,
    ВалютаУчета,
    ТекущийПользователь);
```

Правильно:

```bsl
Настройки = Новый Структура;
Настройки.Вставить("Организация", ВыбраннаяОрганизация);
Настройки.Вставить("Период", ТекущаяДата());
Настройки.Вставить("Склад", ОсновнойСклад);
Настройки.Вставить("Валюта", ВалютаУчета);
Настройки.Вставить("Ответственный", ТекущийПользователь);
```
