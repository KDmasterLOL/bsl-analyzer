# Доступ к файловой системе (FileSystemAccess)

## Описание диагностики

Операции с файлами и каталогами (чтение, запись, копирование, удаление, перемещение) требуют повышенного внимания при аудите кода. Некорректное или злонамеренное обращение к файловой системе может привести к утечке конфиденциальных данных, несанкционированной модификации файлов или удалению важной информации. Особенно тщательно следует проверять код, полученный от сторонних разработчиков, из внешних источников или каталогов расширений.

По каждому срабатыванию диагностики рекомендуется выполнить ручную проверку на предмет безопасности и корректности: кто инициирует доступ, как формируется путь, как удаляются временные файлы и не происходит ли прямой передачи файловых путей между клиентом и сервером.

## Примеры

```bsl
ЧтениеФайла = Новый ЧтениеТекста(ПутьКФайлу, КодировкаТекста.UTF8); // срабатывание
ЗаписьФайла = Новый ЗаписьТекста(ПутьВыгрузки, КодировкаТекста.UTF8); // срабатывание

ЗначениеВФайл(ПутьКФайлу, ПерсональныеДанные); // срабатывание
КопироватьФайл(Источник, Приёмник); // срабатывание
ПереместитьФайл(Источник, Приёмник); // срабатывание
УдалитьФайлы(ВременныйКаталог); // срабатывание
СоздатьКаталог(НовыйКаталог); // срабатывание
```
