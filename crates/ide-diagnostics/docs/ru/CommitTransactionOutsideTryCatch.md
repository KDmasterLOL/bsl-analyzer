# Нарушение правил работы с транзакциями для метода 'ЗафиксироватьТранзакцию' (CommitTransactionOutsideTryCatch)

## Описание диагностики

Вызов `ЗафиксироватьТранзакцию()` должен быть последним оператором в блоке `Попытка`, непосредственно перед ключевым словом `Исключение`. Если после фиксации транзакции в блоке `Попытка` выполняется дополнительный код и он вызывает исключение, управление перейдёт в блок `Исключение`, где может быть выполнен `ОтменитьТранзакцию()` -- но транзакция уже зафиксирована. Это приводит к ошибкам и непредсказуемому поведению.

Текущая реализация срабатывает, если вызов:

- расположен вне конструкции `Попытка ... Исключение`;
- находится в ветке `Исключение`;
- расположен в ветке `Попытка`, но после него идёт исполняемый код.

Диагностика проверяет именно положение `ЗафиксироватьТранзакцию`, а не всю схему парности транзакций целиком.

## Примеры

### Неправильно

```bsl
НачатьТранзакцию();
Попытка
    Документ.Записать();
    ЗафиксироватьТранзакцию();
    ЗаписатьВЖурнал("Документ записан"); // ошибка здесь приведёт к откату уже зафиксированной транзакции
Исключение
    ОтменитьТранзакцию();
КонецПопытки;
```

### Правильно

```bsl
НачатьТранзакцию();
Попытка
    Документ.Записать();
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;

ЗаписатьВЖурнал("Документ записан");
```
