# Цикломатическая сложность (CyclomaticComplexity)

## Описание диагностики

Цикломатическая сложность -- метрика, предложенная Томасом Мак-Кейбом в 1976 году. Она определяет минимальное количество тестовых сценариев, необходимых для полного покрытия всех путей выполнения метода.

Высокая цикломатическая сложность свидетельствует о запутанной логике. Основные способы её снижения -- декомпозиция метода на более мелкие процедуры и упрощение условных выражений.

Каждая из следующих конструкций увеличивает значение метрики на 1:

- `Для ... По ... Цикл`
- `Для каждого ... Из ... Цикл`
- `Если ... Тогда`
- `ИначеЕсли ... Тогда`
- `Иначе`
- `Попытка ... Исключение ... КонецПопытки`
- `Перейти ~Метка`
- Бинарные операции `И` / `ИЛИ`
- Тернарный оператор `?()`
- `Процедура` / `Функция`

## Примеры

```bsl
Функция ОпределитьКатегорию(Сумма, ТипКлиента)                        // +1
    Если Сумма > 100000 Тогда                                          // +1
        Если ТипКлиента = "Оптовый" ИЛИ ТипКлиента = "Дилер" Тогда   // +1 (Если) +1 (ИЛИ)
            Категория = "А";
        ИначеЕсли ТипКлиента = "Розничный" Тогда                      // +1
            Категория = "Б";
        Иначе                                                          // +1
            Категория = "В";
        КонецЕсли;
    ИначеЕсли Сумма > 50000 Тогда                                     // +1
        Категория = "Г";
    Иначе                                                              // +1
        Категория = "Д";
    КонецЕсли;
    Результат = ?(Категория = "А", 1, 0);                             // +1
    Возврат Результат;
КонецФункции                                                           // итого: 10
```
