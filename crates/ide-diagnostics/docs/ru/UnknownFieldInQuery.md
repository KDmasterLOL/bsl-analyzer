# Поле не найдено в таблице запроса (UnknownFieldInQuery)

## Описание диагностики

Диагностика сообщает о запросе, который обращается к полю, отсутствующему в таблице метаданных.

Чтобы исключить ложные срабатывания, она работает только для таблиц с доказанно полной моделью полей (разрешённые ссылочные объекты и главная таблица регистра). Для неполных моделей диагностика молчит: это виртуальные таблицы регистров, временные таблицы, подзапросы и объекты, разрешённые через расширение.

Проверяется только первый хоп: в `Т.Поле.ПодПоле` относительно таблицы проверяется только `Поле`.

## Примеры

Обращение к несуществующему полю регистра:
```sdbl
ВЫБРАТЬ
	Т.НетТакогоПоля КАК Значение
ИЗ
	РегистрНакопления.Товары КАК Т
```
