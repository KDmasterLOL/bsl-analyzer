## ADDED Requirements

### Requirement: Отсутствующая конфигурация диагностик использует defaults без warning
Общий загрузчик конфигурации диагностик MUST трактовать `null`, которым project model представляет отсутствующую секцию, как штатное отсутствие настройки. Он SHALL возвращать `DiagnosticsConfig::default()` с разрешённой locale и MUST NOT записывать warning о десериализации. Это поведение MUST быть одинаковым для CLI, LSP и MCP.

#### Scenario: Analyze без файла конфигурации
- **WHEN** `bsl-analyzer-app analyze` запускается в проекте без поддержанного файла или секции конфигурации диагностик
- **THEN** анализ выполняется с defaults
- **AND** stderr не содержит `failed to deserialize project diagnostics config`

#### Scenario: Пустой объект диагностик
- **WHEN** проект явно передаёт пустой объект конфигурации диагностик
- **THEN** загрузчик принимает его как валидную конфигурацию с defaults без warning

### Requirement: Явно некорректная конфигурация остаётся наблюдаемой
Если значение конфигурации присутствует, но не может быть десериализовано как объект диагностик, загрузчик MUST записать один warning с причиной и MUST безопасно продолжить с `DiagnosticsConfig::default()`. Ошибка MUST NOT останавливать анализ и MUST NOT менять поведение корректной конфигурации.

#### Scenario: Строка вместо объекта
- **WHEN** конфигурация диагностик явно содержит строку вместо объекта
- **THEN** загрузчик выдаёт один warning и возвращает defaults

#### Scenario: Корректные параметры сохраняются
- **WHEN** конфигурация содержит поддержанные `parameters`, locale и другие существующие поля
- **THEN** они применяются без нового warning и без изменения прежней семантики
