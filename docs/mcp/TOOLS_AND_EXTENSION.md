# Инструменты MCP и расширение для 1С

Сервер MCP (Model Context Protocol) в BSL Analyzer предоставляет набор инструментов (tools), которые AI-агенты могут вызывать для работы с кодом 1С.

## Доступные инструменты

В зависимости от профиля сервера (`reference` или `workspace`), доступны разные инструменты:

### Профиль `reference` (Справка)
- `search(find_docs/search_docs/status)` — полнотекстовый и семантический поиск по документации платформы.
- `syntax_help` — справка по API платформы: типы, методы, глобальные функции.
- `its_help` — вопрос эксперту по ИТС: стандарты разработки, паттерны БСП, методические рекомендации.

### Профиль `workspace` (Проект)
- `metadata` — структура конфигурации: объекты, реквизиты, табличные части, формы.
- `search(find_code/search_code/status)` — полнотекстовый и семантический поиск по коду проекта.
- `query` — валидация и выполнение SDBL-запросов к подключённой базе 1С.
- `execute` — проверка синтаксиса, выполнение произвольного кода 1С и вычисление выражений в подключённой базе.
- `debug` — интеграция с отладчиком 1С: установка точек останова, просмотр стека вызовов, пошаговое выполнение.

---

## Справка ИТС (`its_help`)

Инструмент `its_help` обращается к сервису [1С:Напарник](https://code.1c.ai/) для поиска по стандартам ИТС, методическим рекомендациям и документации платформы. 

**Требования:**
1. Получите токен на [code.1c.ai/tokens](https://code.1c.ai/tokens).
2. Передайте его через переменную окружения `NAPARNIK_TOKEN` при запуске MCP-сервера или установке (`--env NAPARNIK_TOKEN=...`).

> **Примечание:** без `NAPARNIK_TOKEN` все остальные инструменты работают. При попытке вызова `its_help` AI-агент просто получит сообщение об ошибке.

## Расширение 1С (для `query`, `execute`, `debug`)

Инструменты `reference`-профиля и локальные инструменты `workspace` (`metadata`, `search` по коду) работают **без подключения к базе 1С**.

Однако для работы инструментов `query`, `execute` и `debug` требуется подключение к работающей базе 1С через HTTP-сервис. Расширение конфигурации с этим HTTP-сервисом встроено в бинарник `bsl-analyzer`.

### Установка расширения в базу 1С

1. **Экспортируйте расширение из бинарника:**
   ```bash
   bsl-analyzer extension export -o ./bsl-extension
   ```
2. **Загрузите в конфигуратор:**
   В конфигураторе 1С откройте **Конфигурация → Расширения конфигурации**. Нажмите **Добавить** и загрузите каталог `bsl-extension` как расширение.
3. **Опубликуйте HTTP-сервис:**
   В конфигураторе перейдите в **Администрирование → Публикация на веб-сервере**, включите публикацию HTTP-сервисов и убедитесь, что сервис `BSLAnalyzerService` опубликован по пути `/hs/bsl-analyzer`.
4. **Настройте права:**
   Убедитесь, что пользователю 1С, под которым будет подключаться MCP-сервер, назначена роль `BSL_ОсновнаяРоль`.

### Проверка подключения

После публикации проверьте доступность HTTP-сервиса с помощью `curl` или браузера:

```bash
curl http://localhost/base/hs/bsl-analyzer/version
# Ожидаемый ответ: {"version":"1.0.0"}
```

### Запуск MCP с подключением к 1С

Чтобы инструменты активировались, при запуске `workspace` профиля нужно передать параметры подключения:

```bash
bsl-analyzer mcp serve \
  --profile workspace \
  --source-dir ./my-project \
  --onec-url http://localhost/base/hs/bsl-analyzer \
  --onec-user admin \
  --onec-password secret
```
