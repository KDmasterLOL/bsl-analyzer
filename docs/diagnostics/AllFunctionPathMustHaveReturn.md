# AllFunctionPathMustHaveReturn

Проверяет, что ВСЕ пути выполнения функции возвращают значение.

## Описание

Функции должны гарантировать, что каждый возможный путь выполнения возвращает значение. Без этого некоторые пути кода могут возвращать `Неопределено`, что приводит к трудноуловимым ошибкам.

Диагностика использует анализ графа потока управления (CFG) для проверки всех возможных путей выполнения.

## Примеры

### ❌ Неправильно

#### Отсутствует ветка Иначе

```bsl
Функция ОпределитьСтавкуНДС(Знач Ставка)
    Если Ставка = Перечисления.СтавкиНДС.НДС20 Тогда
        Возврат 20;
    ИначеЕсли Ставка = Перечисления.СтавкиНДС.НДС10 Тогда
        Возврат 10;
    КонецЕсли;
    // Отсутствует возврат в ветке Иначе!
КонецФункции
```

#### Отсутствует возврат в обработчике исключений

```bsl
Функция ПроверитьЧисло(Число)
    Попытка
        Возврат Число / 2;
    Исключение
        // Отсутствует возврат в обработчике исключений!
        СообщитьОбОшибке();
    КонецПопытки;
КонецФункции
```

#### Отсутствует возврат после цикла

```bsl
Функция НайтиЭлемент(Массив, Значение)
    Для Каждого Элемент Из Массив Цикл
        Если Элемент = Значение Тогда
            Возврат Истина;
        КонецЕсли;
    КонецЦикла;
    // Отсутствует возврат после цикла!
КонецФункции
```

### ✅ Правильно

#### Полная структура If-Else

```bsl
Функция ОпределитьСтавкуНДС(Знач Ставка)
    Если Ставка = Перечисления.СтавкиНДС.НДС20 Тогда
        Возврат 20;
    ИначеЕсли Ставка = Перечисления.СтавкиНДС.НДС10 Тогда
        Возврат 10;
    Иначе
        Возврат 0;
    КонецЕсли;
КонецФункции
```

#### Возврат в обработчике исключений

```bsl
Функция ПроверитьЧисло(Число)
    Попытка
        Возврат Число / 2;
    Исключение
        Возврат -1;
    КонецПопытки;
КонецФункции
```

#### Возврат после цикла

```bsl
Функция НайтиЭлемент(Массив, Значение)
    Для Каждого Элемент Из Массив Цикл
        Если Элемент = Значение Тогда
            Возврат Истина;
        КонецЕсли;
    КонецЦикла;
    Возврат Ложь;
КонецФункции
```

## Конфигурация

### Формат .bslls.json

```json
{
  "diagnostics": {
    "parameters": {
      "AllFunctionPathMustHaveReturn": {
        "loopsExecutedAtLeastOnce": true,
        "ignoreMissingElseOnExit": false
      }
    }
  }
}
```

### Параметры

#### loopsExecutedAtLeastOnce

**Тип:** `boolean`
**По умолчанию:** `true`

Предполагать, что циклы (while/for/foreach) выполняются хотя бы один раз.

- `true` — путь обхода цикла (когда цикл не выполняется) допускается без явного возврата
- `false` — все пути, включая обход цикла, должны иметь явный возврат

**Пример:**

```bsl
Функция НайтиЭлемент(Массив, Значение)
    Для Каждого Элемент Из Массив Цикл
        Если Элемент = Значение Тогда
            Возврат Истина;
        КонецЕсли;
    КонецЦикла;
    // При loopsExecutedAtLeastOnce = true: диагностика не сработает
    // При loopsExecutedAtLeastOnce = false: требуется явный возврат
КонецФункции
```

#### ignoreMissingElseOnExit

**Тип:** `boolean`
**По умолчанию:** `false`

Игнорировать отсутствие ветки Иначе в условиях, ведущих к выходу.

- `true` — If/ИначеЕсли без Иначе на пути к выходу допускается
- `false` — отсутствие ветки Иначе сообщается как отсутствие пути возврата

**Пример:**

```bsl
Функция ОпределитьСтавку(Ставка)
    Если Ставка = 20 Тогда
        Возврат 20;
    ИначеЕсли Ставка = 10 Тогда
        Возврат 10;
    КонецЕсли;
    // При ignoreMissingElseOnExit = true: диагностика не сработает
    // При ignoreMissingElseOnExit = false: требуется ветка Иначе
КонецФункции
```

## Совместимость

Полностью совместима с bsl-language-server:
- Код диагностики: `AllFunctionPathMustHaveReturn`
- Параметры конфигурации: идентичны
- Поведение: идентично

## Связанные диагностики

- **FunctionShouldHaveReturn** — проверяет наличие хотя бы одного оператора Возврат в функции
- **ProcedureReturnsValue** — проверяет, что процедуры не возвращают значения

## Технические детали

### Алгоритм

1. Построить граф потока управления (CFG) для функции
2. Получить все входящие рёбра к точке выхода
3. Для каждой входящей вершины проверить наличие явного возврата
4. Сообщить о путях без явного возврата

### Реализация

- **CFG Infrastructure:** `crates/cfg/`
- **Diagnostic Handler:** `crates/ide-diagnostics/src/handlers/all_function_path_must_have_return.rs`
- **Портировано из:**
  - AllFunctionPathMustHaveReturnDiagnostic.java (bsl-language-server)
  - all_function_path_must_have_return.rs (bsl-language-server-rust)

### Производительность

Диагностика требует построения CFG для каждой функции:
- Время построения CFG: O(n), где n — количество операторов
- Анализ путей: O(e), где e — количество рёбер в графе
- Общая сложность: O(n + e) на функцию

Для типичного проекта (~10,000 функций, ~50 операторов в функции):
- Анализ занимает < 100 мс
- Потребление памяти: ~10 MB
