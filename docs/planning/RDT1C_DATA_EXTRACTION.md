# Извлечение данных о платформе 1С из RDT1C

Документ описывает как RDT1C собирает данные о типах/методах/свойствах платформы 1С и как это повторить для bsl-analyzer.

## Источники данных

### Файлы синтакс-помощника платформы

**Расположение:** `C:\Program Files\1cv8\<версия>\bin\` (или `КаталогПрограммы()` в 1С)

| Файл | Содержимое |
|------|------------|
| `shcntx_ru.hbk` | Справка по типам, методам, свойствам |
| `shlang_ru.hbk` | Справка по встроенному языку |

### Формат .hbk файла

`.hbk` — это **ZIP-архив** со специальной структурой:

```
shcntx_ru.hbk (ZIP)
├── FileStorage.data    (ZIP) ← HTML страницы справки
├── PackBlock.data      (ZIP) ← Содержание/структура книги
└── IndexPackBlock.data (ZIP) ← Индекс для поиска
```

**Код извлечения в RDT1C:**
- `src/DataProcessors/ирСинтаксПомощник/Ext/ObjectModule.bsl:146` — функция `АрхивСинтаксПомощникаПоИмени()`
- Элемент 0 = FileStorage.data (страницы)
- Элемент 1 = PackBlock.data (содержание)
- Элемент 2 = IndexPackBlock.data (индекс)

## Алгоритм сбора данных

### Код генерации

**Форма:** `src/DataProcessors/ирПлатформа/Forms/ОписаниеПлатформы/Ext/Form/Module.bsl`

### Основные шаги

```
1. Распаковать shcntx_ru.hbk
   └── СинтаксПомощник.АрхивСинтаксПомощникаПоИмени(0, "shcntx_ru")
   └── СинтаксПомощник.ЗапуститьРаспаковкуАрхиваСинтаксПомощника()

2. Прочитать индекс (IndexPackBlock.data)
   └── Парсить регуляркой структуру индекса

3. Для каждого элемента индекса:
   └── Определить тип слова по пути:
       • /methods/    → "Метод"
       • /properties/ → "Свойство"
       • /events/     → "Событие"
       • /ctors/      → "Конструктор"
       • /fields/     → "Свойство"
       • /tables/     → "Таблица" (язык запросов)

   └── Прочитать HTML файл страницы

   └── Извлечь данные регулярками:
       • Тип возвращаемого значения
       • Версия платформы
       • Доступность по контекстам
       • Режим чтения/записи

4. Для типов - дополнительно рефлексия:
   └── Тип(ИмяТипа) → получить реальный объект типа
   └── ТипЗнч(Значение) → UUID типа
   └── Вычислить(ИмяПеречисления) → проверка перечислений
```

### Ключевые регулярные выражения

```bsl
// Парсинг индекса (строка 1236)
'((""ru""\,""([^""]+)""[^}]*}[^{]*{[^{}]*})|({""#"",""([^""]*)""}))[^}]*},""([^""]+)""'

// Версия платформы (строка 1395)
"Доступен, начиная с версии (8.*?)\.<"

// Тип значения свойства (строка 1332)
"Тип:" + шТегНеКлюч + "?((?:" + шТип + ")+)"

// Возвращаемое значение метода (строка 1335)
"Возвращаемое значение:" + шТег + "?(?:" + шТип + ")?"

// Элементы коллекции (строка 1379)
"Элементы\x20коллекции:" + шТегНеКлюч + "?((?:" + шТип + ")+)"

// Доступность (строка 1409)
шТегКлюч + "Доступность:" + шКонецТегаКлюч
// Затем поиск: "тонкий клиент", "толстый клиент", "сервер"

// Использование свойств (строка 1425)
шТегКлюч + "Использование:" + шКонецТегаКлюч
// Затем поиск: "запись"
```

### Вариант 1: Экспорт через 1С (рекомендуется)

### Вариант 2: Парсер .hbk на Rust

```rust
use zip::ZipArchive;
use regex::Regex;

pub fn extract_platform_api(platform_bin_dir: &Path) -> Result<PlatformDatabase> {
    let hbk_path = platform_bin_dir.join("shcntx_ru.hbk");
    let hbk_file = File::open(&hbk_path)?;
    let mut hbk_zip = ZipArchive::new(hbk_file)?;

    // 1. Извлечь FileStorage.data (вложенный ZIP)
    let file_storage = hbk_zip.by_name("FileStorage.data")?;
    let mut pages_zip = ZipArchive::new(file_storage)?;

    // 2. Извлечь и парсить IndexPackBlock.data
    let index_data = hbk_zip.by_name("IndexPackBlock.data")?;
    let index = parse_hbk_index(&index_data)?;

    // 3. Для каждой страницы - извлечь информацию
    let mut types = Vec::new();
    let mut methods = Vec::new();

    for entry in index.entries {
        let html = read_zip_entry(&mut pages_zip, &entry.path)?;

        if entry.path.contains("/methods/") {
            methods.push(parse_method_page(&html, &entry)?);
        } else if entry.path.contains("/properties/") {
            methods.push(parse_property_page(&html, &entry)?);
        } else if is_type_page(&entry.path) {
            types.push(parse_type_page(&html, &entry)?);
        }
    }

    Ok(PlatformDatabase { types, methods })
}

fn parse_method_page(html: &str, entry: &IndexEntry) -> Result<PlatformMethod> {
    // Регулярки аналогичные BSL коду
    let version_re = Regex::new(r"Доступен, начиная с версии (8\.[^\.<]+)")?;
    let return_type_re = Regex::new(r"Возвращаемое значение:.*?<[^>]+>([^<]+)")?;
    let availability_re = Regex::new(r"Доступность:.*?([^.]+)\.")?;

    let min_version = version_re.captures(html)
        .map(|c| parse_version(&c[1]))
        .unwrap_or(Version::new(8, 0, 0));

    let return_type = return_type_re.captures(html)
        .map(|c| c[1].trim().to_string());

    let availability = availability_re.captures(html)
        .map(|c| parse_availability(&c[1]))
        .unwrap_or_default();

    Ok(PlatformMethod {
        type_name: extract_type_from_path(&entry.path),
        name: entry.name.clone(),
        kind: MemberKind::Method,
        return_type,
        min_version,
        context: availability,
        ..Default::default()
    })
}
```

**Плюсы:** Независимость, свежие данные для любой версии
**Минусы:** Сложнее, нужен reverse engineering формата индекса

### Вариант 3: Парсер формата макетов 1С

```rust
// Парсер сериализованного формата таблицы значений 1С
pub fn parse_1c_value_table(input: &str) -> Result<Vec<HashMap<String, Value>>> {
    // Рекурсивный парсер для структуры {...}
    let mut parser = Parser::new(input);
    parser.parse_table()
}

enum Value {
    String(String),     // {"S", "value"}
    Number(f64),        // {"N", 123}
    Boolean(bool),      // {"B", 0} или {"B", 1}
    Null,
}

impl Parser {
    fn parse_value(&mut self) -> Result<Value> {
        self.expect("{")?;
        let type_marker = self.parse_string()?;
        self.expect(",")?;

        let value = match type_marker.as_str() {
            "S" => Value::String(self.parse_string()?),
            "N" => Value::Number(self.parse_number()?),
            "B" => Value::Boolean(self.parse_number()? != 0.0),
            _ => return Err(Error::UnknownType(type_marker)),
        };

        self.expect("}")?;
        Ok(value)
    }
}
```

**Плюсы:** Прямое использование существующих данных RDT1C
**Минусы:** Хрупкий формат, может сломаться
